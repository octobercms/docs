# Twig Tags

Tag | Description
------------- | -------------
[`{% ajaxPartial %}`](./twig-tags/ajax-partial.md) | renders a partial that can update itself with AJAX.
[`{% cache %}`](./twig-tags/cache.md) | caches the enclosed content.
[`{% component %}`](./twig-tags/component.md) | renders the default markup of a CMS component.
[`{% content %}`](./twig-tags/content.md) | renders a CMS content block.
[`{% flash %}`](./twig-tags/flash.md) | renders the flash messages stored in the session.
[`{% for %}`](./twig-tags/for.md) | loops over each value in a collection.
[`{% if %}`](./twig-tags/if.md) | renders content when an expression is true.
[`{% macro %}`](./twig-tags/macro.md) | defines a reusable function inside a template.
[`{% page %}`](./twig-tags/page.md) | renders the page contents inside a layout.
[`{% partial %}`](./twig-tags/partial.md) | renders a CMS partial.
[`{% placeholder %}`](./twig-tags/placeholder.md) | renders a placeholder section, generally inside a layout.
[`{% props %}`](./twig-tags/props.md) | declares the props and attributes a partial accepts.
[`{% verbatim %}`](./twig-tags/verbatim.md) | outputs a section as raw text without parsing it.

# Tailor Components

Component | Description
------------- | -------------
[`collection`](./tailor-components/collection.md) | displays a collection of entries on the page.
[`global`](./tailor-components/global.md) | makes a global record available to the page, layout or partial.
[`resources`](./tailor-components/resources.md) | creates variables, adds headers and injects assets into the page.
[`section`](./tailor-components/section.md) | defines a website section with a supporting entry.
[`sitePicker`](./tailor-components/sitepicker.md) | provides tools for working with multiple sites.
[`submission`](./tailor-components/submission.md) | displays a form for accepting user submitted content.
[`translatable`](./tailor-components/translatable.md) | stores translated page properties for each site.

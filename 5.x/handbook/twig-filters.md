# Twig Filters

Filter | Description
------------- | -------------
[`\|app`](./twig-filters/app.md) | returns a URL relative to the public path of the website.
[`\|currency`](./twig-filters/currency.md) | formats a currency value.
[`\|default`](./twig-filters/default.md) | returns a fallback value when the value is undefined or empty.
[`\|link`](./twig-filters/link.md) | converts a page finder value to a URL.
[`\|md`](./twig-filters/md.md) | converts Markdown to HTML.
[`\|media`](./twig-filters/media.md) | returns a URL to a file in the media library.
[`\|page`](./twig-filters/page.md) | returns a URL to a CMS page using its file name.
[`\|raw`](./twig-filters/raw.md) | marks the value as safe so it is not escaped.
[`\|resize`](./twig-filters/resize.md) | resizes an image and returns its URL.
[`\|theme`](./twig-filters/theme.md) | returns a URL to an asset in the active theme.

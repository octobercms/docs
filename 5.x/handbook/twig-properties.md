# Twig Properties

Property | Description
------------- | -------------
[`this.controller`](./twig-properties/this-controller.md) | the current controller object.
[`this.environment`](./twig-properties/this-environment.md) | the current environment name.
[`this.layout`](./twig-properties/this-layout.md) | the current layout object.
[`this.page`](./twig-properties/this-page.md) | the current page object.
[`this.param`](./twig-properties/this-param.md) | the current URL parameters.
[`this.request`](./twig-properties/this-request.md) | the current request object.
[`this.session`](./twig-properties/this-session.md) | the current session manager.
[`this.site`](./twig-properties/this-site.md) | the active site definition.
[`this.theme`](./twig-properties/this-theme.md) | the active theme and its customization settings.

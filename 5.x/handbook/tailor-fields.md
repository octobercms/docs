# Content Fields

Content fields are available inside Tailor blueprints, in addition to the [form fields](./form-fields.md).

Field | Description
------------- | -------------
[`entries`](./tailor-fields/entries.md) | links to other entries by UUID or handle.
[`mixin`](./tailor-fields/mixin.md) | includes another set of fields.
[`nesteditems`](./tailor-fields/nesteditems.md) | creates nested records belonging exclusively to the current record.

# Database Configuration

The database configuration is in the `config/database.php` file. This file defines all of your database connections and which one is used by default, with examples for each supported database system. Most values load from environment variables in the `.env` file.

```ini
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=database
DB_USERNAME=root
DB_PASSWORD=
```

## Using SQLite

An SQLite database is a single file on your filesystem. To create a new SQLite database, use the `touch` command.

```bash
touch storage/database.sqlite
```

Then set your environment variables to use the database, with the absolute path to the file in the `DB_DATABASE` variable.

```text
DB_CONNECTION=sqlite
DB_DATABASE=/absolute/path/to/database.sqlite
```

## Using Separate Read and Write Connections

You can use one database connection for SELECT statements and another for INSERT, UPDATE and DELETE statements. The right connection is used whether you run raw queries, use the query builder or use a model.

This example configures separate read and write hosts.

```php
'mysql' => [
    'read' => [
        'host' => '192.168.1.1',
    ],
    'write' => [
        'host' => '192.168.1.2'
    ],
    'driver'    => 'mysql',
    'database'  => 'database',
    'username'  => 'root',
    'password'  => '',
    'charset'   => 'utf8',
    'collation' => 'utf8_unicode_ci',
    'prefix'    => '',
],
```

Two keys have been added to the configuration array: `read` and `write`. Each contains a single key, `host`. The other database options for the `read` and `write` connections are merged from the main `mysql` array.

You only need to place items in the `read` and `write` arrays to override values in the main array. In this case, `192.168.1.1` is used for the read connection and `192.168.1.2` for the write connection. The database credentials, prefix, character set and all other options in the main `mysql` array are shared by both connections.

## Index Lengths Using MySQL / MariaDB

October CMS uses the `utf8mb4` character set by default. If you run a version of MySQL older than v5.7.7 or MariaDB older than v10.2.2, configure the default string length generated by migrations so MySQL can create indexes for them. Add the following to your **config/database.php** file under the `connections.mysql` key.

```php
'mysql' => [
    // ...
    'varcharmax' => 191,
],
```

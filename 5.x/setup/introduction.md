# Welcome to October CMS

October CMS is a content management system built on [Laravel](https://laravel.com). It gives you a backend panel for managing content and a simple way to build websites, with the full Laravel framework underneath.

## Choose Your Path

There are two main ways to work with October CMS. Many projects use both, but it helps to know which one you are in.

**Theme development** builds the website a visitor sees. You work with pages, layouts and partials written in Twig, manage content with Tailor, and set up sites and translations.

**Backend development** builds the application behind it, including headless projects with no theme at all. You work with plugins, models, controllers, forms, lists and permissions.

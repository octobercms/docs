# Theme Development

Theme development builds the website a visitor sees. A theme is a folder of pages, layouts and partials written in Twig, and Tailor defines the content that editors manage in the admin panel.

## Where to Start

Read these in order to learn the essentials.

1. [Theme Structure](./structure.md), how a theme is organized.
1. [Pages](./pages.md), [Layouts](./layouts.md) and [Partials](./partials.md), the building blocks of every website.
1. [Twig Templating](./templating.md), the Twig syntax used inside them.
1. [Using Components](./components.md), adding features to pages.
1. [Tailor Overview](./tailor/introduction.md), defining and displaying content.
1. [AJAX Framework](./ajax/introduction.md), updating the page without a reload.

# Getting Started

Welcome to October CMS! This guide will have you up and running with a working website in just a few minutes. Choose one of the installation methods below to get started.

## Choose Your Installation Method

### Wizard Installer

The easiest way to install October CMS. No command line required — just download, extract, and follow the on-screen wizard in your browser.

**Best for:** Shared hosting, cPanel environments, or anyone who prefers a visual setup.

[Continue with the Wizard Installer →](./installation.md#wizard-installer)

### DDEV (Docker)

A Docker-based local development environment. DDEV handles PHP, the database, and the web server for you in an isolated container — nothing to install on your system besides Docker and DDEV.

**Best for:** Local development, developers who want a clean, reproducible environment.

[Continue with DDEV →](./installation.md#ddev)

### Composer

For developers who already have PHP and Composer set up, you can install October CMS directly from the command line. See the [Installation guide](../../../4.x/setup/installation.md) in the developer documentation.

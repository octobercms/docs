## Минимальные системные требования

Перед установкой October CMS убедитесь, что целевая система соответствует минимальным требованиям:

* PHP версии 8.0.0 или выше
* Composer 2.0 или выше
* Расширение PHP PDO
* Расширение PHP cURL
* Расширение PHP OpenSSL
* Расширение PHP Mbstring
* Расширение PHP ZipArchive
* Расширение PHP GD
* Расширение PHP SimpleXML.

Поддерживаемые серверы баз данных:

* MySQL 5.7 или MariaDB 10.2. Для более старых версий MySQL или MariaDB может потребоваться [настроить длину индексов](../setup/database-config.md#oc-index-lengths-using-mysql-mariadb) для поддержки набора символов utf8mb4.
* PostgreSQL 9.6
* SQLite 3.8.8.

Поддерживаемые веб-серверы:

* Apache
* Nginx
* Lighttpd
* Microsoft IIS

## Установка October CMS

::: aside
Необходимо настроить виртуальный хост на веб-сервере для доступа к каталогу установки. Для локальной разработки можно использовать [Laravel Sail](../resources/using-laravel-sail.md), [Valet](https://laravel.com/docs/valet), [Laragon](https://laragon.org/) или встроенный сервер разработки Laravel.
:::

October CMS — это веб-приложение на PHP, которое использует [Composer](http://getcomposer.org/) для управления зависимостями. Перед началом убедитесь, что Composer установлен. Для завершения установки потребуется [лицензионный ключ](https://octobercms.com/help/site/projects#project-id).

Для установки платформы инициализируйте проект с помощью команды `create-project` в терминале. Следующая команда создаёт новый проект в каталоге *myoctober*:

```bash
composer create-project october/october myoctober
```

Приведённые выше команды устанавливают последнюю версию October CMS. Если вы хотите установить версию v3.0, используйте следующую команду.

```bash
composer create-project october/october myoctober "^3.0"
```

После завершения команды перейдите в каталог проекта:

```bash
cd myoctober
```

Запустите команду установки:

```bash
php artisan october:install
```

Последний шаг — команда миграции, которая инициализирует базу данных. В качестве альтернативы October CMS может инициализировать базу данных при первом обращении к панели администрирования.

```bash
php artisan october:migrate
```

После завершения процесса вы можете открыть панель администрирования в браузере и создать профиль администратора. Если вы используете встроенный веб-сервер, запустите его следующей командой:

```bash
php artisan serve
```

::: warning
Если вы устанавливаете платформу на рабочий веб-сервер, ознакомьтесь с рекомендациями, перечисленными в статье [Настройка для рабочего окружения](../setup/configuration.md#production-configuration).
:::

## Установка с помощью мастера

<VideoBlockLink src="https://www.youtube.com/watch?v=ypyOiVCxaQg" title="Руководство по мастеру установки" description="В этом видео описывается процесс установки October CMS с помощью простого мастера установки." prompt="Смотреть руководство" />

Установка с помощью мастера — это альтернативный способ установки October CMS без использования Composer. Он проще, чем установка через командную строку, и не требует специальных навыков.

1. Подготовьте пустой каталог на сервере. Это может быть подкаталог, корневой каталог домена или поддомен.
1. [Скачайте архив установщика](https://octobercms.com/download).
1. Распакуйте архив установщика в подготовленный каталог.
1. Предоставьте права на запись для каталога установки, всех его подкаталогов и файлов.
1. Откройте скрипт `install.php` в веб-браузере.
1. Следуйте инструкциям по установке.

## Устранение неполадок при установке

В процессе установки или после неё могут возникнуть несколько типичных проблем.

::: details Установка зависает после ввода лицензионного ключа
В некоторых окружениях это может происходить при вставке содержимого лицензионного ключа. Нажмите клавишу ENTER несколько раз, чтобы процесс установки продолжился.
:::

::: details При установке отображается ошибка «Unable to get local issuer certificate»
Полное сообщение об ошибке может выглядеть так: `cURL error 60: SSL certificate problem: unable to get local issuer certificate`.

Скачайте [этот файл сертификата](https://curl.se/ca/cacert.pem) и сохраните его как `cacert.pem`. Откройте файл **php.ini** и добавьте или измените следующую строку. Для применения изменений может потребоваться перезапуск Apache.
```
curl.cainfo = "/path/to/cacert.pem"
```
:::

::: details При миграции отображается ошибка «Specified key was too long»
Полное сообщение об ошибке может выглядеть так: `SQLSTATE[42000]: Syntax error or access violation: 1071 Specified key was too long; max key length is 767 bytes`

Это может произойти при использовании старых версий MySQL или MariaDB. [Настройка длины индексов](../setup/database-config.md#index-lengths-using-mysql-mariadb) для поддержки набора символов utf8mb4 поможет решить эту проблему.
:::

::: details При открытии приложения отображается пустой экран
Проверьте, что права доступа к файлам и подкаталогам /storage установлены правильно. Они должны быть доступны для записи веб-серверу.
:::

::: details Ошибка недействительного токена безопасности при входе в систему
Убедитесь, что в каталоге storage/framework нет отсутствующих подкаталогов. Возможно, потребуется создать [каталоги sessions, cache и views](https://github.com/octobercms/october-private/tree/develop/storage/framework).
:::

::: details Панель администрирования отображает «Page not found» (404)
Если приложение не может найти базу данных, для панели администрирования будет отображаться страница 404. Попробуйте включить [режим отладки](../setup/configuration.md#debug-mode), чтобы увидеть исходное сообщение об ошибке.
:::

::: details При обновлении приложения отображается ошибка 500
Необходимо увеличить или отключить тайм-аут запросов на веб-сервере. Например, в Apache FastCGI иногда параметр -idle-timeout установлен на 30 секунд.
:::

::: details Zend OPcache API is restricted by "restrict_api" configuration directive
Эта проблема может возникнуть, когда внутренние компоненты пытаются использовать внутренний механизм OPcache. Её можно устранить, установив параметр **force_bytecode_invalidation** в значение `false` в файле **config/cms.php**.
:::

::: details Invalid credentials (HTTP 403) for '...', aborting.
Эта ошибка может возникнуть в Composer, когда файл **auth.json** отсутствует на сервере или срок действия лицензии проекта истёк. Попробуйте войти в свою учётную запись и проверить, что у проекта есть активная лицензия. Если лицензия активна, её можно сбросить с помощью artisan-команды `project:set`.
:::

# Развёртывание

::: aside
При развёртывании сайта в рабочем окружении убедитесь, что вы выполнили рекомендуемую [настройку для рабочего окружения](./configuration.md).
:::

Проекты October CMS можно развернуть с помощью Composer при наличии доступа к командной строке (оболочке), а также с помощью официального плагина Deploy при ограниченном доступе к оболочке.

## Развёртывание с помощью Composer

Этот сценарий применим, если у вас есть SSH-доступ и Composer установлен на целевом сервере. Развёртывание проектов October CMS с помощью Composer аналогично развёртыванию любого другого проекта на Composer:

* клонируйте репозиторий проекта на сервер;
* скопируйте файл `auth.json` вручную на сервер;
* выполните `composer install` в каталоге проекта;
* обновите файлы конфигурации.

Имейте в виду, что файл [auth.json](https://getcomposer.org/doc/articles/http-basic-authentication.md) из исходной установки October CMS необходимо перенести на сервер. Этот файл автоматически создаётся при первой установке October CMS. Он содержит информацию о лицензионном ключе и необходим для аутентификации запросов Composer к шлюзу October CMS.

В качестве альтернативы можно пересоздать файл **auth.json** с помощью artisan-команды `project:set` перед выполнением composer install.

```bash
php artisan project:set <license key>
```

## Развёртывание без Composer

Если у вас нет SSH-доступа к серверу или вы не можете выполнять команды Composer по какой-либо причине, существует возможность развернуть проект October CMS с помощью официального <LinkWithIcon text="плагина Deploy" icon="https://d2f5cg397c40hu.cloudfront.net/storage/app/uploads/public/optimized/local/c99/b52/eb1c99b52eb1dde393bb7ef60e4c861b062.png" href="https://octobercms.com/plugin/rainlab-deploy"/>.

<VideoBlockLink src="https://www.youtube.com/watch?v=Lx9X3CfXwfw" title="Руководство по развёртыванию" description="В этом видео описывается, как развернуть проект на удалённом сервере без Composer." prompt="Смотреть руководство"/>

Плагин Deploy использует локальную установку October CMS для выполнения команд Composer на вашем компьютере. Локально сгенерированные файлы развёртываются на сервер на основе этой установки. После этого October CMS предоставляет средство обновления в один клик, которое можно использовать для обновления установки непосредственно на сервере. Если обновление в один клик завершается неудачей, плагин Deploy можно использовать для восстановления установки без доступа к командной строке.

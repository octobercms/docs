# Конфигурация базы данных

Конфигурация базы данных вашего приложения находится в файле `config/database.php`. В этом файле вы можете определить все подключения к базам данных, а также указать, какое подключение должно использоваться по умолчанию. Примеры для всех поддерживаемых систем баз данных приведены в этом файле.

## Конфигурация SQLite

Базы данных SQLite используют один файл в файловой системе. Чтобы создать новую базу данных SQLite, используйте команду `touch`.

```bash
touch storage/database.sqlite
```

После этого вы можете настроить переменные окружения для использования базы данных, указав абсолютный путь в переменной `DB_DATABASE`.

```text
DB_CONNECTION=sqlite
DB_DATABASE=/absolute/path/to/database.sqlite
```

## Подключения для чтения и записи

Иногда может потребоваться использовать одно подключение к базе данных для операторов SELECT, а другое — для операторов INSERT, UPDATE и DELETE. Указать, какое подключение используется, легко независимо от того, применяете ли вы прямые запросы, конструктор запросов или модель.

Чтобы увидеть, как следует настраивать подключения для чтения и записи, рассмотрим следующий пример:

```php
'mysql' => [
    'read' => [
        'host' => '192.168.1.1',
    ],
    'write' => [
        'host' => '196.168.1.2'
    ],
    'driver'    => 'mysql',
    'database'  => 'database',
    'username'  => 'root',
    'password'  => '',
    'charset'   => 'utf8',
    'collation' => 'utf8_unicode_ci',
    'prefix'    => '',
],
```

Обратите внимание, что в массив конфигурации добавлены два ключа: `read` и `write`. Оба эти ключа содержат массивы с одним ключом: `host`. Остальные параметры базы данных для подключений `read` и `write` будут объединены из основного массива `mysql`.

Нам нужно помещать элементы в массивы `read` и `write` только в том случае, если мы хотим переопределить значения из основного массива. Таким образом, в данном случае `192.168.1.1` будет использоваться как подключение для чтения, а `192.168.1.2` — как подключение для записи. Учётные данные базы данных, префикс, набор символов и все остальные параметры из основного массива `mysql` будут общими для обоих подключений.

## Длина индексов в MySQL / MariaDB

По умолчанию October CMS использует набор символов `utf8mb4`. Если вы используете версию MySQL старше v5.7.7 или MariaDB старше v10.2.2, вам необходимо вручную настроить длину строк по умолчанию, генерируемую миграциями, чтобы MySQL мог создавать для них индексы. Для настройки длины строк по умолчанию добавьте следующее в файл конфигурации **config/database.php** под ключом `connections.mysql`.

```php
'mysql' => [
    // ...
    'varcharmax' => 191,
],
```

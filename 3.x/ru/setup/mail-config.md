# Конфигурация почты

October CMS предоставляет драйверы для SMTP, Mailgun, SparkPost, Amazon SES и `sendmail`, позволяя быстро начать отправку почты через локальный или облачный сервис по вашему выбору.

Существует два способа настройки почтовых сервисов: через панель администратора в разделе **Настройки → Настройки почты** или путём обновления значений конфигурации по умолчанию. В приведённых примерах мы будем обновлять значения конфигурации в файлах.

::: tip
Экран настроек почты в панели администратора переопределяет настройки, заданные в файлах конфигурации. Нажатие кнопки **Сбросить по умолчанию** обновит настройки почты до актуальных значений. Если вы не нажмёте **Сохранить** в этой форме, настройки будут по-прежнему загружаться из файлов конфигурации.
:::

## Предварительные требования для драйверов

В большинстве случаев вы можете использовать драйвер SMTP, который поддерживается большинством почтовых провайдеров. Однако использование драйверов на основе API зачастую является более простым и быстрым подходом.

### Драйвер Mailgun

Для использования драйвера Mailgun установите транспорт Symfony Mailgun Mailer через Composer.

```bash
composer require symfony/mailgun-mailer symfony/http-client
```

Затем установите параметр `driver` в файле конфигурации `config/mail.php` в значение `mailgun`. После этого убедитесь, что ваш файл конфигурации `config/services.php` содержит следующие параметры:

```php
'mailgun' => [
    'domain' => 'your-mailgun-domain',
    'secret' => 'your-mailgun-key',
    'endpoint' => 'api.mailgun.net', // api.eu.mailgun.net for EU
],
```

### Драйвер Postmark

Для использования драйвера Postmark установите транспорт Symfony Postmark Mailer через Composer.

```bash
composer require symfony/postmark-mailer symfony/http-client
```

Затем установите параметр `default` в файле конфигурации `config/mail.php` вашего приложения в значение postmark. После настройки почтового сервиса по умолчанию убедитесь, что ваш файл конфигурации `config/services.php` содержит следующее.

```php
'postmark' => [
    'token' => env('POSTMARK_TOKEN'),
],
```

### Драйвер SES

Для использования драйвера Amazon SES необходимо сначала установить Amazon AWS SDK для PHP. Вы можете установить эту библиотеку через менеджер пакетов Composer.

```bash
composer require aws/aws-sdk-php
```

Затем установите параметр `driver` в файле конфигурации `config/mail.php` в значение `ses`. После этого убедитесь, что ваш файл конфигурации `config/services.php` содержит следующие параметры:

```php
'ses' => [
    'key' => 'your-ses-key',
    'secret' => 'your-ses-secret',
    'region' => 'ses-region',  // e.g. us-east-1
],
```

## Почта и локальная разработка

При разработке приложения, отправляющего электронную почту, вы, вероятно, не захотите отправлять письма на реальные адреса электронной почты. Существует несколько способов «отключить» фактическую отправку сообщений.

### Драйвер Log

Одно из решений — использовать почтовый драйвер `log` во время локальной разработки. Этот драйвер записывает все сообщения электронной почты в файлы журнала для последующего просмотра. Для получения дополнительной информации о настройке приложения для различных окружений ознакомьтесь с [документацией по конфигурации](../setup/configuration.md).

### Универсальный получатель

Другое решение — задать универсального получателя для всех писем, отправляемых фреймворком. Таким образом, все письма, генерируемые вашим приложением, будут отправляться на указанный адрес, а не на адрес, фактически заданный при отправке сообщения. Это можно сделать с помощью параметра `to` в файле конфигурации `config/mail.php`:

```php
'to' => [
    'address' => 'dev@example.tld',
    'name' => 'Dev Example'
],
```

### Режим имитации отправки

Вы можете динамически отключить отправку почты с помощью метода `Mail::pretend`. Когда почтовый сервис находится в режиме имитации, сообщения записываются в файлы журнала приложения вместо отправки получателю.

```php
Mail::pretend();
```

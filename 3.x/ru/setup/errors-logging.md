# Ошибки и журналирование

Когда вы начинаете использовать October CMS, обработка ошибок и исключений уже настроена для вас. Существует два способа доступа к журналу событий:

1. Журнал событий можно просмотреть в файловой системе, открыв файл `storage/logs/system.log`.
1. Также его можно просмотреть через панель администратора, перейдя в раздел **Настройки → Журнал событий**.

Записи в журнале всегда создаются при отображении страницы ошибки и для определённых [типов исключений](../extend/system/exceptions.md).

## Конфигурация

#### Детализация ошибок

Степень детализации ошибок, отображаемых вашим приложением в браузере, определяется параметром конфигурации `debug` в файле `config/app.php`. По умолчанию детальный вывод ошибок *включён*, что полезно для просмотра подробной информации об ошибках при отладке и устранении неполадок. Когда эта функция отключена, при возникновении проблемы на странице будет отображаться общее сообщение об ошибке.

Для локальной разработки следует установить значение `debug` в `true`. В рабочем окружении это значение всегда должно быть `false`.

```php
/*
|--------------------------------------------------------------------------
| Application Debug Mode
|--------------------------------------------------------------------------
|
| When your application is in debug mode, detailed error messages with
| stack traces will be shown on every error that occurs within your
| application. If disabled, a simple generic error page is shown.
|
*/

'debug' => false,
```

#### Режимы файлов журнала

October CMS поддерживает различные драйверы, включая режимы журналирования `single`, `daily`, `syslog` и `errorlog`. Например, если вы хотите использовать ежедневные файлы журнала вместо одного файла, просто установите значение `default` в файле конфигурации `config/logging.php`:

```php
'default' => env('LOG_CHANNEL', 'daily'),
```

# Структура каталогов

October CMS использует модульную структуру, в которой большинство программных функций находится в каталогах модулей или плагинов.

## Корневой каталог

### Каталог App

Каталог `app` содержит код, специфичный для приложения. Содержимое этого каталога подробнее рассматривается далее в этом разделе. В общих чертах, здесь располагается бизнес-логика, которая не относится к традиционным плагинам. Большинство возможностей плагинов доступно и в этом каталоге.

### Каталог Bootstrap

Каталог `bootstrap` содержит скрипт начальной загрузки app.php, который загружает фреймворк Laravel. В этом каталоге также находится пользовательский автозагрузчик PHP-классов. Как правило, файлы в этом каталоге не следует изменять.

### Каталог Config

Каталог `config` содержит все файлы конфигурации приложения. Каждый файл управляет определённым аспектом работы приложения. Файлы конфигурации можно изменять в соответствии с требованиями вашего приложения. Обновления системы не изменяют файлы конфигурации.

### Каталог Plugins

Каталог `plugins` содержит пакеты, расширяющие базовую функциональность October CMS. Плагины могут модифицировать платформу, добавляя новые возможности. По умолчанию система загружает все плагины, найденные в файловой системе. Определённые плагины можно отключить с помощью параметра конфигурации `system.disable_plugins`.

### Каталог Storage

Каталог `storage` содержит файлы журналов, файлы кэша, сессии и другие файлы, генерируемые October CMS. Он включает несколько подкаталогов:

* `app` — содержит файлы хранилища, специфичные для приложения, такие как медиафайлы, загруженные файлы и автоматически генерируемые ресурсы, например, файлы изменённого размера и объединённые файлы ресурсов.
* `framework` — используется фреймворком Laravel для хранения сгенерированных файлов и кэшей.
* `cms` — используется платформой October CMS для хранения сгенерированных файлов и кэшей.
* `logs` — содержит файлы журналов приложения.
* `temp` — используется для хранения временных файлов приложения.

### Каталог Modules

Каталог `modules` содержит основные пакеты October CMS, предоставляющие базовую функциональность, общую для всей системы. По умолчанию модули загружаются автоматически на основе их наличия в файловой системе. Однако можно указать, какие модули загружать, с помощью параметра конфигурации `system.load_modules`. Для работы приложения как минимум должен быть загружен модуль `system`.

* `system` — определяет базовую функциональность October CMS и является обязательным модулем.
* `cms` — обеспечивает функциональность для отображения фронтенд-темы сайта. Отвечает за маршрутизацию запросов к страницам, отображение страниц и обработку AJAX-запросов.
* `backend` — отвечает за отображение страниц панели администрирования.
* `editor` — предоставляет пользовательский интерфейс для редактирования CMS-шаблонов в панели администрирования.
* `media` — предоставляет пользовательский интерфейс для управления медиафайлами в панели администрирования. Позволяет пользователям загружать медиафайлы, такие как изображения или видеофайлы, и использовать их в других местах, например, в записях блога.
* `tailor` — обеспечивает функциональность Tailor в October CMS.

### Каталог Themes

Каталог `themes` содержит подкаталоги для фронтенд-тем CMS-сайта. Темы CMS включают файлы шаблонов для страниц сайта, макетов, фрагментов, ресурсов и других файлов. Активная тема задаётся с помощью параметра конфигурации `cms.active_theme` и может быть переопределена на странице настроек панели администрирования.

### Каталог Vendor

Каталог `vendor` содержит пакеты, подключённые через Composer. Некоторые плагины также могут включать каталог vendor. Системный каталог vendor имеет приоритет над каталогами vendor отдельных плагинов.

## Каталог App

Каталог `app` содержит файлы, специфичные для приложения, включая контент, ресурсы и бизнес-логику, которая не относится к [традиционным плагинам](../extend/system/plugins.md). Он включает файл сервис-провайдера, загружаемый конфигурацией по умолчанию.

### Каталог Assets

Каталог `app/assets` содержит файлы ресурсов, такие как JavaScript, CSS и файлы изображений. Этот каталог должен быть публично доступен для сайта.

### Каталог Blueprints

Каталог `app/blueprints` содержит файлы [схем контента](../cms/tailor/introduction.md), используемые Tailor.

### Другие каталоги

Вы можете создавать любые каталоги внутри этой директории, как и в плагине, например `models` или `controllers`. Они будут автоматически загружены в пространстве имён `App`. Например, файл **app/models/Customer.php** будет доступен в PHP как `App\Models\Customer`.

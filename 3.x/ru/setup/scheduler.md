# Настройка Планировщика

Для корректной работы запланированных задач добавьте следующее [задание Cron](https://www.cyberciti.biz/faq/how-do-i-add-jobs-to-cron-under-linux-or-unix-oses/) на сервер:

```bash
* * * * * php /october/artisan schedule:run >> /dev/null 2>&1
```

Обязательно замените `/october/artisan` на абсолютный путь к файлу artisan в каталоге установки October CMS. Это задание cron будет вызывать планировщик команд каждую минуту. Затем October CMS проверяет все запланированные задачи и выполняет те, для которых наступило время.

::: tip
При добавлении файла crontab в /etc/cron.d укажите имя пользователя после `* * * * *`:

```bash
* * * * * alice php /october/artisan schedule:run >> /dev/null 2>&1
```
:::

## Настройка обработчиков очередей

При необходимости можно настроить драйвер очередей для обработки [заданий в очереди](../extend/services/queue.md). Драйвер очередей настраивается в файле `config/queue.php`.

Для драйвера очередей на основе базы данных можно настроить задание cron, выполняющее команду, которая обрабатывает первое доступное задание в очереди: `php artisan queue:work --once`.

```bash
* * * * * php /october/artisan queue:work --once >> /dev/null 2>&1
```

В качестве альтернативы можно запустить очередь как фоновый процесс-демон:

```bash
php artisan queue:work
```

## Cron без командной строки

Если ваш хостинг-провайдер не предоставляет доступ к таблице cron, можно вместо этого вызывать публичный URL каждые X минут. Например, если плагин требует выполнения следующей команды каждые 15 минут:

```bash
php artisan campaign:run
```

Для решения этой задачи потребуется написать PHP-код, используя фасад `Artisan` вместе с [файлом маршрутов](../extend/system/routing.md) для создания конечной точки, вызывающей эту команду. Например, файл **routes.php** может содержать следующее:

```php
Route::get('/campaign-run', function () {
    return Artisan::call('campaign:run');
});
```

При открытии URL `/campaign-run` будет вызвана artisan-команда.

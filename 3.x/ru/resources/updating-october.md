# Обновление October CMS

Команда `october:update` запрашивает обновления с сервера October. Она обновляет файлы ядра приложения и плагинов, а затем выполняет миграцию базы данных.

```bash
php artisan october:update
```

## Миграция базы данных

Команда `october:migrate` выполняет миграцию базы данных, создавая таблицы и запуская сценарии заполнения данными, предоставленные системой и [историей версий плагина](../plugin/updates.md). Команду миграции можно запускать многократно — каждая миграция или сценарий заполнения выполняется только один раз, то есть применяются только новые изменения.

```bash
php artisan october:migrate
```

Параметр `--rollback` отменяет все миграции, удаляя таблицы базы данных и данные. Используйте эту команду с осторожностью. Команда [обновления плагина](../resources/installing-packages.md) является полезной альтернативой для отладки отдельного плагина.

```bash
php artisan october:migrate --rollback
```

Параметр `--skip-errors` игнорирует любые исключения, возникающие в процессе миграции. Это может быть полезно в случаях, когда таблицы уже существуют, но информация о версиях всё равно должна быть применена.

```bash
php artisan october:migrate --skip-errors
```

## Обновления из ветки разработки

Чтобы получать самые свежие обновления October CMS, измените настройку минимальной стабильности на `dev`.

```bash
composer config minimum-stability dev
```

Затем укажите ветку `develop` в файле composer.json. Например:

```json
"october/all": "dev-develop",
"october/rain": "dev-develop",
```

Ветка `develop` содержит обновления, которые ещё не опубликованы в стабильном канале. В ней могут быть последние исправления ошибок и новые функции, но в то же время она может содержать незавершённые наработки. Использование обновлений из ветки разработки не рекомендуется для рабочих окружений.

::: tip
Обозначение `dev-develop` может также применяться к некоторым плагинам и темам.
:::

## Руководство по обновлению с v1 и v2

Если вы обновляетесь с October CMS 2.0, ознакомьтесь со следующими руководствами перед выполнением обновления.

- [Руководство по обновлению до October CMS v3.0](https://octobercms.com/support/article/rn-30)
- [Стабильный релиз October CMS v3.1](https://octobercms.com/support/article/rn-32)

Если вы обновляетесь с October CMS 1.0, ознакомьтесь с этими руководствами, прежде чем переходить к указанным выше.

- [Руководство по обновлению до October CMS v2.0](https://octobercms.com/support/article/rn-13)
- [Стабильный релиз October CMS v2.1](https://octobercms.com/support/article/rn-27)

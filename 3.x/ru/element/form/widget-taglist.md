# Поле Tag List

Виджет формы `taglist` рендерит поле для ввода списка тегов.

```yaml
tags:
    type: taglist
    separator: space
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**mode** | управляет форматом возвращаемого значения: `string`, `array` или `relation`. По умолчанию: `string`
**separator** | разделяет теги указанным символом: `comma` или `space`. По умолчанию: `comma`
**customTags** | разрешает пользователю вводить произвольные теги вручную. По умолчанию: `true`
**options** | задаёт массив предопределённых вариантов.
**optionsMethod** | задаёт имя метода для предопределённых вариантов, определённого в модели или как статический метод, например `Class::method`. Установите в `true` для использования метода модели **get*Field*Options**.
**nameFrom** | при использовании режима relation — имя атрибута модели для отображения названия тега. По умолчанию: `name`
**useKey** | использовать ключ вместо значения для сохранения и чтения данных. По умолчанию: `false`
**maxItems** | максимальное количество тегов, которые можно добавить или выбрать.

Список тегов поддерживает те же методы определения вариантов, что и [тип поля dropdown](./field-dropdown.md).

```yaml
tags:
    type: taglist
    options:
        - Red
        - Blue
        - Orange
```

Вы можете использовать `mode` со значением **relation**, где имя поля является [отношением многие-ко-многим](../../extend/database/relations.md). Это автоматически будет получать и назначать теги через отношение. Если поддерживаются произвольные теги, они будут созданы перед назначением.

```yaml
tags:
    type: taglist
    mode: relation
```

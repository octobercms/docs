# Поле Code Editor

`codeeditor` — рендерит текстовый редактор для форматированного кода или разметки. Обратите внимание, что опции могут наследоваться из настроек редактора кода, определённых для администратора в панели управления.

```yaml
css_content:
    type: codeeditor
    size: huge
    language: html
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**language** | язык кода, например: php, css, javascript, html. По умолчанию: `php`.
**showGutter** | показывает боковую панель с номерами строк. По умолчанию: `true`.
**wrapWords** | переносит длинные строки на новую строку. По умолчанию: `true`.
**fontSize** | размер шрифта текста. По умолчанию: 12.

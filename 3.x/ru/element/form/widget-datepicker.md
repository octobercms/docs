# Поле Date Picker

`datepicker` — рендерит текстовое поле для выбора даты и времени.

```yaml
published_at:
    label: Published
    type: datepicker
    mode: date
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**mode** | ожидаемый результат: `date`, `datetime` или `time`. По умолчанию: `datetime`.
**format** | явный формат отображения даты. Например: `Y-m-d`
**minDate** | минимальная/самая ранняя дата, которую можно выбрать.
**maxDate** | максимальная/самая поздняя дата, которую можно выбрать.
**yearRange** | количество лет для отображения в обе стороны, или массив верхней/нижней границы, например `[1900,2015]`. По умолчанию: `10`.
**disableDays** | дни, которые нельзя выбрать: число от воскресенья (`0`) до субботы (`6`) или конкретная дата (`2024-10-01`).
**firstDay** | первый день недели. По умолчанию: `0` (воскресенье).
**twelveHour** | отображать 12-часовой формат при выборе времени. По умолчанию: `false`
**hoursOnly** | разрешает выбор только часов при выборе времени. По умолчанию: `false`
**showWeekNumber** | показывать номера недель в начале строки. По умолчанию: `false`
**useTimezone** | конвертировать дату и время из часового пояса, указанного в настройках панели управления.

Используйте режим `time` для отображения выбора времени и переключайте 24-часовой или 12-часовой формат с помощью свойства `twelveHour`.

```yaml
birth_time:
    label: Time Born
    type: datepicker
    mode: time
    twelveHour: true
```

Для упрощённого выбора времени используйте режим `hoursOnly` для отображения выбора часов без минут.

```yaml
birth_hour:
    label: Hour Born
    type: datepicker
    mode: time
    hoursOnly: true
```

Свойство `disableDays` может использоваться для отключения выбора определённых дней.

```yaml
booking_date:
    label: Booking Date
    type: datepicker
    mode: date
    disableDays:
        - 0 # Sundays
        - 6 # Saturdays
        - "2023-08-10" # Specific date
```

Свойство `disableDays` также может быть задано как статическая PHP-функция для динамической установки отключённых дней.

```yaml
booking_date:
    type: datepicker
    disableDays: App\Classes\BookingManager::getDisabledBookingDates
```

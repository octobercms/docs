# Поле Number

Поле `number` рендерит однострочное текстовое поле, принимающее только числа.

```yaml
your_age:
    label: Your Age
    type: number
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | определяет значение строки по умолчанию, необязательно.
**comment** | размещает описательный комментарий под полем.
**min** | минимальное значение на стороне клиента, по умолчанию `null`.
**max** | максимальное значение на стороне клиента, по умолчанию `null`.
**step** | шаг инкремента на стороне клиента, по умолчанию `any`.

Вы можете использовать свойства `min` и `max` для ограничения ввода минимальным и максимальным значениями. Следующее определение принимает только ввод от 1 до 100.

```yaml
your_age:
    label: Your Age
    type: number
    min: 1
    max: 100
```

Используйте свойство `step` для управления шагом увеличения или уменьшения числа, по умолчанию значение — **any**.

```yaml
your_age:
    label: Your Age
    type: number
    step: 10
```

## Серверная валидация

Если вы хотите валидировать это поле на стороне сервера при сохранении, чтобы убедиться, что оно числовое. При работе с полями Tailor используйте свойство `validation`.

```yaml
your_age:
    label: Your Age
    type: number
    validation: numeric
```

При работе с моделями используйте свойство `$rules` в вашей модели следующим образом.

```php
public $rules = [
    'your_age' => ['numeric'],
];
```

Подробнее о валидации моделей см. в [статье о сервисе валидации](../../extend/services/validation.md#rule-numeric).

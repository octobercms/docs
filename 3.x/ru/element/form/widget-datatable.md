# Поле Data Table

`datatable` — рендерит редактируемую таблицу записей, отформатированную в виде сетки. Содержимое ячеек может редактироваться прямо в сетке, что позволяет управлять несколькими строками и столбцами информации.

```yaml
data:
    type: datatable
    adding: true
    deleting: true
    columns: []
    recordsPerPage: false
    searching: false
```

::: tip
Для использования с моделью поле должно быть определено в [свойстве jsonable](../../extend/system/models.md) или в любом другом свойстве, поддерживающем хранение в виде массива.
:::

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------ | -----------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**adding** | разрешает добавление записей в таблицу данных. По умолчанию: `true`.
**btnAddRowLabel** | определяет пользовательскую метку для кнопки «Add Row Above».
**btnAddRowBelowLabel** | определяет пользовательскую метку для кнопки «Add Row Below».
**btnDeleteRowLabel** | определяет пользовательскую метку для кнопки «Delete Row».
**columns** | массив, представляющий конфигурацию столбцов таблицы данных. См. раздел *Конфигурация столбцов* ниже.
**deleting** | разрешает удаление записей из таблицы данных. По умолчанию: `true`.
**dynamicHeight** | если `true`, высота таблицы данных будет увеличиваться или уменьшаться в зависимости от добавленных записей, до максимального размера, определённого значением конфигурации `height`. По умолчанию: `false`.
**fieldName** | определяет пользовательское имя поля для использования в POST-данных, отправляемых из таблицы данных. Оставьте пустым для использования псевдонима поля по умолчанию.
**height** | высота таблицы данных в пикселях. Если установлено `false`, таблица данных растянется для заполнения контейнера поля.
**keyFrom** | атрибут данных, используемый как ключ каждой записи. Обычно должен быть установлен в `id`. Поддерживает только целочисленные значения.
**postbackHandlerName** | указывает имя AJAX-обработчика, с которым будет отправлено содержимое таблицы данных. При значении `null` (по умолчанию) имя обработчика будет автоматически определено из имени запроса, используемого формой, содержащей таблицу данных. Рекомендуется оставлять значение `null`.
**recordsPerPage** | количество записей на странице. Если установлено `false`, пагинация будет отключена.
**searching** | разрешает поиск записей через поле поиска. По умолчанию: `false`.
**toolbar** | массив, представляющий конфигурацию панели инструментов таблицы данных.

#### Конфигурация столбцов

Виджет таблицы данных позволяет задавать столбцы в виде массива через переменную конфигурации `columns`. Каждый столбец должен использовать имя поля в качестве ключа и следующие переменные конфигурации для настройки поля.

Пример:

```yaml
columns:
    id:
        type: string
        title: ID
        validation:
            integer:
                message: Please enter a number
    name:
        type: string
        title: Name
```

Опция | Описание
------ | -----------
**type** | тип ввода для ячеек этого столбца. Должен быть одним из: `string`, `checkbox`, `dropdown` или `autocomplete`.
**options** | используется только для столбцов `dropdown` и `autocomplete`. Ключ массива определяет значение опции, значение массива определяет метку опции. См. раздел AJAX-обработчики ниже.
**readOnly** | является ли столбец доступным только для чтения. По умолчанию: `false`.
**title** | определяет заголовок столбца.
**validation** | массив, определяющий валидацию содержимого ячеек столбца. См. раздел *Валидация столбцов* ниже.
**width** | определяет ширину столбца в пикселях.

#### Валидация столбцов

Ячейки столбцов могут быть валидированы по следующим типам валидации. Валидация должна быть указана как массив, где тип валидации используется как ключ, а необязательное сообщение указывается как атрибут `message` для этой валидации.

Валидация | Описание
---------- | -----------
**float** | Проверяет, что данные являются числом с плавающей точкой. Может быть указан необязательный булевый атрибут `allowNegative`, разрешающий отрицательные числа с плавающей точкой.
**integer** | Проверяет, что данные являются целым числом. Может быть указан необязательный булевый атрибут `allowNegative`, разрешающий отрицательные целые числа.
**length** | Проверяет, что данные имеют определённую длину. Должны быть указаны целочисленные атрибуты `min` и `max`, представляющие минимальное и максимальное количество символов.
**regex** | Проверяет данные по регулярному выражению. Должен быть указан строковый атрибут `pattern`, определяющий регулярное выражение для проверки данных.
**required** | Проверяет, что данные должны быть введены перед сохранением.

#### AJAX-обработчики

Для столбцов типа `dropdown` или `autocomplete` список доступных опций может быть предоставлен через AJAX-обработчик, определённый в модели.

Обработчик должен следовать соглашению об именовании `getFieldNameDataTableOptions()`, где `FieldName` соответствует имени поля, определённому в конфигурации формы.

Метод должен возвращать ассоциативный массив, где ключ массива используется как сохраняемое значение, а значение массива — как отображаемая метка в таблице данных.

Например, для поля с именем **country** используется метод `getCountryDataTableOptions`.

```php
public function getCountryDataTableOptions()
{
    return Country::pluck('name', 'code')->all();
}
```

Это автоматически заполнит опции для поля `country` в DataTable.

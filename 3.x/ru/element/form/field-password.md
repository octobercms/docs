# Поле Password

Поле `password` рендерит однострочное поле пароля и используется для захвата конфиденциальных значений, таких как пароли.

```yaml
user_password:
    label: Password
    type: password
```

Обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**title** | заголовок поля формы.
**comment** | размещает описательный комментарий под полем.

::: tip
Обратите внимание на [виджет формы Sensitive](./widget-sensitive.md) для поля, которое может захватывать и отображать конфиденциальные значения.
:::

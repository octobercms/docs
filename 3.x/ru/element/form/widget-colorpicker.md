# Поле Color Picker

`colorpicker` — рендерит элементы управления для выбора шестнадцатеричного значения цвета.

```yaml
color:
    label: Background
    type: colorpicker
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**availableColors** | список доступных цветов в виде массива.
**allowEmpty** | разрешает пустое значение. По умолчанию: `false`
**allowCustom** | разрешает выбор произвольного цвета. По умолчанию: `true`
**showAlpha** | отображает ползунок прозрачности и устанавливает 8-значный hex-код. По умолчанию: `false`
**showInput** | отображает текстовое поле ввода рядом с палитрой и отключает доступные цвета. По умолчанию: `false`

Вы можете определить предустановленные цвета, задав свойство `availableColors` как массив hex-цветов. Свойство `allowCustom` может использоваться для отключения выбора произвольного цвета, и оно необязательно.

```yaml
color:
    label: Background
    type: colorpicker
    availableColors: ['#000000', '#111111', '#222222']
    allowCustom: false
```

::: tip
Если поле `availableColors` не определено в YAML-файле, палитра использует набор из 20 цветов по умолчанию.
:::

Используйте свойство `showAlpha` для включения прозрачности в выбор цвета — это создаёт 8-значное hex-значение.

```yaml
color:
    label: Background
    type: colorpicker
    showAlpha: true
```

Используйте свойство `showInput` для отображения текстового поля ввода рядом с цветом. В этом режиме доступные цвета отключаются, а выбор и ввод произвольного hex-цвета становятся основной задачей.

```yaml
color:
    label: Primary Color
    type: colorpicker
    showInput: true
```

## Динамические доступные цвета

Доступные цвета могут быть получены из класса модели, если задать `availableColors` как имя метода, объявленного в классе модели. Этот метод должен возвращать массив hex-цветов в том же формате, что и в примере выше. Первый аргумент метода — имя поля, второй — текущее значение поля, третий — текущий объект данных всей формы.

```yaml
color:
    label: Background
    type: colorpicker
    availableColors: myColorList
```

Предоставление доступных цветов в классе модели:

```php
public function myColorList($fieldName, $value, $formData)
{
    return ['#000000', '#111111', '#222222']
}
```

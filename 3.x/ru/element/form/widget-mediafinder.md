# Поле Media Finder

`mediafinder` — рендерит поле для выбора элемента из библиотеки медиа-менеджера. При раскрытии поля отображается медиа-менеджер для поиска файла. Результат выбора — строка с относительным путём к файлу.

```yaml
whitepaper_file:
    label: Whitepaper PDF
    type: mediafinder
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**mode** | ожидаемый тип файла: `file`, `folder` или `image`. По умолчанию: `file`.
**imageWidth** | при использовании типа image превью изображения будет отображаться с этой шириной, необязательно.
**imageHeight** | при использовании типа image превью изображения будет отображаться с этой высотой, необязательно.
**maxItems** | максимальное количество элементов, которые можно выбрать.
**thumbOptions** | дополнительные [опции масштабирования](../../extend/services/resizer.md) для генерации миниатюры, или `false` для отключения генерации миниатюр.

Установите `mode` в **image** для отображения превью выбранного изображения.

```yaml
background_image:
    label: Background Image
    type: mediafinder
    mode: image
```

Вы можете установить `mode` в **folder** для выбора только пути к медиа-папке.

```yaml
media_folder:
    label: Media Folder
    type: mediafinder
    mode: folder
```

::: tip
В отличие от [виджета формы File Upload](./widget-fileupload.md), виджет формы Media Finder хранит данные в виде строки, представляющей путь к медиа-файлам, выбранным в медиа-библиотеке. Он должен быть связан с обычным атрибутом вашей модели.
:::

## Выбор нескольких элементов

Media Finder автоматически определяет, можно ли выбрать несколько элементов, на основе [атрибута jsonable](../../extend/system/models.md) в модели, что является обязательным условием для хранения нескольких элементов.

Вы можете ограничить количество выбираемых элементов с помощью свойства `maxItems`.

```yaml
media_gallery:
    label: Image
    type: mediafinder
    mode: image
    maxItems: 10
```

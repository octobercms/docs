# Поле File Upload

`fileupload` — рендерит загрузчик файлов для изображений или обычных файлов.

```yaml
avatar:
    label: Avatar
    type: fileupload
    mode: image
    imageHeight: 260
    imageWidth: 260
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**mode** | ожидаемый тип файла: file или image. По умолчанию: `image`
**size** | для множественной загрузки — размер контейнера. Доступные варианты: tiny, small, large, huge, giant. По умолчанию: `large`
**imageWidth** | при использовании типа image изображение будет масштабировано до этой ширины, необязательно.
**imageHeight** | при использовании типа image изображение будет масштабировано до этой высоты, необязательно.
**fileTypes** | расширения файлов, принимаемые загрузчиком, необязательно. Например: `zip,txt`
**mimeTypes** | MIME-типы, принимаемые загрузчиком, в виде расширения файла или полного имени, необязательно. Например: `bin,txt`
**maxFilesize** | размер файла в Мб, принимаемый загрузчиком, необязательно. По умолчанию: из значения параметра "upload_max_filesize".
**maxFiles** | максимальное количество файлов, разрешённых к загрузке.
**useCaption** | позволяет задать заголовок и описание для файла. По умолчанию: `true`
**thumbOptions** | дополнительные [опции масштабирования](../../extend/services/resizer.md) для генерации миниатюры, или `false` для отключения генерации миниатюр.
**deferredBinding** | использовать отложенную привязку при загрузке файла, когда доступно. Отключите для немедленного прикрепления файла при загрузке вместо сохранения. По умолчанию: `true`

::: tip
В отличие от [виджета формы Media Finder](./widget-mediafinder.md), виджет формы File Upload использует [файловые вложения базы данных](../../extend/database/attachments.md), поэтому имя поля должно соответствовать атрибуту отношения `attachOne` или `attachMany` в вашей модели.
:::

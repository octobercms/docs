# Поле Sensitive

`sensitive` — рендерит поле пароля с возможностью раскрытия, которое может использоваться для конфиденциальной информации, такой как API-ключи или секреты, значения конфигурации и т.д. Поле sensitive может переключаться между видимым и скрытым состоянием по запросу пользователя.

Поле sensitive, содержащее ранее введённое значение, при загрузке заменяет его значением-заполнителем, предотвращая угадывание значения по длине или копирование. При раскрытии значения оригинальное значение извлекается через AJAX и подставляется в поле.

```yaml
api_secret:
    type: sensitive
    allowCopy: false
    hideOnTabChange: true
```

Поддерживаются и обычно используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя при отображении поля формы пользователю.
**default** | значение по умолчанию (строка), необязательно.
**comment** | пояснительный комментарий под полем.
**mode** | режим отображения виджета: `textarea` или `text`. По умолчанию: `text`
**allowCopy** | добавляет действие «копировать» к полю sensitive, позволяя пользователю скопировать пароль без его раскрытия. По умолчанию: `true`
**hiddenPlaceholder** | задаёт текст-заполнитель, используемый для имитации скрытого, нераскрытого значения. Вы можете изменить его на длинную или короткую строку для эмуляции значений разной длины. По умолчанию: `__hidden__`
**hideOnTabChange** | если true, поле sensitive будет автоматически скрыто при переходе пользователя на другую вкладку или сворачивании браузера. По умолчанию: `true`

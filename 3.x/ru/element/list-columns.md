# Столбцы списка

Столбцы списка — это определения столбцов, используемые списками. На них ссылаются следующие области.

- [Контроллер списков](../extend/lists/list-controller.md)
- [Контроллер отношений](../extend/forms/relation-controller.md)

Все столбцы списка идентифицируются по их индивидуальному свойству **type**.

```yaml
columns:
    mycolumn:
        type: number
        # ...
```

## Свойства столбцов

Для каждого столбца можно указать следующие свойства (где применимо):

Свойство | Описание
------------- | -------------
**label** | имя при отображении столбца списка пользователю.
**type** | определяет, как должен рендериться этот столбец.
**default** | задаёт значение по умолчанию для столбца, если значение пусто.
**searchable** | включает этот столбец в результаты поиска по списку. По умолчанию: `false`.
**invisible** | определяет, скрыт ли этот столбец по умолчанию. По умолчанию: `false`.
**sortable** | определяет, можно ли сортировать по этому столбцу. По умолчанию: `true`.
**sortableDefault** | определяет, сортируется ли этот столбец по умолчанию. Должно использоваться только на одном сортируемом столбце. Поддерживаемые значения: `asc`, `desc`.
**clickable** | если установлено в false, отключает стандартное поведение при клике на столбец. По умолчанию: true.
**select** | определяет пользовательское SQL-выражение select для значения. Если указан `relation`, это ссылается на столбец в связанной таблице базы данных.
**valueFrom** | определяет атрибут модели для использования в качестве исходного значения. Если указан `relation`, это ссылается на атрибут отношения и выполняет жадную загрузку отношения.
**displayFrom** | определяет атрибут модели для использования в качестве отображаемого значения.
**relation** | определяет имя отношения модели как источник, используется с `select` или `valueFrom`.
**relationCount** | отображает количество связанных записей как значение столбца. Должно использоваться с опцией `relation`. По умолчанию: `false`
**relationWith** | выполняет жадную загрузку указанного определения отношения с запросом списка. Полезно для улучшения производительности вложенных выборок столбцов.
**cssClass** | назначает CSS-класс контейнеру столбца.
**headCssClass** | назначает CSS-класс контейнеру заголовка столбца.
**width** | устанавливает ширину столбца, может быть указана в процентах (10%) или пикселях (50px). Может быть один столбец без указанной ширины, он растянется для заполнения доступного пространства.
**align** | определяет выравнивание столбца. Возможные значения: `left`, `right` и `center`.
**permissions** | [разрешения](../extend/backend/permissions.md), которые должен иметь текущий пользователь панели управления для использования столбца. Поддерживает строку для одного разрешения или массив разрешений, из которых достаточно одного для предоставления доступа.
**order** | числовой вес при определении порядка отображения, значение по умолчанию увеличивается на 100 пунктов за столбец.
**after** | поместить этот столбец после другого существующего столбца по имени, используя порядок отображения (+1).
**before** | поместить этот столбец перед другим существующим столбцом по имени, используя порядок отображения (-1).
**tooltip** | добавляет иконку с подсказкой после метки столбца. Подробнее см. ниже.

### Пользовательский выбор значения

Можно изменить исходное и отображаемое значения для каждого столбца. Если вы хотите получить значение столбца из другого столбца, используйте опцию `valueFrom`.

```yaml
other_name:
    label: Something Great
    valueFrom: name
```

Если вы хотите сохранить исходное значение столбца, но отображать другое значение из атрибута модели, используйте опцию `displayFrom`.

```yaml
status_code:
    label: Status
    displayFrom: status_label
```

Это в основном применимо, когда используется [аксессор модели](../extend/database/mutators.md) для изменения отображаемого значения. Это полезно, когда вы хотите отображать одно значение, но сортировать и искать по другому.

```php
public function getStatusLabelAttribute()
{
    return title_case($this->status_code);
}
```

### Вложенный выбор столбцов

В некоторых случаях имеет смысл получать значение столбца из вложенной структуры данных, например, столбца [отношения модели](../extend/database/relations.md) или [jsonable-массива](../extend/system/models.md). Следующий пример будет искать значение в PHP-эквиваленте `$record->content->title` или `$record->content['title']` соответственно.

```yaml
content[title]:
    name: Title
    sortable: false
```

Единственный недостаток этого подхода — столбец не может использовать опции searchable или sortable. Чтобы сделать столбец доступным для поиска и по причинам производительности, рекомендуется дублировать его значение в локальной таблице базы данных с помощью [событий модели](../extend/database/model.md). В качестве альтернативы вы можете использовать свойство `relation`, описанное далее.

### Прямой SQL-выбор

Свойство `select` позволяет создать столбец с использованием пользовательского выражения select. Здесь работает любое допустимое SQL-выражение SELECT.

```yaml
full_name:
    label: Full Name
    select: concat(first_name, ' ', last_name)
```

### Выбор связанного столбца

Свойство `relation` позволяет отображать связанные столбцы как часть запроса к базе данных, обеспечивая поиск и сортировку по этому столбцу. `relation` устанавливается в имя [отношения модели](../database/relations.md). В следующем примере значение **name** будет преобразовано в атрибут name, найденный в связанной модели (например: `$model->name`).

```yaml
group_name:
    label: Group
    relation: groups
    select: name
```

Для отображения столбца с количеством связанных записей используйте свойство `relationCount`.

```yaml
users_count:
    label: Users
    type: number
    relation: users
    relationCount: true
```

::: warning
Будьте осторожны, не называйте отношения так же, как существующие столбцы базы данных. Например, использование имени `group_id` может нарушить отношение group из-за конфликта имён.
:::

### Подсказка

Свойство `tooltip` улучшает столбцы списка, добавляя информационную иконку в заголовок столбца. При наведении на эту иконку отображается подсказка, предоставляющая дополнительный контекст или детали о столбце. Эта функция помогает предоставить пользователям руководство или пояснения для понимания содержимого столбца.

```yaml
count:
    label: Count
    type: number
    tooltip: Number of users in the group
```

Помимо указания `title` подсказки, вы также можете задать `icon` ([доступные иконки](../element/available-icons.md)) и `placement` (`right`, `bottom`, `left`, значение по умолчанию — `top`) подсказки.

```yaml
count:
    label: Count
    type: number
    tooltip:
        title: Number of users in the group
        placement: bottom
        icon: icon-users
```

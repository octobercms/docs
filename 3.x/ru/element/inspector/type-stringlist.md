# Тип Inspector String List

Тип inspector `stringList` позволяет пользователям вводить списки строк. Редактор открывается во всплывающем окне и отображает текстовую область. Каждая строка текста представляет элемент в результирующем массиве. Необязательный параметр `default` должен содержать массив строк.

```php
public function defineProperties()
{
    return [
        'items' => [
            'title' => 'Items',
            'type' => 'stringList',
            'default' => ['String 1', 'String 2']
        ]
    ];
}
```

Генерируемый вывод — массив значений, например:

```json
"items": ["String 1", "String 2", "String 3"]
```

Обычно используются следующие [значения конфигурации](../inspector-types.md).

Свойство | Описание
------------- | -------------
**title** | заголовок свойства.
**description** | краткое описание свойства, необязательно.
**default** | значение по умолчанию (массив), необязательно.

# Доступные иконки

October CMS поставляется со своей собственной библиотекой иконок, а также включает сторонние библиотеки для быстрого и удобного поиска подходящей иконки.

## Phosphor Icons

[Набор иконок Phosphor](https://phosphoricons.com/) доступен для использования в панели администрирования. Эта библиотека предоставляет гибкую коллекцию иконок для повседневного использования.

```html
<i class="ph ph-laptop"></i>
```

При использовании в определении иконки имя иконки содержит оба префикса `ph` и `ph-`.

```yaml
icon: ph ph-laptop
```

## October Icons

**Набор иконок October** — это пользовательская библиотека иконок с иконками различных типов. Набор в основном используется основными функциями и может время от времени обновляться.

```html
<i class="icon-october"></i>
```

При использовании в определении иконки имя иконки содержит только префикс `icon-`.

```yaml
icon: icon-october
```

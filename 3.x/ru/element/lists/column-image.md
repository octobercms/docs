# Столбец Image

Столбец `image` отображает столбец с изображением и возможностью масштабирования вывода.

```yaml
avatar:
    label: Avatar
    type: image
```

Поддерживаются следующие свойства.

Свойство | Описание
------------- | -------------
**sortable** | отключает сортировку столбца. По умолчанию: `false`
**width** | ширина миниатюры изображения, необязательно.
**height** | высота миниатюры изображения, необязательно.
**options** | опции [масштабирования изображений](../../extend/services/resizer.md).
**limit** | максимальное количество отображаемых изображений. По умолчанию: `3`

Используйте свойство `sortable` для отключения сортировки.

```yaml
avatar:
    label: Avatar
    type: image
    sortable: false
```

Используйте свойства `width` и `height` для указания пользовательского размера изображения.

```yaml
avatar:
    label: Avatar
    type: image
    width: 150
    height: 150
```

Используйте свойство `options` для указания опций масштабирования.

```yaml
avatar:
    label: Avatar
    type: image
    options:
        quality: 80
```

Подробнее о поддерживаемых опциях см. в [статье о масштабировании изображений](../../extend/services/resizer.md).

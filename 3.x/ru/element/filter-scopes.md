# Области фильтрации

Области фильтрации — это определения областей, используемые фильтрами, часто совместно со списком. Подобно столбцам списка, на них ссылаются следующие области:

- [Контроллер списков](../extend/lists/list-controller.md)
- [Контроллер отношений](../extend/forms/relation-controller.md)

Все области фильтрации идентифицируются по их индивидуальному свойству **type**.

```yaml
scopes:
    myscope:
        type: date
        # ...
```

## Свойства областей

Для каждой области можно указать следующие свойства (где применимо).

Свойство | Описание
------------- | -------------
**label** | имя при отображении области фильтрации пользователю.
**type** | определяет, как должна отображаться эта область. По умолчанию: `group`.
**conditions** | включает или отключает функции условий или задаёт необработанное условие where для применения к каждому условию, подробнее см. определение типа области.
**modelClass** | класс модели для использования как источника данных и ссылки для вызова локальных методов.
**modelScope** | задаёт метод [области запроса модели](../extend/database/model.md), определённый в **модели списка**, для применения к запросу списка. Первый аргумент будет содержать объект запроса (как в обычном методе области), а второй аргумент — определение области, включая её заполненные значения.
**options** | опции для использования при фильтрации по нескольким элементам, предоставленные как массив.
**optionsMethod** | запрашивает опции из имени метода, определённого в модели или как статический метод, например `Class::method`.
**emptyOption** | необязательная метка для намеренного пустого выбора.
**default** | значение по умолчанию для фильтра: массив, строка или целое число в зависимости от значения фильтра.
**permissions** | [разрешения](../extend/backend/permissions.md), которые должен иметь текущий пользователь панели управления для использования области фильтрации. Поддерживает строку для одного разрешения или массив разрешений, из которых достаточно одного для предоставления доступа.
**dependsOn** | строка или массив имён других областей, от которых зависит эта область. При изменении других областей эта область будет сброшена.
**nameFrom** | имя атрибута модели, используемого для отображения метки фильтра. По умолчанию: `name`.
**valueFrom** | определяет атрибут модели для использования в качестве исходного значения. По умолчанию берётся из имени области.
**order** | числовой вес при определении порядка отображения, значение по умолчанию увеличивается на 100 пунктов за область.
**after** | поместить эту область после другой существующей области по имени, используя порядок отображения (+1).
**before** | поместить эту область перед другой существующей областью по имени, используя порядок отображения (-1).

### Применение областей модели

Большинство фильтров применяют свои ограничения с использованием разумных значений по умолчанию. Свойство `modelScope` может использоваться для применения пользовательских ограничений к запросу фильтра с помощью [определения метода области модели](../extend/database/model.md).

```yaml
myfilter:
    label: My Filter
    type: group
    modelScope: applyMyFilter
```

В приведённом примере мы ожидаем отношение на первичной модели с именем **myfilter** и метод **scopeApplyMyFilter**, определённый на связанной модели. Второй аргумент содержит определение области, включая её заполненные значения.

```php
public function scopeApplyMyFilter($query, $scope)
{
    return $query->whereIn('my_filter_attribute', (array) $scope->value);
}
```

Свойство `modelScope` также может быть определено как статический метод PHP-класса (`Class::method`).

```yaml
myfilter:
    label: My Filter
    type: group
    modelScope: "App\MyCustomClass::applyMyFilter"
```

В этом примере метод должен быть объявлен статически на указанном классе.

```php
namespace App;

class MyCustomClass
{
    public static function applyMyFilter($query, $scope)
    {
        return $query->whereIn('my_filter_attribute', (array) $scope->value);
    }
}
```

### Зависимости областей

Свойство `dependsOn` позволяет связывать несколько фильтров вместе. При изменении зависимости область фильтрации сбрасывается для применения новых условий. Рассмотрим следующий пример двух определений областей.

```yaml
country:
    label: Country
    type: group

state:
    label: State
    type: group
    dependsOn: country
    optionsMethod: getCityOptionsForFilter
```

Область state зависит от значения области country, и опции фильтруются в PHP с помощью метода **getCityOptionsForFilter**. Первый аргумент этого метода будет содержать полный набор определений областей, включая их текущие значения.

```php
public function getCityOptionsForFilter($scopes = null)
{
    if ($scopes->country && ($countryIds = $scopes->country->value)) {
        return self::whereIn('country_id', $countryIds)->lists('name', 'id');
    }

    return self::lists('name', 'id');
}
```

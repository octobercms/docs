# Область Switch

`switch` — используется как переключатель для переключения между двумя предопределёнными условиями или запросами к списку: неопределённое, включено или выключено.

```yaml
is_approved:
    label: Approved
    type: switch
    conditions:
        - is_approved <> true
        - is_approved = true
```

Для фильтра доступны следующие свойства.

Свойство | Описание
------------- | -------------
**default** | установите в `1` или `2`, чтобы фильтр был отмечен по умолчанию. По умолчанию: `0`.
**select** | массив с пользовательскими SQL-выражениями select для фильтра, включённый для случаев, когда условие неопределённое (первый элемент) и отмечено (второй элемент).

Вы можете установить значение `default` для задания значения фильтра по умолчанию. Используйте `0` для выключено, `1` для неопределённого и `2` для включено.

```yaml
is_approved:
    label: Approved
    type: switch
    default: 1
```

# Область Checkbox

`checkbox` — используется как бинарный чекбокс для применения предопределённого условия или запроса к списку, включено или выключено. Используйте 0 для выключено и 1 для включено в качестве значения по умолчанию.

```yaml
is_published:
    label: Hide Published
    type: checkbox
    conditions: is_published <> true
```

Для фильтра доступны следующие свойства.

Свойство | Описание
------------- | -------------
**default** | установите в true, чтобы фильтр был отмечен по умолчанию. По умолчанию: `false`.
**conditions** | пользовательское SQL-выражение select для фильтра.

Вы можете установить значение `default`, чтобы фильтр был отмечен по умолчанию.

```yaml
is_published:
    label: Hide Published
    type: checkbox
    default: 1
```

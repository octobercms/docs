# Хеширование и шифрование

## Конфигурация

При первой установке October для вас должен был быть сгенерирован случайный ключ. Вы можете убедиться в этом, проверив параметр `key` в конфигурационном файле `config/app.php`. Если ключ остаётся неизменённым, вам следует установить его в случайную строку длиной 32 символа. Если это значение не установлено должным образом, все зашифрованные значения будут небезопасны.

## Хеширование

Фасад `Hash` предоставляет безопасное хеширование Bcrypt для хранения паролей пользователей. Bcrypt является отличным выбором для хеширования паролей, потому что его «фактор нагрузки» настраивается, а это значит, что время, необходимое для генерации хеша, может быть увеличено по мере роста мощности оборудования.

Вы можете хешировать пароль, вызвав метод `make` фасада `Hash`:

```php
$user = new User;
$user->password = Hash::make('mypassword');
$user->save();
```

В качестве альтернативы модели могут реализовать [трейт Hashable](../database/traits.md) для автоматического хеширования атрибутов.

#### Проверка пароля по хешу

Метод `check` позволяет вам проверить, что данная строка открытого текста соответствует данному хешу.

```php
if (Hash::check('plain-text', $hashedPassword)) {
    // The passwords match...
}
```

#### Проверка необходимости повторного хеширования пароля

Функция `needsRehash` позволяет определить, изменился ли фактор нагрузки, используемый хешером, с момента хеширования пароля:

```php
if (Hash::needsRehash($hashed)) {
    $hashed = Hash::make('plain-text');
}
```

## Шифрование

Вы можете зашифровать значение с помощью фасада `Crypt`. Все зашифрованные значения шифруются с использованием OpenSSL и шифра `AES-256-CBC`. Кроме того, все зашифрованные значения подписываются кодом аутентификации сообщения (MAC) для обнаружения любых модификаций зашифрованной строки.

Например, мы можем использовать метод `encrypt` для шифрования секрета и сохранения его в [модели базы данных](../database/model.md):

```php
$user = new User;
$user->secret = Crypt::encrypt('shhh no telling');
$user->save();
```

#### Расшифровка значения

Разумеется, вы можете расшифровать значения с помощью метода `decrypt` фасада `Crypt`. Если значение не может быть правильно расшифровано, например, когда MAC недействителен, будет выброшено исключение `Illuminate\Contracts\Encryption\DecryptException`:

```php
use Illuminate\Contracts\Encryption\DecryptException;

try {
    $decrypted = Crypt::decrypt($encryptedValue);
}
catch (DecryptException $ex) {
    //
}
```

В качестве альтернативы модели могут реализовать [трейт Encryptable](../database/traits.md) для автоматического шифрования и расшифровки атрибутов.

# Формы и HTML

## Введение

October CMS предоставляет различные полезные функции с помощью фасада `Html`, полезные для работы с HTML и формами. Хотя большинство примеров используют язык PHP, все эти возможности напрямую переносятся в [разметку Twig](../../markup/templating.md) с помощью простого преобразования.

```
// PHP
<?= Form::open(..) ?>

// Twig
{{ form_open(...) }}
```

Как вы можете видеть выше, в Twig все функции с префиксом `form_` будут напрямую привязываться к фасаду `Form` и предоставлять доступ к методам с использованием *snake_case*. Смотрите [руководство по разметке](../../markup/function/form.md) для получения дополнительной информации об использовании хелпера форм во фронтенде.

## Открытие формы

Формы могут быть открыты с помощью метода `Form::open`, который принимает массив атрибутов в качестве первого аргумента:

```php
<?= Form::open(['url' => 'foo/bar']) ?>
    //
<?= Form::close() ?>
```

По умолчанию будет использоваться метод `POST`, однако вы можете указать другой метод:

```php
Form::open(['url' => 'foo/bar', 'method' => 'put'])
```

::: tip
Поскольку HTML-формы поддерживают только `POST` и `GET`, методы `PUT` и `DELETE` будут имитироваться путём автоматического добавления скрытого поля `_method` в вашу форму.
:::

Вы также можете передать обычные HTML-атрибуты:

```php
Form::open(['url' => 'foo/bar', 'class' => 'pretty-form'])
```

Если ваша форма будет принимать загрузку файлов, добавьте опцию `files` в ваш массив:

```php
Form::open(['url' => 'foo/bar', 'files' => true])
```

Вы также можете открывать формы, указывающие на методы обработчиков в ваших страницах или компонентах:

```php
Form::open(['request' => 'onSave'])
```

#### Формы с поддержкой AJAX

Аналогично, формы с поддержкой AJAX могут быть открыты с помощью метода `Form::ajax`, где первый аргумент — имя метода обработчика:

```php
Form::ajax('onSave')
```

Второй аргумент `Form::ajax` должен содержать атрибуты:

```php
Form::ajax('onSave', ['confirm' => 'Are you sure?'])
```

Вы также можете передать фрагменты для обновления в виде другого массива:

```php
Form::ajax('onSave', ['update' => [
        'control-panel' => '#controlPanel',
        'layout/sidebar' => '#layoutSidebar'
    ]
])
```

::: tip
Большинство [data-атрибутов из AJAX-фреймворка](../../cms/ajax/attributes-api.md) доступны здесь путём удаления префикса `data-request-`.
:::

## Токены формы

#### Защита от CSRF

Если у вас [включена защита](../../setup/configuration.md), использование метода `Form::open` с `POST`, `PUT` или `DELETE` автоматически добавит CSRF-токен в вашу форму как скрытое поле. Альтернативно, если вы хотите сгенерировать HTML для скрытого поля CSRF, вы можете использовать метод `token`:

```php
<?= Form::token() ?>
```

#### Ключ сессии отложенной привязки

Ключ сессии, используемый для [отложенной привязки](../database/relations.md), будет добавлен в каждую форму как скрытое поле. Если вы хотите сгенерировать это поле вручную, вы можете использовать метод `sessionKey`:

```php
<?= Form::sessionKey() ?>
```

## Привязка формы к модели

#### Открытие формы модели

Вы можете захотеть заполнить форму на основе содержимого модели. Для этого используйте метод `Form::model`:

```php
<?= Form::model($user, ['id' => 'userForm']) ?>
```

Теперь, когда вы генерируете элемент формы, например текстовое поле, значение модели, соответствующее имени поля, будет автоматически установлено в качестве значения поля. Так, например, для текстового поля с именем `email` атрибут `email` модели пользователя будет установлен в качестве значения. Если в данных сессии (flash data) есть элемент, соответствующий имени поля ввода, он будет иметь приоритет над значением модели. Приоритет выглядит следующим образом:

1. Данные сессии (старый ввод)
2. Явно переданное значение
3. Данные атрибута модели
4. Существующее значение из обратной отправки

Это позволяет быстро создавать формы, которые не только привязываются к значениям модели, но и легко перезаполняются при ошибке валидации на сервере. Вы можете вручную получить доступ к этим значениям с помощью `Form::value`:

```php
<input type="text" name="name" value="<?= Form::value('name') ?>" />
```

Вы можете передать значение по умолчанию в качестве второго аргумента:

```php
<?= Form::value('name', 'John Travolta') ?>
```

::: warning
При использовании `Form::model` обязательно закройте форму с помощью `Form::close`!
:::

## Метки

#### Генерация элемента метки

```php
<?= Form::label('email', 'E-Mail Address') ?>
```

#### Указание дополнительных HTML-атрибутов

```php
<?= Form::label('email', 'E-Mail Address', ['class' => 'awesome']) ?>
```

::: tip
После создания метки любой элемент формы, созданный с именем, совпадающим с именем метки, автоматически получит ID, совпадающий с именем метки.
:::

## Текстовые поля

#### Генерация текстового поля

```php
<?= Form::text('username') ?>
```

#### Указание значения по умолчанию

```php
<?= Form::text('email', 'emailaddress@example.tld') ?>
```

::: tip
Методы **hidden** и **textarea** имеют такую же сигнатуру, как и метод **text**.
:::

#### Генерация поля пароля

```php
<?= Form::password('password') ?>
```

#### Генерация других полей ввода

```php
<?= Form::email($name, $value = null, $attributes = []) ?>
<?= Form::file($name, $attributes = []) ?>
```

## Чекбоксы и радиокнопки

#### Генерация чекбокса или радиокнопки

```php
<?= Form::checkbox('name', 'value') ?>

<?= Form::radio('name', 'value') ?>
```

#### Генерация отмеченного чекбокса или радиокнопки

```php
<?= Form::checkbox('name', 'value', true) ?>

<?= Form::radio('name', 'value', true) ?>
```

## Числовое поле

#### Генерация числового поля

```php
<?= Form::number('name', 'value') ?>
```

## Файловое поле

#### Генерация файлового поля

```php
<?= Form::file('image') ?>
```

> **Примечание**: Форма должна быть открыта с параметром `files`, установленным в `true`.

## Выпадающие списки

#### Генерация выпадающего списка

```php
<?= Form::select('size', ['L' => 'Large', 'S' => 'Small']) ?>
```

#### Генерация выпадающего списка с выбранным значением по умолчанию

```php
<?= Form::select('size', ['L' => 'Large', 'S' => 'Small'], 'S') ?>
```

#### Генерация сгруппированного списка

```php
<?= Form::select('animal', [
    'Cats' => ['leopard' => 'Leopard'],
    'Dogs' => ['spaniel' => 'Spaniel'],
]) ?>
```

#### Генерация выпадающего списка с диапазоном

```php
<?= Form::selectRange('number', 10, 20) ?>
```

#### Генерация выпадающего списка с диапазоном, выбранным значением и пустой опцией

```php
<?= Form::selectRange('number', 10, 20, 2, ['emptyOption' => 'Choose...']) ?>
```

#### Генерация списка с названиями месяцев

```php
<?= Form::selectMonth('month') ?>
```

#### Генерация списка с названиями месяцев, выбранным значением и пустой опцией

```php
<?= Form::selectMonth('month', 2, ['emptyOption' => 'Choose month...']) ?>
```

## Кнопки

#### Генерация кнопки отправки

```php
<?= Form::submit('Click Me!') ?>
```

::: tip
Нужно создать элемент кнопки? Попробуйте метод **button**. Он имеет такую же сигнатуру, как и **submit**.
:::

## Пользовательские макросы

#### Регистрация макроса формы

Легко определить собственные хелперы класса Form, называемые «макросами». Вот как это работает. Сначала просто зарегистрируйте макрос с указанным именем и Closure:

```php
Form::macro('myField', function() {
    return '<input type="awesome">';
})
```

Теперь вы можете вызвать ваш макрос по его имени:

#### Вызов пользовательского макроса формы

```php
<?= Form::myField() ?>
```

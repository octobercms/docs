# Запросы и ввод

## Базовый ввод

Вы можете получить доступ ко всему пользовательскому вводу с помощью нескольких простых методов. Вам не нужно беспокоиться о HTTP-методе запроса при использовании фасада `Input`, так как доступ к вводу осуществляется одинаково для всех методов. Глобальная [вспомогательная функция](./helpers.md) `input` является псевдонимом для `Input::get`.

#### Получение значения ввода

```php
$name = Input::get('name');

$name = input('name');
```

#### Получение значения по умолчанию, если значение ввода отсутствует

```php
$name = Input::get('name', 'Sally');
```

#### Определение наличия значения ввода

```php
if (Input::has('name')) {
    //
}
```

#### Получение всего ввода запроса

```php
$input = Input::all();
```

#### Получение только части ввода запроса

```php
$input = Input::only('username', 'password');

$input = Input::except('credit_card');
```

При работе с формами с «массивным» вводом вы можете использовать точечную нотацию для доступа к массивам:

```php
$input = Input::get('products.0.name');
```

::: tip
Некоторые JavaScript-библиотеки, такие как Backbone, могут отправлять ввод в приложение в формате JSON. Вы можете получить доступ к этим данным через `Input::get` как обычно.
:::

## Cookies

По умолчанию все cookies, созданные October CMS, зашифрованы и подписаны кодом аутентификации, что означает, что они будут считаться недействительными, если были изменены клиентом. Cookies, перечисленные в конфигурационном ключе `system.unencrypt_cookies`, не будут зашифрованы.

#### Получение значения cookie

```php
$value = Cookie::get('name');
```

#### Прикрепление нового cookie к ответу

```php
$response = Response::make('Hello World');

$response->withCookie(Cookie::make('name', 'value', $minutes));
```

#### Постановка cookie в очередь для следующего ответа

Если вы хотите установить cookie до создания ответа, используйте метод `Cookie::queue`. Cookie будет автоматически прикреплён к финальному ответу вашего приложения.

```php
Cookie::queue($name, $value, $minutes);
```

#### Создание cookie с бесконечным сроком действия

```php
$cookie = Cookie::forever('name', 'value');
```

#### Обработка cookies без шифрования

Если вы не хотите, чтобы некоторые cookies шифровались или расшифровывались, вы можете указать их в конфигурации. Это полезно, например, когда вы хотите передавать данные с фронтенда на серверный бэкенд через cookies и наоборот.

Добавьте имена cookies, которые не должны шифроваться или расшифровываться, в параметр `unencrypt_cookies` в конфигурационном файле `config/system.php`.

```php
'unencrypt_cookies' => [
    'my_cookie',
],
```

Альтернативно для плагинов вы можете добавить их динамически из `Plugin.php` вашего плагина.

```php
public function boot()
{
    Config::push('system.unencrypt_cookies', 'my_cookie');
}
```

## Старый ввод

Вам может потребоваться сохранить ввод от одного запроса до следующего. Например, вам может понадобиться повторно заполнить форму после проверки на ошибки валидации.

#### Сохранение ввода в сессии

```php
Input::flash();
```

#### Сохранение только части ввода в сессии

```php
Input::flashOnly('username', 'email');

Input::flashExcept('password');
```

Поскольку вы часто будете хотеть сохранить ввод вместе с перенаправлением на предыдущую страницу, вы можете легко цепочить сохранение ввода к перенаправлению.

```php
return Redirect::to('form')->withInput();

return Redirect::to('form')->withInput(Input::except('password'));
```

::: tip
Вы можете сохранять другие данные между запросами, используя класс [Session](./session.md).
:::

#### Получение старых данных

Получение отдельного значения ввода.

```php
Input::old('username');
```

Получение всех старых значений ввода.

```php
$data = Input::old();
```

## Файлы

Вы можете получить загруженные файлы из запроса, используя метод `file` фасада `Input` или глобальный хелпер `files()`.

```php
$file = Input::file('photo');

$file = files('photo');
```

Чтобы определить, присутствует ли файл в запросе, используйте метод `hasFile`.

```php
if (Input::hasFile('photo')) {
    //
}
```

Помимо проверки наличия файла, вы можете проверить, что не было проблем с загрузкой файла, с помощью метода isValid.

```php
if ($file->isValid()) {
    //
}
```

Возвращённый объект файла имеет множество методов, связанных с загруженным файлом.

Имя метода | Назначение
------------- | -------------
**move($destinationPath, $fileName)** | Перемещает загруженный файл в локальный путь
**store($folder, $disk)** | Сохраняет файл с помощью [сервиса хранилища](../../extend/services/storage.md).
**storeAs($folder, $name, $disk)** | Сохраняет файл с определённым именем с помощью [сервиса хранилища](../../extend/services/storage.md).
**extension()** | Угадывает расширение на основе содержимого файла
**getRealPath()** | Возвращает локальный путь
**getClientOriginalName()** | Возвращает оригинальное имя
**getClientOriginalExtension()** | Возвращает оригинальное расширение
**getSize()** | Возвращает размер
**getMimeType()** | Возвращает MIME-тип

Пример перемещения загруженного файла.

```php
$file->move($destinationPath);

$file->move($destinationPath, $fileName);
```

Примеры [сохранения загруженного файла](./storage.md) в папку (первый аргумент) и на необязательный диск (второй аргумент).

```php
$file->store($folder);

$file->store($folder, 's3');
```

::: warning
Имена папок `media`, `resources`, `uploads` или `public` являются зарезервированными.
:::

Примеры `storeAs` — сохранение файла с пользовательским именем диска (второй аргумент). Метод `storePubliclyAs` сохраняет файл с публичной видимостью.

```php
$file->storeAs($folder, 'avatar');

$file->storeAs($folder, 'avatar', 's3');

$file->storePublicly($folder, 's3');

$file->storePubliclyAs($folder, 'avatar', 's3');
```

Пример получения пути к загруженному файлу.

```php
$path = $file->getRealPath();
```

Пример получения оригинального имени загруженного файла.

```php
$name = $file->getClientOriginalName();
```

Получение расширения загруженного файла.

```php
$extension = $file->getClientOriginalExtension();
```

Получение размера загруженного файла.

```php
$size = $file->getSize();
```

Получение MIME-типа загруженного файла.

```php
$mime = $file->getMimeType();
```

## Информация о запросе

Класс `Request` предоставляет множество методов для проверки HTTP-запроса вашего приложения и расширяет класс `Symfony\Component\HttpFoundation\Request`. Вот некоторые основные возможности.

#### Получение URI запроса

```php
$uri = Request::path();
```

#### Получение метода запроса

```php
$method = Request::method();

if (Request::isMethod('post')) {
    //
}
```

#### Определение соответствия пути запроса шаблону

```php
if (Request::is('admin/*')) {
    //
}
```

#### Получение URL запроса

```php
$url = Request::url();
```

#### Получение сегмента URI запроса

```php
$segment = Request::segment(1);
```

#### Получение заголовка запроса

```php
$value = Request::header('Content-Type');
```

#### Получение значений из $_SERVER

```php
$value = Request::server('PATH_INFO');
```

#### Определение, является ли запрос HTTPS

```php
if (Request::secure()) {
    //
}
```

#### Определение, является ли запрос AJAX

```php
if (Request::ajax()) {
    //
}
```

#### Определение, имеет ли запрос JSON-тип содержимого

```php
if (Request::isJson()) {
    //
}
```

#### Определение, запрашивает ли запрос JSON

```php
if (Request::wantsJson()) {
    //
}
```

#### Проверка запрашиваемого формата ответа

Метод `Request::format` вернёт запрашиваемый формат ответа на основе HTTP-заголовка Accept:

```php
if (Request::format() == 'json') {
    //
}
```

# Хранилище

October CMS предоставляет мощную абстракцию файловой системы благодаря Laravel и замечательному PHP-пакету [Flysystem](https://github.com/thephpleague/flysystem). Интеграция Flysystem обеспечивает простые в использовании драйверы для работы с локальными файловыми системами и Amazon S3. Более того, переключение между этими вариантами хранения невероятно просто, поскольку API остаётся одинаковым для каждой системы.

## Конфигурация

Конфигурационный файл файловой системы расположен в `config/filesystems.php`. В этом файле вы можете настроить все ваши «диски». Каждый диск представляет определённый драйвер хранения и место хранения. Примеры конфигураций для каждого поддерживаемого драйвера включены в конфигурационный файл. Поэтому просто измените конфигурацию, чтобы отразить ваши предпочтения и учётные данные хранения.

Конечно, вы можете настроить столько дисков, сколько хотите, и даже иметь несколько дисков, использующих один и тот же драйвер.

#### Локальный драйвер

При использовании драйвера `local` обратите внимание, что все файловые операции выполняются относительно директории `root`, определённой в вашем конфигурационном файле. По умолчанию это значение установлено в директорию `storage/app`. Поэтому следующий метод сохранит файл в `storage/app/file.txt`:

```php
Storage::disk('local')->put('file.txt', 'Contents');
```

#### Требования к другим драйверам

Перед использованием драйвера S3 вам необходимо установить пакет Flysystem S3 через менеджер пакетов Composer.

```bash
composer require league/flysystem-aws-s3-v3 "^3.0"
```

Конфигурационная информация драйвера S3 находится в вашем конфигурационном файле `config/filesystems.php`. Этот файл содержит пример массива конфигурации для драйвера S3. Вы можете свободно изменять этот массив, указав собственную конфигурацию и учётные данные S3.

## Основы использования

### Получение экземпляров дисков

Фасад `Storage` может использоваться для взаимодействия с любым из ваших настроенных дисков. Например, вы можете использовать метод `put` на фасаде для сохранения аватара на диске по умолчанию. Если вы вызываете методы на фасаде `Storage` без предварительного вызова метода `disk`, вызов метода будет автоматически передан на диск по умолчанию:

```php
$user = User::find($id);

Storage::put(
    'avatars/'.$user->id,
    file_get_contents(Request::file('avatar')->getRealPath())
);
```

При использовании нескольких дисков вы можете получить доступ к определённому диску с помощью метода `disk` фасада `Storage`. Конечно, вы можете продолжать цепочку методов для выполнения операций на диске:

```php
$disk = Storage::disk('s3');

$contents = Storage::disk('local')->get('file.jpg')
```

### Получение файлов

Метод `get` может использоваться для получения содержимого заданного файла. Метод вернёт необработанное строковое содержимое файла:

```php
$contents = Storage::get('file.jpg');
```

Метод `exists` может использоваться для определения, существует ли заданный файл на диске:

```php
$exists = Storage::disk('s3')->exists('file.jpg');
```

#### Метаинформация о файле

Метод `size` может использоваться для получения размера файла в байтах:

```php
$size = Storage::size('file1.jpg');
```

Метод `lastModified` возвращает UNIX-метку времени последнего изменения файла:

```php
$time = Storage::lastModified('file1.jpg');
```

### Сохранение файлов

Метод `put` может использоваться для сохранения файла на диск. Вы также можете передать PHP-`resource` в метод `put`, который будет использовать поддержку потоков Flysystem. Использование потоков настоятельно рекомендуется при работе с большими файлами:

```php
Storage::put('file.jpg', $contents);

Storage::put('file.jpg', $resource);
```

Метод `copy` может использоваться для копирования существующего файла в новое расположение на диске:

```php
Storage::copy('old/file1.jpg', 'new/file1.jpg');
```

Метод `move` может использоваться для перемещения существующего файла в новое расположение:

```php
Storage::move('old/file1.jpg', 'new/file1.jpg');
```

#### Добавление в начало / конец файлов

Методы `prepend` и `append` позволяют легко вставлять содержимое в начало или конец файла:

```php
Storage::prepend('file.log', 'Prepended Text');

Storage::append('file.log', 'Appended Text');
```

### Удаление файлов

Метод `delete` принимает одно имя файла или массив файлов для удаления с диска:

```php
Storage::delete('file.jpg');

Storage::delete(['file1.jpg', 'file2.jpg']);
```

### Директории

#### Получение всех файлов в директории

Метод `files` возвращает массив всех файлов в заданной директории. Если вы хотите получить список всех файлов в заданной директории, включая все поддиректории, вы можете использовать метод `allFiles`:

```php
$files = Storage::files($directory);

$files = Storage::allFiles($directory);
```

#### Получение всех директорий в директории

Метод `directories` возвращает массив всех директорий в заданной директории. Кроме того, вы можете использовать метод `allDirectories` для получения списка всех директорий в заданной директории и всех её поддиректориях:

```php
$directories = Storage::directories($directory);

// Recursive...
$directories = Storage::allDirectories($directory);
```

#### Создание директории

Метод `makeDirectory` создаст заданную директорию, включая все необходимые поддиректории:

```php
Storage::makeDirectory($directory);
```

#### Удаление директории

Наконец, метод `deleteDirectory` может использоваться для удаления директории, включая все её файлы, с диска:

```php
Storage::deleteDirectory($directory);
```

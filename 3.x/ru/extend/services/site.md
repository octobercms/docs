# Менеджер сайтов

### Введение

Глобальный фасад `Site` включён в October CMS для предоставления инструментов работы с [мультисайтовыми реализациями](../../cms/resources/multisite.md). Все необязательные мультисайтовые функции включаются или отключаются с помощью конфигурационного файла **config/multisite.php**.

```php
'features' => [
    'cms_maintenance_setting' => false,
    // ...
]
```

Метод `hasFeature` используется для проверки, включена ли определённая мультисайтовая функция.

```php
$useMultisite = Site::hasFeature('cms_maintenance_setting');
```

## Проверка состояния конфигурации сайта

Используйте `hasAnySite` для проверки, доступен ли хотя бы один включённый сайт.

```php
if (Site::hasAnySite()) {
    // ...
}
```

Метод `hasMultiSite` вернёт true, если доступно несколько определений сайтов.

```php
if (Site::hasMultiSite()) {
    // ...
}
```

Метод `hasSiteGroups` вернёт true, если несколько определений сайтов используют группировку.

```php
if (Site::hasSiteGroups()) {
    // ...
}
```

## Получение сайта

Запрос сайта вернёт экземпляр `System\Models\SiteDefinition` с доступными атрибутами, загруженными из драйвера кэша или базы данных.

Метод `getPrimarySite` возвращает определение основного сайта, используемое в качестве запасного варианта для каждого случая.

```php
$site = Site::getPrimarySite();
```

Тема фронтенда имеет выбранный сайт, который используется при рендеринге CMS-страниц. Метод `getActiveSite` вернёт этот сайт.

```php
$site = Site::getActiveSite();
```

Аналогично, в панели администрирования можно выбрать сайт, и его можно получить с помощью метода `getEditSite`.

```php
$site = Site::getEditSite();
```

Для поиска сайта по его уникальному идентификатору используйте `getSiteFromId` с идентификатором.

```php
$siteFour = Site::getSiteFromId(4);
```

Для поиска сайта по его коду локали используйте `getSiteForLocale`, передав желаемую локаль.

```php
$frenchSite = Site::getSiteForLocale('fr');
```

## Доступ к нескольким сайтам

Если возвращается несколько сайтов, они будут представлены как заполненный экземпляр объекта `October\Rain\Database\Collection`.

Вывести список всех сайтов, включая отключённые, можно с помощью метода `listSites`.

```php
$sites = Site::listSites();
```
Вывести только включённые сайты можно с помощью метода `listEnabled`.

```php
$sites = Site::listEnabled();
```

Вывести сайты, включённые в панели администрирования, можно с помощью `listEditEnabled`.

```php
$sites = Site::listEditEnabled();
```

## Контекст сайта

Контекст сайта используется для определения активного сайта, и это автоматически ограничит запросы этим сайтом. В некоторых случаях используется глобальное состояние, позволяющее доступ к данным всех сайтов.

Используйте `withContext` для переключения контекста на другой сайт, передав идентификатор нужного сайта.

```php
Site::withContext(2, function() {
    // Models in site 2 are now available.
});
```

Активация глобального контекста выполняется с помощью `withGlobalContext` и передачи замыкания.

```php
Site::withGlobalContext(function() {
    // All models are available in here.
});
```

Используйте метод `hasGlobalContext` для проверки, активировано ли в данный момент глобальное состояние.

```php
$global = Site::hasGlobalContext();
```

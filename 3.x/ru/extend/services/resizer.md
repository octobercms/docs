# Ресайзер

## Введение

October CMS поставляется с ресайзером изображений, который позволяет изменять форму и размер поддерживаемых изображений.

## Изменение размера файла на диске

Для изменения размера изображения используйте метод `open` фасада `Resizer`, указав путь к файлу.

```php
$image = Resizer::open('path/to/image.jpg');
```

Вы также можете передать загруженный файл из [ввода запроса страницы](./request-input.md).

```php
$image = Resizer::open(Input::file('field_name'));
```

Для изменения размера изображения вызовите метод `resize` на объекте. Первый аргумент — ширина изображения, второй — высота изображения, а третий — массив параметров изменения размера.

```php
$image->resize(800, 600, ['mode' => 'crop']);
```

Аргументы ширины и высоты также необязательны. Например, чтобы использовать существующую ширину и изменить только высоту, передайте второй аргумент как `null`. Это значение затем вычисляется с использованием исходного соотношения сторон изображения (автоматическое пропорциональное масштабирование) на основе опции `mode`.

```php
$image->resize(800, null, [...]);
```

Наконец, используйте метод `save` для сохранения изменённого изображения в новом расположении.

```php
$image->save('path/to/new/file.jpg');
```

### Параметры изменения размера

В массиве опций поддерживаются следующие элементы:

Ключ | Описание | По умолчанию | Варианты
--- | --- | --- | ---
`mode` | Как изображение должно быть подогнано под размеры | `auto` | `exact`, `portrait`, `landscape`, `auto`, `fit` или `crop`
`offset` | Смещение обрезки изменённого изображения | `[0,0]` | [left, top]
`quality` | Качество изменённого изображения | `90` | `0-100`
`sharpen` | Степень резкости изображения | `0` | `0-100`

### Доступные режимы

Опция `mode` позволяет указать, как изображение должно быть изменено. Доступные режимы следующие:

Режим | Описание
--- | ---
`auto` | Автоматический выбор между `portrait` и `landscape` на основе ориентации изображения
`exact` | Изменить размер до точных указанных размеров без сохранения соотношения сторон
`portrait` | Изменить размер до указанной высоты и адаптировать ширину для сохранения соотношения сторон
`landscape` | Изменить размер до указанной ширины и адаптировать высоту для сохранения соотношения сторон
`crop` | Обрезать до указанных размеров после максимального вписывания изображения в эти размеры
`fit` | Вписать изображение в указанные максимальные размеры, сохраняя соотношение сторон

## Изменение размера файла для браузера

Класс `System\Classes\ResizeImages` может использоваться для изменения размера изображения и предоставления его через URL:

```php
$url = \System\Classes\ResizeImages::resize($image, $width, $height, $options);
```

Если вы изменяете размер элемента из медиабиблиотеки, вам следует разрешить путь к медиа с помощью класса `Media\Classes\MediaLibrary` и метода `url`.

```php
$image = \Media\Classes\MediaLibrary::url('relative/path/to/asset.jpg');

$url = \System\Classes\ResizeImages::resize($image, $width, $height, $options);
```

:::

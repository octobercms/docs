# Кэш

## Конфигурация

October CMS предоставляет унифицированный API для различных систем кэширования, а конфигурация кэша расположена в `config/cache.php`. В этом файле вы можете указать, какой драйвер кэша должен использоваться по умолчанию в вашем приложении. Популярные системы кэширования, такие как [Memcached](http://memcached.org) и [Redis](https://redis.io), поддерживаются из коробки.

Конфигурационный файл кэша также содержит различные другие параметры, которые задокументированы внутри файла, поэтому обязательно ознакомьтесь с ними. По умолчанию October CMS настроен на использование драйвера кэша `file`, который хранит сериализованные кэшированные объекты в файловой системе. Для крупных приложений рекомендуется использовать кэш в памяти, такой как Memcached или APC. Вы можете даже настроить несколько конфигураций кэша для одного и того же драйвера.

### Требования для кэша

#### Database

Драйвер кэша `database` использует базу данных вместо файловой системы. Никакой дополнительной конфигурации не требуется для использования этого типа, так как структура базы данных уже доступна.

#### Memcached

Использование кэша Memcached требует установки [пакета Memcached PECL](http://pecl.php.net/package/memcached). Конфигурация по умолчанию использует TCP/IP на основе [Memcached::addServer](http://php.net/manual/en/memcached.addserver.php).

```php
'memcached' => [
    'servers' => [
        [
            'host' => env('MEMCACHED_HOST', '127.0.0.1'),
            'port' => env('MEMCACHED_PORT', 11211),
            'weight' => 100,
        ],
    ],
],
```

Вы также можете установить параметр `host` как путь к UNIX-сокету. Если вы сделаете это, параметр `port` должен быть установлен в `0`.

```php
'memcached' => [
    [
        'host' => '/var/run/memcached/memcached.sock',
        'port' => 0,
        'weight' => 100
    ],
],
```

#### Redis

::: tip
Перед использованием кэша Redis с Laravel вам необходимо либо установить расширение PHP PhpRedis через PECL, либо установить пакет `predis/predis` (~1.0) через Composer.
:::

Конфигурация Redis для вашего приложения расположена в конфигурационном файле `config/database.php`. В этом файле вы увидите массив `redis`, содержащий серверы Redis, используемые вашим приложением:

```php
'redis' => [

    'cluster' => false,

    'default' => [
        'host'     => '127.0.0.1',
        'port'     => 6379,
        'database' => 0,
    ],

],
```

Вы можете определить значение массива `options` в определении подключения Redis, что позволяет указать набор [клиентских опций](https://github.com/nrk/predis/wiki/Client-Options) Predis.

Если ваш сервер Redis требует аутентификации, вы можете указать пароль, добавив элемент конфигурации `password` в массив конфигурации вашего сервера Redis.

#### DynamoDB

Перед использованием драйвера кэша DynamoDB вы должны создать таблицу кэша DynamoDB для хранения всех кэшированных данных, обычно она называется `cache`. Вы можете назвать таблицу как угодно на основе значения конфигурации `stores.dynamodb.table` в конфигурационном файле `cache` вашего приложения.

```php
'dynamodb' => [
    'table' => env('DYNAMODB_CACHE_TABLE', 'cache'),
],
```

Эта таблица также должна иметь строковый ключ раздела с именем, соответствующим значению элемента конфигурации `stores.dynamodb.attributes.key` в конфигурационном файле кэша вашего приложения. По умолчанию ключ раздела должен называться `key`.

## Использование кэша

Хотя большая часть кэширования обрабатывается внутренне October, фасад `Cache` предоставляет несколько простых методов для кэширования ваших собственных данных.

### Получение элементов из кэша

Метод `get` фасада `Cache` используется для получения элементов из кэша. Если элемент не существует в кэше, будет возвращён `null`. При желании вы можете передать второй аргумент в метод `get`, указывающий пользовательское значение по умолчанию, которое вы хотите получить, если элемент не существует:

```php
$value = Cache::get('key');

$value = Cache::get('key', 'default');
```

Вы даже можете передать `Closure` в качестве значения по умолчанию. Результат `Closure` будет возвращён, если указанный элемент не существует в кэше. Передача Closure позволяет отложить получение значений по умолчанию из базы данных или другого внешнего сервиса:

```php
$value = Cache::get('key', function() {
    return Db::table(...)->get();
});
```

#### Проверка существования элемента

Метод `has` может использоваться для определения, существует ли элемент в кэше:

```php
if (Cache::has('key')) {
    //
}
```

#### Инкремент / Декремент значений

Методы `increment` и `decrement` могут использоваться для корректировки значения целочисленных элементов в кэше. Оба метода опционально принимают второй аргумент, указывающий величину, на которую нужно увеличить или уменьшить значение элемента:

```php
Cache::increment('key');

Cache::increment('key', $amount);

Cache::decrement('key');

Cache::decrement('key', $amount);
```

#### Получение или обновление

Иногда вам может понадобиться получить элемент из кэша, но также сохранить значение по умолчанию, если запрашиваемый элемент не существует. Например, вы можете захотеть получить всех пользователей из кэша или, если они не существуют, получить их из базы данных и добавить в кэш. Вы можете сделать это с помощью метода `Cache::remember`:

```php
$value = Cache::remember('users', $seconds, function() {
    return Db::table('users')->get();
});
```

Если элемент не существует в кэше, `Closure`, переданное в метод `remember`, будет выполнено, и его результат будет помещён в кэш.

Вы также можете комбинировать методы `remember` и `forever`:

```php
$value = Cache::rememberForever('users', function() {
    return Db::table('users')->get();
});
```

#### Получение и удаление

Если вам нужно получить элемент из кэша и затем удалить его, вы можете использовать метод `pull`. Как и метод `get`, `null` будет возвращён, если элемент не существует в кэше:

```php
$value = Cache::pull('key');
```

### Сохранение элементов в кэше

Вы можете использовать метод `put` фасада `Cache` для сохранения элементов в кэше. При помещении элемента в кэш вам нужно указать количество секунд, в течение которых значение должно быть кэшировано:

```php
Cache::put('key', 'value', $seconds);
```

Вместо передачи количества секунд до истечения срока действия элемента вы также можете передать экземпляр PHP `DateTime`, представляющий время истечения кэшированного элемента:

```php
$expiresAt = Carbon::now()->addMinutes(10);

Cache::put('key', 'value', $expiresAt);
```

> **Примечание**: Мы рекомендуем использовать экземпляры `DateTime` для определения всех сроков истечения, чтобы обеспечить совместимость с будущими версиями October CMS.

Метод `add` добавит элемент в кэш только если он ещё не существует в хранилище кэша. Метод вернёт `true`, если элемент действительно добавлен в кэш. В противном случае метод вернёт `false`:

```php
Cache::add('key', 'value', $seconds);
```

Метод `forever` может использоваться для постоянного хранения элемента в кэше. Эти значения должны быть удалены вручную из кэша с помощью метода `forget`:

```php
Cache::forever('key', 'value');
```

### Удаление элементов из кэша

Вы можете удалить элементы из кэша с помощью метода `forget` фасада `Cache`:

```php
Cache::forget('key');
```

Вы можете очистить весь кэш с помощью метода `flush`:

```php
Cache::flush();
```

Очистка кэша **не** учитывает префикс кэша и удалит все записи из кэша. Учитывайте это при очистке кэша, который используется совместно с другими приложениями.

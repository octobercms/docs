# Основы использования

Подключение к базам данных и выполнение запросов — это простой процесс, поддерживаемый использованием чистого SQL, [конструктора запросов](./query.md) или [моделей Active Record](./model.md). Управление таблицами базы данных и заполнение начальными данными осуществляется через процесс [миграций и сидеров](./structure.md).

Чистый SQL и использование конструктора запросов выполняются быстрее и должны использоваться для простых задач. Active Record — это подход, используемый популярным фреймворком Ruby On Rails. Он предоставляет простой интерфейс для выполнения повторяющихся задач, таких как создание, чтение, обновление и удаление записей базы данных. Вы можете узнать больше о [паттерне Active Record в Википедии](http://en.wikipedia.org/wiki/Active_record_pattern).

## Выполнение чистых SQL-запросов

После настройки подключения к базе данных вы можете выполнять запросы с помощью фасада `Db`. Фасад `Db` предоставляет методы для каждого типа запросов: `select`, `update`, `insert`, `delete` и `statement`.

### Выборка записей

Для выполнения базового запроса используйте метод `select` фасада `Db`.

```php
$users = Db::select('select * from users where active = ?', [1]);
```

Первый аргумент, передаваемый методу `select` — это чистый SQL-запрос, а второй аргумент — привязка параметров, которые необходимо связать с запросом. Как правило, это значения ограничений оператора `where`. Привязка параметров обеспечивает защиту от SQL-инъекций.

Метод `select` всегда возвращает `array` результатов. Каждый результат в массиве будет объектом PHP `stdClass`, что позволяет получать доступ к значениям результатов:

```php
foreach ($users as $user) {
    echo $user->name;
}
```

Вместо использования `?` для представления привязки параметров вы можете выполнить запрос с использованием именованных привязок.

```php
$results = Db::select('select * from users where id = :id', ['id' => 1]);
```

Если запрос к базе данных может вернуть единственное значение, его можно получить с помощью метода `scalar`.

```php
$count = Db::scalar('select count(*) as count from menu_items');
```

### Изменение записей

Для выполнения оператора `insert` вы можете использовать метод `insert` фасада `Db`. Как и `select`, этот метод принимает чистый SQL-запрос в качестве первого аргумента и привязки в качестве второго аргумента.

```php
Db::insert('insert into users (id, name) values (?, ?)', [1, 'Joe']);
```

Метод `update` следует использовать для обновления существующих записей в базе данных. Количество затронутых строк будет возвращено методом:

```php
$affected = Db::update('update users set votes = 100 where name = ?', ['John']);
```

Метод `delete` следует использовать для удаления записей из базы данных. Как и `update`, количество удалённых строк будет возвращено:

```php
$deleted = Db::delete('delete from users');
```

### Общие операторы

Некоторые операторы базы данных не должны возвращать значение. Для таких типов операций вы можете использовать метод `statement` фасада `Db`.

```php
Db::statement('drop table users');
```

## Множественные подключения к базе данных

При [использовании нескольких подключений](../../setup/database-config.md) вы можете получить доступ к каждому подключению через метод `connection` фасада `Db`. Имя `name`, передаваемое методу `connection`, должно соответствовать одному из подключений, перечисленных в вашем файле конфигурации `config/database.php`.

```php
$users = Db::connection('foo')->select(...);
```

Вы также можете получить доступ к базовому экземпляру PDO с помощью метода `getPdo` на экземпляре подключения.

```php
$pdo = Db::connection()->getPdo();
```

## Транзакции базы данных

Для выполнения набора операций внутри транзакции базы данных вы можете использовать метод `transaction` фасада `Db`. Если внутри `Closure` транзакции будет выброшено исключение, транзакция автоматически откатится. Если `Closure` выполнится успешно, транзакция автоматически подтвердится. Вам не нужно беспокоиться о ручном откате или подтверждении при использовании метода `transaction`.

```php
Db::transaction(function () {
    Db::table('users')->update(['votes' => 1]);

    Db::table('posts')->delete();
});
```

Если вы хотите начать транзакцию вручную и иметь полный контроль над откатами и подтверждениями, вы можете использовать метод `beginTransaction` фасада `Db`:

```php
Db::beginTransaction();
```

Вы можете откатить транзакцию с помощью метода `rollBack`:

```php
Db::rollBack();
```

Наконец, вы можете подтвердить транзакцию с помощью метода `commit`:

```php
Db::commit();
```

::: tip
Использование методов транзакций фасада `Db` также управляет транзакциями для [конструктора запросов](./query.md) и [запросов моделей](./model.md).
:::

## События базы данных

Если вы хотите получать каждый SQL-запрос, выполняемый вашим приложением, вы можете использовать метод `listen`. Этот метод полезен для логирования запросов или отладки.

```php
Db::listen(function($sql, $bindings, $time) {
    //
});
```

Вы можете зарегистрировать свой слушатель запросов в методе `boot` [файла регистрации плагина](../extending.md). Кроме того, плагины могут предоставлять файл с именем **init.php** в директории плагина, который можно использовать для размещения этой логики.

### Логирование запросов

При включении логирования запросов в памяти ведётся журнал всех запросов, выполненных для текущего запроса. Вызовите метод `enableQueryLog` для включения этой функции.

```php
Db::connection()->enableQueryLog();
```

Для получения массива выполненных запросов вы можете использовать метод `getQueryLog`:

```php
$queries = Db::getQueryLog();
```

Однако в некоторых случаях, например при вставке большого количества строк, это может привести к чрезмерному использованию памяти приложением. Для отключения журнала вы можете использовать метод `disableQueryLog`:

```php
Db::connection()->disableQueryLog();
```

::: tip
Для более быстрой отладки может быть полезнее вызвать [вспомогательную функцию](../services/log.md) `trace_sql`.
:::

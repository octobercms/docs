# Конструктор запросов

::: aside
Конструктор запросов использует привязку параметров PDO для защиты вашего приложения от атак SQL-инъекций. Нет необходимости очищать строки, передаваемые как привязки.
:::

Конструктор запросов к базе данных предоставляет удобный, гибкий интерфейс для создания и выполнения запросов к базе данных. Он может использоваться для выполнения большинства операций с базой данных в вашем приложении и работает на всех поддерживаемых системах баз данных.

### Пример необработанного SQL

Иногда имеет больше смысла выполнить запрос с использованием чистого SQL, вы можете сделать это с помощью метода `Db::select`.

```php
Db::select('select * from sometable where name = :name', ['name' => 'Charles']);
```

Подробнее смотрите статью о [выполнении необработанных SQL-запросов](./basics.md).

## Получение результатов

Для начала формирования запроса используйте метод `table` фасада `Db`. Метод `table` возвращает экземпляр конструктора запросов для указанной таблицы, позволяя цепочкой добавлять ограничения к запросу и, наконец, получать результаты. В этом примере `get` вернёт все записи из таблицы.

```php
$users = Db::table('users')->get();
```

Аналогично [необработанным запросам](./basics.md), метод `get` возвращает `array` результатов, где каждый результат является экземпляром PHP-объекта `stdClass`. Вы можете получить значение каждого столбца, обращаясь к столбцу как к свойству объекта.

```php
foreach ($users as $user) {
    echo $user->name;
}
```

Если вам нужно получить только одну строку из таблицы базы данных, используйте метод `first`. Этот метод вернёт один объект `stdClass`.

```php
$user = Db::table('users')->where('name', 'John')->first();

echo $user->name;
```

### Извлечение значений

Если вам не нужна вся строка целиком, вы можете извлечь одно значение из записи с помощью метода `value`. Этот метод вернёт значение столбца напрямую:

```php
$email = Db::table('users')->where('name', 'John')->value('email');
```

Если вы хотите получить массив, содержащий значения одного столбца, используйте метод `pluck`. В этом примере мы получим массив названий ролей.

```php
$titles = Db::table('roles')->pluck('title');

foreach ($titles as $title) {
    echo $title;
}
```

Вы также можете указать пользовательский столбец-ключ для возвращаемого массива.

```php
$roles = Db::table('roles')->pluck('title', 'name');

foreach ($roles as $name => $title) {
    echo $title;
}
```

::: warning
Результат `pluck` возвращает объект `Collection`, который ведёт себя как массив. Используйте метод `all()` для преобразования его в PHP-массив, например: `pluck('name')->all()`.
:::

### Разбиение результатов на части

Если вам нужно работать с тысячами записей базы данных, рассмотрите использование метода `chunk`. Этот метод получает небольшую «часть» результатов за раз и передаёт каждую часть в `Closure` для обработки. Этот метод очень полезен при написании [консольных команд](../console-commands.md), обрабатывающих тысячи записей. Например, обработаем всю таблицу `users` частями по 100 записей.

```php
Db::table('users')->chunk(100, function($users) {
    foreach ($users as $user) {
        //
    }
});
```

Вы можете остановить обработку дальнейших частей, вернув `false` из `Closure`.

```php
Db::table('users')->chunk(100, function($users) {
    // Process the records...

    return false;
});
```

Если вы обновляете записи базы данных при разбиении на части, результаты могут измениться неожиданным образом. Поэтому при обновлении записей во время разбиения лучше всего использовать метод `chunkById`. Этот метод автоматически пагинирует результаты на основе первичного ключа записи.

```php
Db::table('users')->where('active', false)
    ->chunkById(100, function ($users) {
        foreach ($users as $user) {
            Db::table('users')
                ->where('id', $user->id)
                ->update(['active' => true]);
        }
    });
```

::: warning
При обновлении или удалении записей внутри callback-функции chunk любые изменения первичного ключа или внешних ключей могут повлиять на запрос chunk. Это потенциально может привести к тому, что записи не будут включены в результаты разбиения.
:::

### Агрегатные функции

Конструктор запросов также предоставляет множество агрегатных методов, таких как `count`, `max`, `min`, `avg` и `sum`. Вы можете вызвать любой из этих методов после построения запроса:

```php
$users = Db::table('users')->count();

$price = Db::table('orders')->max('price');
```

Конечно, вы можете комбинировать эти методы с другими условиями для построения запроса:

```php
$price = Db::table('orders')
    ->where('is_finalized', 1)
    ->avg('price');
```

Вместо использования метода `count` для определения наличия записей, соответствующих ограничениям запроса, вы можете использовать методы `exists` и `doesntExist`:

```php
return Db::table('orders')->where('finalized', 1)->exists();

return Db::table('orders')->where('finalized', 1)->doesntExist();
```

## Операторы Select

В некоторых случаях вам может не понадобиться выбирать все столбцы из таблицы базы данных. С помощью метода `select` вы можете указать пользовательское предложение `select` для запроса.

```php
$users = Db::table('users')->select('name', 'email as user_email')->get();
```

Метод `distinct` позволяет принудительно вернуть только уникальные результаты запроса.

```php
$users = Db::table('users')->distinct()->get();
```

Если у вас уже есть экземпляр конструктора запросов и вы хотите добавить столбец к существующему предложению select, используйте метод `addSelect`:

```php
$query = Db::table('users')->select('name');

$users = $query->addSelect('age')->get();
```

### Необработанные выражения

Иногда вам может понадобиться использовать необработанное выражение в запросе. Для создания необработанного выражения используйте метод `Db::raw`.

```php
$users = Db::table('users')
    ->select(Db::raw('count(*) as user_count, status'))
    ->where('status', '<>', 1)
    ->groupBy('status')
    ->get();
```

Другое использование — конкатенация столбцов и/или строк.

```php
Db::raw("(first_name, ' ', last_name) as full_name");
```

::: warning
Необработанные выражения будут вставлены в запрос как строки, поэтому будьте крайне осторожны, чтобы не создать уязвимости SQL-инъекций.
:::

### Необработанные методы

Вместо использования `Db::raw` вы также можете использовать следующие методы для вставки необработанного выражения в различные части запроса.

Метод `selectRaw` можно использовать вместо `addSelect(Db::raw(...))`. Этот метод принимает необязательный массив привязок в качестве второго аргумента:

```php
$orders = Db::table('orders')
    ->selectRaw('price * ? as price_with_tax', [1.0825])
    ->get();
```

Методы `whereRaw` и `orWhereRaw` можно использовать для вставки необработанного условия `where` в запрос. Эти методы принимают необязательный массив привязок в качестве второго аргумента:

```php
$orders = Db::table('orders')
    ->whereRaw('price > IF(state = "TX", ?, 100)', [200])
    ->get();
```

Методы `havingRaw` и `orHavingRaw` можно использовать для установки необработанной строки в качестве значения предложения `having`. Эти методы принимают необязательный массив привязок в качестве второго аргумента:

```php
$orders = Db::table('orders')
    ->select('department', Db::raw('SUM(price) as total_sales'))
    ->groupBy('department')
    ->havingRaw('SUM(price) > ?', [2500])
    ->get();
```

Метод `orderByRaw` можно использовать для установки необработанной строки в качестве значения предложения order by:

```php
$orders = Db::table('orders')
    ->orderByRaw('updated_at - created_at DESC')
    ->get();
```

Метод `groupByRaw` можно использовать для установки необработанной строки в качестве значения предложения group by:

```php
$orders = Db::table('orders')
    ->select('city', 'state')
    ->groupByRaw('city, state')
    ->get();
```

## Соединения (Joins)

Конструктор запросов также может использоваться для написания операторов соединения. Для выполнения базового SQL «inner join» используйте метод `join` на экземпляре конструктора запросов. Первый аргумент, передаваемый методу `join`, — это имя таблицы, к которой нужно присоединиться, а остальные аргументы указывают ограничения столбцов для соединения. Конечно, как видите, вы можете присоединить несколько таблиц в одном запросе.

```php
$users = Db::table('users')
    ->join('contacts', 'users.id', '=', 'contacts.user_id')
    ->join('orders', 'users.id', '=', 'orders.user_id')
    ->select('users.*', 'contacts.phone', 'orders.price')
    ->get();
```

Если вы хотите выполнить «left join» или «right join» вместо «inner join», используйте метод `leftJoin` или `rightJoin`. Методы `leftJoin` и `rightJoin` имеют ту же сигнатуру, что и метод `join`.

```php
$users = Db::table('users')
    ->leftJoin('posts', 'users.id', '=', 'posts.user_id')
    ->get();

$users = Db::table('users')
    ->rightJoin('posts', 'users.id', '=', 'posts.user_id')
    ->get();
```

Для выполнения «cross join» используйте метод `crossJoin` с именем таблицы, к которой хотите выполнить перекрёстное соединение. Перекрёстные соединения генерируют декартово произведение между первой таблицей и присоединённой таблицей.

```php
$users = Db::table('sizes')
    ->crossJoin('colors')
    ->get();
```

### Расширенные операторы соединения

Вы также можете указать более сложные условия соединения. Для начала передайте `Closure` в качестве второго аргумента метода `join`. `Closure` получит объект `JoinClause`, позволяющий указать ограничения для предложения `join`.

```php
Db::table('users')
    ->join('contacts', function ($join) {
        $join->on('users.id', '=', 'contacts.user_id')->orOn(...);
    })
    ->get();
```

Если вы хотите использовать условие в стиле «where» в соединениях, используйте методы `where` и `orWhere` для соединения. Вместо сравнения двух столбцов эти методы сравнивают столбец со значением.

```php
Db::table('users')
    ->join('contacts', function ($join) {
        $join->on('users.id', '=', 'contacts.user_id')
            ->where('contacts.user_id', '>', 5);
    })
    ->get();
```

### Соединения с подзапросами

Вы можете использовать методы `joinSub`, `leftJoinSub` и `rightJoinSub` для присоединения запроса к подзапросу. Каждый из этих методов принимает три аргумента: подзапрос, его псевдоним таблицы и Closure, определяющую связанные столбцы:

```php
$latestPosts = Db::table('posts')
    ->select('user_id', Db::raw('MAX(created_at) as last_post_created_at'))
    ->where('is_published', true)
    ->groupBy('user_id');

$users = Db::table('users')
    ->joinSub($latestPosts, 'latest_posts', function ($join) {
        $join->on('users.id', '=', 'latest_posts.user_id');
    })->get();
```

### Объединения (Unions)

Конструктор запросов также предоставляет быстрый способ «объединения» двух запросов. Например, вы можете создать начальный запрос, а затем использовать метод `union` для объединения со вторым запросом.

```php
$first = Db::table('users')
    ->whereNull('first_name');

$users = Db::table('users')
    ->whereNull('last_name')
    ->union($first)
    ->get();
```

Метод `unionAll` также доступен и имеет ту же сигнатуру, что и `union`.

## Условия Where

Для добавления условий `where` к запросу используйте метод `where` экземпляра конструктора запросов. Базовый вызов `where` требует три аргумента. Первый аргумент — имя столбца. Второй аргумент — оператор, который может быть любым из поддерживаемых операторов базы данных. Третий аргумент — значение для сравнения со столбцом.

Например, вот запрос, проверяющий, что значение столбца «votes» равно 100.

```php
$users = Db::table('users')->where('votes', '=', 100)->get();
```

Для удобства, если вы просто хотите проверить равенство столбца заданному значению, вы можете передать значение напрямую вторым аргументом метода `where`.

```php
$users = Db::table('users')->where('votes', 100)->get();
```

Вы можете использовать различные другие операторы при написании условия `where`, например, больше `>`, не равно `<>` и `like`.

```php
$users = Db::table('users')
    ->where('votes', '>=', 100)
    ->get();

$users = Db::table('users')
    ->where('votes', '<>', 100)
    ->get();

$users = Db::table('users')
    ->where('name', 'like', 'T%')
    ->get();
```

### Операторы Or

Вы можете объединять условия where в цепочку, а также добавлять условия `or` к запросу. Метод `orWhere` принимает те же аргументы, что и метод `where`:

```php
$users = Db::table('users')
    ->where('votes', '>', 100)
    ->orWhere('name', 'John')
    ->get();
```

::: tip
Вы также можете добавить префикс `or` к любому из нижеприведённых методов where, чтобы сделать условие условием «OR» — например, `orWhereBetween`, `orWhereIn` и т.д.
:::

### Дополнительные операторы Where

Метод `whereBetween` проверяет, что значение столбца находится между двумя значениями.

```php
$users = Db::table('users')
    ->whereBetween('votes', [1, 100])->get();
```

Метод `whereNotBetween` проверяет, что значение столбца лежит за пределами двух значений.

```php
$users = Db::table('users')
    ->whereNotBetween('votes', [1, 100])
    ->get();
```

Метод `whereIn` проверяет, что значение данного столбца содержится в указанном массиве.

```php
$users = Db::table('users')
    ->whereIn('id', [1, 2, 3])
    ->get();
```

Метод `whereNotIn` проверяет, что значение данного столбца **не** содержится в указанном массиве.

```php
$users = Db::table('users')
    ->whereNotIn('id', [1, 2, 3])
    ->get();
```

Метод `whereNull` проверяет, что значение данного столбца равно `NULL`.

```php
$users = Db::table('users')
    ->whereNull('updated_at')
    ->get();
```

Метод `whereNotNull` проверяет, что значение столбца **не** равно `NULL`.

```php
$users = Db::table('users')
    ->whereNotNull('updated_at')
    ->get();
```

### Оператор поиска

Методы `searchWhere` и `orSearchWhere` могут использоваться для выполнения поискового запроса по значению столбца. Метод добавляет к запросу условие, используя поисковый термин (первый аргумент) и столбцы поиска (второй аргумент) с помощью регистронезависимого запроса `like`.

```php
$pages = Db::table('posts')
    ->searchWhere('foo bar', ['title', 'content'])
    ->get();
```

Приведённый выше пример сформирует следующий SQL, где к каждому столбцу и значению применяется `lower()`:

```sql
select * from users where
    (title like '%foo%' and title like '%bar%') or
    (content like '%foo%' and content like '%bar%')
```

По умолчанию каждое слово в поисковом термине будет искаться, однако вы можете изменить это поведение, указав режим (третий аргумент), со следующими поддерживаемыми режимами.

- **all**: результат должен содержать все слова (по умолчанию)
- **any**: результат может содержать любое слово
- **exact**: результат должен содержать точную фразу

```php
$query->searchWhere('foo bar', ['title', 'content'], 'exact');
```

Пример поиска `exact` выше сформирует следующий SQL:

```sql
select * from users where (title like '%foo bar%' or content like '%foo bar%')
```

## Составные условия Where

Иногда вам может понадобиться создать более сложные условия where, такие как «where exists» или вложенные группы параметров. Конструктор запросов Laravel может обрабатывать и эти случаи. Для начала рассмотрим пример группировки ограничений в скобках:

```php
Db::table('users')
    ->where('name', '=', 'John')
    ->orWhere(function ($query) {
        $query->where('votes', '>', 100)
            ->where('title', '<>', 'Admin');
    })
    ->get();
```

Как видите, передача `Closure` в метод `orWhere` указывает конструктору запросов начать группу ограничений. `Closure` получит экземпляр конструктора запросов, который вы можете использовать для установки ограничений, которые должны содержаться внутри группы скобок. Приведённый выше пример сформирует следующий SQL:

```sql
select * from users where name = 'John' or (votes > 100 and title <> 'Admin')
```

### Операторы Exists

Метод `whereExists` позволяет писать SQL-условия `where exists`. Метод `whereExists` принимает аргумент `Closure`, который получит экземпляр конструктора запросов, позволяющий определить запрос, который должен быть помещён внутри условия «exists»:

```php
Db::table('users')
    ->whereExists(function ($query) {
        $query->select(Db::raw(1))
            ->from('orders')
            ->whereRaw('orders.user_id = users.id');
    })
    ->get();
```

Запрос выше сформирует следующий SQL:

```sql
select * from users where exists (
    select 1 from orders where orders.user_id = users.id
)
```

### JSON-условия Where

October CMS также поддерживает запросы к столбцам типа JSON в базах данных, которые поддерживают типы столбцов JSON. Для запроса к JSON-столбцу используйте оператор `->`.

```php
$users = Db::table('users')
    ->where('options->language', 'en')
    ->get();

$users = Db::table('users')
    ->where('preferences->dining->meal', 'salad')
    ->get();
```

Вы можете использовать `whereJsonContains` для запроса JSON-массивов (не поддерживается в SQLite).

```php
$users = Db::table('users')
    ->whereJsonContains('options->languages', 'en')
    ->get();
```

MySQL и PostgreSQL поддерживают `whereJsonContains` с несколькими значениями.

```php
$users = Db::table('users')
    ->whereJsonContains('options->languages', ['en', 'de'])
    ->get();
```

Вы можете использовать `whereJsonLength` для запроса JSON-массивов по их длине.

```php
$users = Db::table('users')
    ->whereJsonLength('options->languages', 0)
    ->get();

$users = Db::table('users')
    ->whereJsonLength('options->languages', '>', 1)
    ->get();
```

### Условные предложения

Иногда вам может понадобиться, чтобы условия применялись к запросу только при выполнении определённого условия. Например, вы можете захотеть применить оператор `where` только если определённое входное значение присутствует во входящем запросе. Вы можете сделать это с помощью метода `when`:

```php
$role = $request->input('role');

$users = Db::table('users')
    ->when($role, function ($query, $role) {
        return $query->where('role_id', $role);
    })
    ->get();
```

Метод `when` выполняет заданное Closure только когда первый параметр равен `true`. Если первый параметр равен `false`, Closure не будет выполнено.

Вы можете передать другое Closure в качестве третьего параметра метода `when`. Это Closure будет выполнено, если первый параметр оценивается как false. Чтобы проиллюстрировать использование этой функции, мы используем её для настройки сортировки запроса по умолчанию:

```php
$sortBy = null;

$users = Db::table('users')
    ->when($sortBy, function ($query, $sortBy) {
        return $query->orderBy($sortBy);
    }, function ($query) {
        return $query->orderBy('name');
    })
    ->get();
```

## Сортировка, группировка, ограничение

### Сортировка

Метод `orderBy` позволяет отсортировать результаты запроса по указанному столбцу. Первый аргумент метода `orderBy` — это столбец, по которому вы хотите отсортировать, а второй аргумент управляет направлением сортировки и может быть `asc` или `desc`.

```php
$users = Db::table('users')
    ->orderBy('name', 'desc')
    ->get();
```

Методы `latest` и `oldest` позволяют легко сортировать результаты по дате. По умолчанию результаты сортируются по столбцу `created_at`. Или вы можете передать имя столбца, по которому хотите отсортировать.

```php
$user = Db::table('users')
    ->latest()
    ->first();
```

Метод `inRandomOrder` может использоваться для случайной сортировки результатов запроса. Например, этот метод можно использовать для получения случайного пользователя.

```php
$randomUser = Db::table('users')
    ->inRandomOrder()
    ->first();
```

### Группировка

Методы `groupBy` и `having` могут использоваться для группировки результатов запроса. Сигнатура метода `having` аналогична сигнатуре метода `where`.

```php
$users = Db::table('users')
    ->groupBy('account_id')
    ->having('account_id', '>', 100)
    ->get();
```

Вы можете передать несколько аргументов методу `groupBy` для группировки по нескольким столбцам.

```php
$users = Db::table('users')
    ->groupBy('first_name', 'status')
    ->having('account_id', '>', 100)
    ->get();
```

Для более сложных операторов `having` вы можете использовать метод `havingRaw`.

### Ограничение и смещение

Для ограничения количества результатов, возвращаемых запросом, или для пропуска заданного количества результатов (`OFFSET`) используйте методы `skip` и `take`.

```php
$users = Db::table('users')->skip(10)->take(5)->get();
```

## Вставка

Конструктор запросов также предоставляет метод `insert` для вставки записей в таблицу базы данных. Метод `insert` принимает массив имён столбцов и значений для вставки:

```php
Db::table('users')->insert(
    ['email' => 'john@example.tld', 'votes' => 0]
);
```

Вы даже можете вставить несколько записей в таблицу одним вызовом `insert`, передав массив массивов. Каждый массив представляет строку для вставки в таблицу:

```php
Db::table('users')->insert([
    ['email' => 'taylor@example.tld', 'votes' => 0],
    ['email' => 'dayle@example.tld', 'votes' => 0]
]);
```

### Автоинкрементные ID

Если таблица имеет автоинкрементный id, используйте метод `insertGetId` для вставки записи и последующего получения ID:

```php
$id = Db::table('users')->insertGetId(
    ['email' => 'john@example.tld', 'votes' => 0]
);
```

::: tip
При использовании драйвера базы данных PostgreSQL метод insertGetId ожидает, что автоинкрементный столбец будет называться `id`. Если вы хотите получить ID из другой «последовательности», вы можете передать имя последовательности вторым параметром метода `insertGetId`.
:::

## Обновление

Помимо вставки записей в базу данных, конструктор запросов может также обновлять существующие записи с помощью метода `update`. Метод `update`, как и метод `insert`, принимает массив пар столбцов и значений, содержащих столбцы для обновления. Вы можете ограничить запрос `update` с помощью условий `where`.

```php
Db::table('users')
    ->where('id', 1)
    ->update(['votes' => 1]);
```

### Обновление или вставка

Иногда вы можете захотеть обновить существующую запись в базе данных или создать её, если соответствующая запись не существует. В этом сценарии можно использовать метод `updateOrInsert`. Метод `updateOrInsert` принимает два аргумента: массив условий для поиска записи и массив пар столбцов и значений, содержащих столбцы для обновления.

Метод `updateOrInsert` сначала попытается найти соответствующую запись в базе данных, используя пары столбец/значение первого аргумента. Если запись существует, она будет обновлена значениями второго аргумента. Если запись не найдена, будет вставлена новая запись с объединёнными атрибутами обоих аргументов.

```php
Db::table('users')
    ->updateOrInsert(
        ['email' => 'john@example.tld', 'name' => 'John'],
        ['votes' => '2']
    );
```

### Upsert

Метод `upsert` вставит строки, которые не существуют, и обновит существующие строки новыми значениями. Первый аргумент метода содержит значения для вставки или обновления, второй аргумент перечисляет столбцы, которые уникально идентифицируют записи в таблице. Третий и последний аргумент — массив столбцов, которые должны быть обновлены, если соответствующая запись уже существует в базе данных.

```php
Db::table('flights')->upsert([
    ['departure' => 'Oakland', 'destination' => 'San Diego', 'price' => 99],
    ['departure' => 'Chicago', 'destination' => 'New York', 'price' => 150]
], ['departure', 'destination'], ['price']);
```

::: tip
Все базы данных, кроме SQL Server, требуют, чтобы столбцы во втором аргументе метода `upsert` имели «primary» или «unique» индекс.
:::

### Обновление JSON-столбцов

При обновлении JSON-столбца используйте синтаксис `->` для доступа к соответствующему ключу в JSON-объекте. Эта операция поддерживается в MySQL 5.7+ и PostgreSQL 9.5+:

```php
$affected = Db::table('users')
    ->where('id', 1)
    ->update(['options->enabled' => true]);
```

### Инкремент / Декремент

Конструктор запросов также предоставляет удобные методы для увеличения или уменьшения значения указанного столбца. Это просто сокращение, предоставляющее более выразительный и лаконичный интерфейс по сравнению с ручным написанием оператора `update`.

Оба метода принимают как минимум один аргумент: столбец для изменения. Второй аргумент может быть опционально передан для управления величиной, на которую столбец должен быть увеличен / уменьшен.

```php
Db::table('users')->increment('votes');

Db::table('users')->increment('votes', 5);

Db::table('users')->decrement('votes');

Db::table('users')->decrement('votes', 5);
```

Вы также можете указать дополнительные столбцы для обновления во время операции:

```php
Db::table('users')->increment('votes', 1, ['name' => 'John']);
```

## Удаление

Конструктор запросов также может использоваться для удаления записей из таблицы с помощью метода `delete`.

```php
Db::table('users')->delete();
```

Вы можете ограничить операторы `delete`, добавив условия `where` перед вызовом метода `delete`.

```php
Db::table('users')->where('votes', '<', 100)->delete();
```

Если вы хотите очистить всю таблицу, что удалит все строки и сбросит автоинкрементный ID на ноль, используйте метод `truncate`.

```php
Db::table('users')->truncate();
```

## Пессимистическая блокировка

Конструктор запросов также включает несколько функций для выполнения «пессимистической блокировки» в операторах `select`. Для выполнения оператора с «разделяемой блокировкой» используйте метод `sharedLock` в запросе. Разделяемая блокировка предотвращает изменение выбранных строк до завершения вашей транзакции.

```php
Db::table('users')->where('votes', '>', 100)->sharedLock()->get();
```

Альтернативно вы можете использовать метод `lockForUpdate`. Блокировка «for update» предотвращает изменение строк или их выбор с другой разделяемой блокировкой.

```php
Db::table('users')->where('votes', '>', 100)->lockForUpdate()->get();
```

## Кэширование запросов

Вы можете легко кэшировать результаты запроса с помощью [сервиса кэширования](../services/cache.md). Просто добавьте метод `remember` или `rememberForever` в цепочку при подготовке запроса.

```php
$users = Db::table('users')->remember(10)->get();
```

В этом примере результаты запроса будут кэшироваться на десять минут. Пока результаты кэшированы, запрос не будет выполняться к базе данных, а результаты будут загружаться из драйвера кэширования по умолчанию, указанного для вашего приложения.

## Отладка

Вы можете использовать методы `dd` или `dump` при построении запроса для вывода привязок и SQL запроса. Метод `dd` отобразит отладочную информацию и затем остановит выполнение запроса. Метод `dump` отобразит отладочную информацию, но позволит продолжить выполнение запроса:

```php
Db::table('users')->where('votes', '>', 100)->dd();

Db::table('users')->where('votes', '>', 100)->dump();
```

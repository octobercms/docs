# Коллекции

Все наборы результатов с множественными записями, возвращаемые моделью, являются экземплярами объекта `October\Rain\Database\Collection`, включая результаты, полученные через метод `get` или доступ через связь. Объект `Collection` расширяет [базовую коллекцию](../services/collections.md), поэтому он естественным образом наследует десятки методов для удобной работы с базовым массивом моделей.

Все коллекции также служат итераторами, позволяя вам перебирать их, как простые PHP-массивы.

```php
$users = User::where('is_active', true)->get();

foreach ($users as $user) {
    echo $user->name;
}
```

Однако коллекции гораздо мощнее массивов и предоставляют различные операции map / reduce с использованием интуитивного интерфейса. Например, давайте отфильтруем все активные модели и соберём имя для каждого отфильтрованного пользователя.

```php
$users = User::get();

$names = $users->filter(function ($user) {
        return $user->is_active === true;
    })
    ->map(function ($user) {
        return $user->name;
    });
```

::: tip
Хотя большинство методов коллекции моделей возвращают новый экземпляр коллекции `Eloquent`, методы `pluck`, `keys`, `zip`, `collapse`, `flatten` и `flip` возвращают экземпляр базовой коллекции. Аналогично, если операция `map` возвращает коллекцию, не содержащую моделей, она автоматически приводится к базовой коллекции.
:::

## Доступные методы

Все коллекции моделей расширяют базовый объект коллекции; поэтому они наследуют все мощные методы, предоставляемые базовым классом коллекции.

Кроме того, класс `October\Rain\Database\Collection` предоставляет расширенный набор методов для управления вашими коллекциями моделей. Большинство методов возвращают экземпляры `October\Rain\Database\Collection`; однако некоторые методы возвращают экземпляр базовой `Illuminate\Support\Collection`.

**contains($key, $operator = null, $value = null)**

Метод `contains` может использоваться для определения, содержится ли данный экземпляр модели в коллекции. Этот метод принимает первичный ключ или экземпляр модели:

```php
$users->contains(1);

$users->contains(User::find(1));
```

**diff($items)**

Метод `diff` возвращает все модели, которые отсутствуют в данной коллекции:

```php
use App\User;

$users = $users->diff(User::whereIn('id', [1, 2, 3])->get());
```

**except($keys)**

Метод `except` возвращает все модели, которые не имеют указанных первичных ключей:

```php
$users = $users->except([1, 2, 3]);
```

**find($key)**

Метод `find` находит модель с указанным первичным ключом. Если `$key` является экземпляром модели, `find` попытается вернуть модель, совпадающую по первичному ключу. Если `$key` является массивом ключей, find вернёт все модели, которые совпадают с `$keys`, используя `whereIn()`:

```php
$users = User::all();

$user = $users->find(1);
```

**fresh($with = [])**

Метод `fresh` получает свежий экземпляр каждой модели в коллекции из базы данных. Кроме того, любые указанные связи будут жадно загружены:

```php
$users = $users->fresh();

$users = $users->fresh('comments');
```

**intersect($items)**

Метод `intersect` возвращает все модели, которые также присутствуют в данной коллекции:

```php
use App\User;

$users = $users->intersect(User::whereIn('id', [1, 2, 3])->get());
```

**load($relations)**

Метод `load` жадно загружает указанные связи для всех моделей в коллекции:

```php
$users->load('comments', 'posts');

$users->load('comments.author');
```

**loadMissing($relations)**

Метод `loadMissing` жадно загружает указанные связи для всех моделей в коллекции, если связи ещё не загружены:

```php
$users->loadMissing('comments', 'posts');

$users->loadMissing('comments.author');
```

**modelKeys()**

Метод `modelKeys` возвращает первичные ключи для всех моделей в коллекции:

```php
$users->modelKeys();

// [1, 2, 3, 4, 5]
```

**makeVisible($attributes)**

Метод `makeVisible` делает видимыми атрибуты, которые обычно являются «скрытыми» в каждой модели коллекции:

```php
$users = $users->makeVisible(['address', 'phone_number']);
```

**makeHidden($attributes)**

Метод `makeHidden` скрывает атрибуты, которые обычно являются «видимыми» в каждой модели коллекции:

```php
$users = $users->makeHidden(['address', 'phone_number']);
```

**only($keys)**

Метод `only` возвращает все модели, которые имеют указанные первичные ключи:

```php
$users = $users->only([1, 2, 3]);
```

**unique($key = null, $strict = false)**

Метод `unique` возвращает все уникальные модели в коллекции. Любые модели того же типа с тем же первичным ключом, что и другая модель в коллекции, удаляются.

```php
$users = $users->unique();
```

## Пользовательские коллекции

Если вам нужно использовать пользовательский объект `Collection` с вашими собственными методами расширения, вы можете переопределить метод `newCollection` в вашей модели:

```php
class User extends Model
{
    /**
     * Create a new Collection instance.
     */
    public function newCollection(array $models = [])
    {
        return new CustomCollection($models);
    }
}
```

После определения метода `newCollection` вы будете получать экземпляр вашей пользовательской коллекции каждый раз, когда модель возвращает экземпляр `Collection`. Если вы хотите использовать пользовательскую коллекцию для каждой модели в вашем плагине или приложении, вы должны переопределить метод `newCollection` в базовом классе модели, от которого наследуются все ваши модели.

```php
use October\Rain\Database\Collection as CollectionBase;

class CustomCollection extends CollectionBase
{
}
```

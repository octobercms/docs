# Навигация

Плагины могут расширять меню навигации панели управления, переопределяя метод `registerNavigation` [файла регистрации плагина](../extending.md). В этом разделе показано, как добавлять элементы меню в область навигации панели управления. Ниже приведён пример регистрации элемента навигации верхнего уровня с двумя элементами подменю.

```php
public function registerNavigation()
{
    return [
        'blog' => [
            'label' => 'Blog',
            'url' => Backend::url('acme/blog/posts'),
            'icon' => 'icon-pencil',
            'permissions' => ['acme.blog.*'],
            'order' => 500,

            'sideMenu' => [
                'posts' => [
                    'label' => 'Posts',
                    'icon' => 'icon-copy',
                    'url' => Backend::url('acme/blog/posts'),
                    'permissions' => ['acme.blog.access_posts'],
                ],
                'categories' => [
                    'label' => 'Categories',
                    'icon' => 'icon-copy',
                    'url' => Backend::url('acme/blog/categories'),
                    'permissions' => ['acme.blog.access_categories'],
                ]
            ]
        ]
    ];
}
```

При регистрации навигации панели управления вы можете использовать [строки локализации](../system/localization.md) для значений `label`. Навигация панели управления также может контролироваться значениями `permissions`, соответствующими определённым [разрешениям пользователей панели управления](./permissions.md). Порядок отображения навигации в общем меню контролируется значением `order`. Большие числа означают, что элемент появится позже в порядке элементов меню, а меньшие — что он появится раньше.

Для отображения элементов подменю вы можете установить контекст навигации в [контроллере панели управления](../system/controllers.md) с помощью метода `BackendMenu::setContext`. Это сделает родительский элемент меню активным и отобразит дочерние элементы в боковом меню.

Свойство | Описание
------------- | -------------
**label** | указывает ключ строки локализации метки меню, обязательно.
**order** | числовой вес для определения порядка отображения.
**icon** | имя иконки из [коллекции иконок October CMS](../../element/available-icons.md), необязательно.
**iconSvg** | SVG-иконка для использования вместо стандартной иконки, SVG-иконка должна быть прямоугольной и может поддерживать цвета, необязательно.
**url** | URL, на который должен указывать элемент меню (например, `Backend::url('author/plugin/controller/action')`), обязательно.
**counter** | числовое значение для отображения рядом с иконкой меню. Значение должно быть числом или вызываемым объектом, возвращающим число, необязательно.
**counterLabel** | строковое значение для описания числовой ссылки в counter, необязательно.
**attributes** | ассоциативный массив атрибутов и значений для применения к элементу меню, необязательно.
**permissions** | массив разрешений, которые пользователь панели управления должен иметь для просмотра элемента меню (Примечание: прямой доступ по URL всё равно требует отдельных проверок разрешений), необязательно.
**sideMenu** | массив элементов подменю, использующих ту же конфигурацию, что и родительские элементы, необязательно.
**itemType** | указывает тип отображения элемента, только для элементов подменю. Поддерживаемые: `primary`, `link`, `ruler`, `section`. По умолчанию: `link`.

Следующие значения генерируются системой и не предоставляются при регистрации элементов навигации.

Ключ | Описание
------------- | -------------
**code** | строковое значение, действующее как уникальный идентификатор для этого элемента меню.
**owner** | строковое значение, указывающее владельца элемента меню — плагин или модуль в формате «Author.Plugin».

## Счётчики навигации

Элементы навигации поддерживают указание счётчика, чтобы показать, что есть элементы, требующие внимания. Эти свойства доступны как для родительских, так и для дочерних элементов меню. Используйте **counter** и **counterLabel** для отображения числового счётчика.

```php
'blog' => [
    // ...
    'counter' => [\Author\Plugin\Classes\MyMenuCounterService::class, 'getCounterMethod'],
    'counterLabel' => 'Label describing a dynamic menu counter',
],
```

## Типы отображения элементов

Элементы подменю поддерживают различные типы отображения с помощью свойства `itemType`, включая элементы пользовательского интерфейса. Установите тип `section` для отображения секции навигации. Добавление префикса подчёркивания (`_`) к имени ключа — хороший способ обозначить, что это элемент интерфейса.

```php
'_section1' => [
    'itemType' => 'section',
    'label' => 'Advanced',
],
```

Может быть полезно сочетать секцию с разделителем навигации, расположенным над ней. Установите тип `ruler` для отображения разделителя.

```php
'_ruler1' => [
    'itemType' => 'ruler',
],
```

Для отображения призыва к действию установите тип `primary`, чтобы отобразить ссылку как кнопку основного действия.

```php
'people_create' => [
    'label' => 'New Person',
    'icon' => 'icon-plus',
    'url' => Backend::url('acme/blog/people/create'),
    'itemType' => 'primary',
],
```

## Расширение меню панели управления

[Обработчик события](../extending.md) `backend.menu.extendItems` может использоваться для модификации существующих элементов навигации после того, как система и плагины зарегистрировали свои элементы навигации. Событие возвращает экземпляр менеджера навигации `$manager`, поддерживающий следующие методы.

Метод | Описание
------------- | -------------
**addMainMenuItems($owner, $definitions)** | Добавить или обновить определение главного меню
**getMainMenuItem($owner, $code)** | Получить существующее определение главного меню
**removeMainMenuItem($owner, $code)** | Удалить существующее определение главного меню
**addSideMenuItems($owner, $code, $definitions)** | Добавить или обновить определение бокового меню
**getSideMenuItem($owner, $code, $sideCode)** | Получить существующее определение бокового меню
**removeSideMenuItem($owner, $code, $sideCode)** | Удалить существующее определение бокового меню

При получении элемента меню объект поддерживает цепочку методов для обновления его свойств. Следующий пример заменит метку Редактора на **Code Editor**.

```php
Event::listen('backend.menu.extendItems', function($manager) {
    $manager->getMainMenuItem('October.Editor', 'editor')->label('Code Editor');
});
```

Следующий пример изменит метку на **News** и добавит счётчик **9** к плагину Acme Blog.

```php
Event::listen('backend.menu.extendItems', function($manager) {
    $manager->getMainMenuItem('Acme.Blog', 'blog')
        ->getSideMenuItem('posts')
        ->label('News')
        ->counter(9);
});
```

Аналогично мы можем удалить элементы меню, используя то же событие. Следующий пример удалит все элементы, один элемент и несколько элементов соответственно.

```php
Event::listen('backend.menu.extendItems', function($manager) {
    $manager->removeMainMenuItem('Acme.Blog', 'blog');

    $manager->removeSideMenuItem('Acme.Blog', 'blog', 'posts');

    $manager->removeSideMenuItems('Acme.Blog', 'blog', [
        'posts',
        'categories'
    ]);
});
```

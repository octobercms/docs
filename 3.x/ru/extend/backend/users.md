# Пользователи

Управление пользователями панели управления работает с администраторами, где модель `Backend\Models\User` является контейнером, хранящим всю важную информацию о пользователе. Она включает такие функции, как роли, группы, разрешения, сброс пароля и ограничение попыток входа. Плагины также могут [регистрировать разрешения](./permissions.md), контролирующие доступ к функциям в панели управления.

## Вспомогательный класс пользователя панели управления

Глобальный фасад `BackendAuth` может использоваться для управления административными пользователями и в основном наследует класс `October\Rain\Auth\Manager`. Для регистрации новой учётной записи администратора используйте метод `BackendAuth::register`.

```php
$user = BackendAuth::register([
    'first_name' => 'Some',
    'last_name' => 'User',
    'login' => 'someuser',
    'email' => 'some@website.tld',
    'password' => 'changeme',
    'password_confirmation' => 'changeme'
]);
```

Метод `BackendAuth::check` — это быстрый способ проверить, авторизован ли пользователь. Для возврата модели авторизованного пользователя используйте `BackendAuth::getUser`. Кроме того, активный пользователь будет доступен как `$this->user` внутри любого [контроллера панели управления](../system/controllers.md).

```php
// Returns true if signed in.
$loggedIn = BackendAuth::check();

// Returns the signed in user
$user = BackendAuth::getUser();
```

Вы можете найти пользователя по его логину с помощью метода `BackendAuth::findUserByLogin`.

```php
$user = BackendAuth::findUserByLogin('someuser');
```

Вы можете аутентифицировать пользователя, указав его логин и пароль с помощью `BackendAuth::authenticate`. Вы также можете аутентифицироваться как пользователь, просто передав модель `Backend\Models\User` в `BackendAuth::login`.

```php
// Authenticate user by credentials
$user = BackendAuth::authenticate([
    'login' => post('login'),
    'password' => post('password')
]);

// Sign in as a specific user
BackendAuth::login($user);
```

## Группы

Группы пользователей используют модель `Backend\Models\UserGroup` и являются организационным инструментом для группировки администраторов. Они не связаны с [разрешениями пользователей](./permissions.md) и предназначены исключительно для организационных целей, таких как уведомления.

Например, если вы хотите отправить электронное письмо всем пользователям в группе `Head Office Staff`, вы можете найти группу пользователей вместе с пользователями в этой группе.

```php
$group = UserGroup::where('code', 'head-office-staff')->first();

Mail::sendTo($group->users, 'author.plugin:important_notification');
```

## Изменение пароля пользователя панели управления

Команда `october:passwd` позволяет изменить пароль администратора панели управления через командную строку. Это полезно, если вы потеряли доступ к установке October CMS или для изменения пароля учётной записи администратора по умолчанию.

```bash
php artisan october:passwd username password
```

Первым аргументом вы можете передать либо логин, либо адрес электронной почты. Вторым аргументом вы можете опционально передать желаемый пароль, в противном случае вам будет предложено его ввести.

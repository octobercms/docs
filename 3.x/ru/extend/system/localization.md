# Локализация

::: aside
Языковые строки, определённые здесь, будут загружены только в панели управления. Для перевода фронтенд-контента посетите [статью о локализации темы](../../cms/themes/settings.md).
:::

Плагины могут иметь файлы локализации в поддиректории **lang**. Файлы локализации плагинов используют формат JSON и автоматически обнаруживаются системой в панели управления. Использование строк локализации нативно поддерживается в меню пользовательского интерфейса панели управления, метках форм и т.д.

## Активный язык

Язык по умолчанию для вашего приложения хранится в опции конфигурации locale файла `config/app.php`. Вы можете свободно изменять это значение в соответствии с потребностями вашего приложения. Каждый пользователь может установить предпочитаемую локаль через **Меню пользователя → Настройки панели управления**.

Вы можете проверить активный язык в PHP с помощью метода `App::getLocale` и установить активный язык с помощью `App::setLocale`, передав код языка как первый аргумент.

```php
App::getLocale();

App::setLocale('fr');
```

## Структура файлов локализации

Ниже приведён пример директории **lang** плагина.

::: dir
├── plugins
|   └── acme
|       └── todo
|           └── `lang`
|               ├── en.json  _← Файл локализации_
|               └── fr.json  _← Файл локализации_
:::

Использование JSON-файлов для локализации является предпочтительным методом перевода, где строки используют «стандартный» перевод строки в качестве ключа. Например, если ваше приложение имеет французский перевод, вы должны создать файл `lang/fr.json`.

```json
{
    "I love programming.": "j'adore programmer"
}
```

::: tip
Laravel предлагает метод перевода на основе PHP как поддерживаемую альтернативу использованию JSON. Подробнее см. [статью о локализации Laravel](https://laravel.com/docs/10.x/localization).
:::

## Доступ к строкам локализации

Строки локализации могут быть загружены с помощью вспомогательной функции `__()`, передав стандартный перевод вашей строки.

```php
echo __('I love programming.');
```

Замена параметров в строках перевода возможна при передаче массива вторым аргументом. Каждое имя параметра начинается с символа `:`.

```php
echo __(':name loves programming.', ['name' => 'Jeff']);
```

### Множественное число

Разные языки могут иметь различные сложные правила для множественного числа. С помощью символа `|` вы можете разделить формы единственного и множественного числа строки.

```json
{
    "There is one apple|There are many apples": "Il y a une pomme|Il y a beaucoup de pommes"
}
```

Более сложные правила множественного числа могут определять строки перевода для нескольких диапазонов значений.

```json
{
    "{0} There are none|[1,19] There are some|[20,*] There are many": "..."
}
```

Функция `trans_choice` используется для обработки значений множественного числа.

```php
echo __('There is one apple|There are many apples', 3);
```

## Переопределение строк локализации

Пользователи системы могут переопределять строки локализации плагинов без изменения файлов плагинов. Это делается добавлением файлов локализации в директорию **lang**. Например, для переопределения французских переводов создайте файл в следующем расположении:

::: dir
├── app
|   └── `lang`
|       └── fr.json  _← Файл переопределения_
:::

Файл может содержать только строки, которые вы хотите переопределить, нет необходимости заменять весь файл. Пример:

```json
{
    "I love programming.": "Coding is the best!"
}
```

Некоторые плагины могут поставляться со своими собственными файлами языка на PHP. Вы можете переопределить их в том же расположении. Используйте полный языковой ключ в JSON-файле, например, для переопределения значения `rainlab.blog::lang.post_label`.

```json
{
    "rainlab.blog::lang.post_label": "Article"
}
```

Вы также можете использовать вложенную структуру папок для переопределения файла в формате PHP. Например, для плагина **Acme.Blog** поместите файл в `lang/acme/blog/en/lang.php`.

::: dir
├── app
|   └── lang
|       └── `acme`  _← Автор плагина_
|           └── `todo`  _← Имя плагина_
|               └── en
|                   └── lang.php  _← Файл переопределения_
:::

### Программное переопределение строк

Вы можете переопределять языковые строки в PHP с помощью метода `Lang::set`. Он принимает языковой ключ и новое переведённое значение как аргументы.

```php
Lang::set('I love programming.', 'Coding is the best!');
```

По умолчанию это переопределит активную локаль, третий аргумент позволяет указать явную локаль. Следующий пример заменяет значение для французского.

```php
Lang::set('I love programming.', 'Le codage est le meilleur!', 'fr');
```

## Участие в переводе языковых строк

October CMS использует сервис Crowdin для более эффективного управления переводами на популярные языки. Он также выполняет автоматические машинные переводы с помощью API перевода Google для всех остальных языков. Если вы обнаружите отсутствующие или неправильные переводы в October CMS, следуйте инструкциям ниже.

### Использование Crowdin

Вы можете проверить, поддерживается ли ваш язык проектом Crowdin, по ссылке ниже. Этот сервис позволяет вносить переводы с помощью удобного интерфейса.

- [Страница проекта October CMS на Crowdin](https://crowdin.com/project/octobercms)

Если ваш язык не отображается на этой странице, следуйте инструкциям GitHub ниже. Языки добавляются в Crowdin, когда мы замечаем, что язык становится более активным на GitHub.

### Использование GitHub

Вы можете посетить [репозиторий на GitHub](https://github.com/octobercms/october/tree/develop/modules), чтобы предложить обновления для вашего языка с помощью pull request. Языковые файлы находятся в различных модулях, поэтому вам может потребоваться проверить несколько файлов, чтобы найти нужную языковую строку. В этом примере мы будем изменять голландский язык, используя код языка `nl`, и мы знаем, что строка находится в модуле Tailor.

1. Откройте [репозиторий GitHub](https://github.com/octobercms/october/tree/develop/modules).
2. Нажмите на **tailor**, затем **lang** для открытия директории языков Tailor.
3. Нажмите на файл **nl.json** для открытия языкового файла голландского.
4. В правом верхнем углу нажмите значок карандаша для **редактирования файла**.

В файле вы увидите английскую версию слева и голландскую версию справа, например:

```json
{
  "Manage Entries": "Invoer beheren",
  "Create :name Entry": "Maak :name invoer"
}
```

При обновлении изменяйте только правую сторону, содержащую переведённое значение. Некоторые значения могут содержать переменные, такие как `:name`, — их следует оставить без изменений. После завершения нажмите кнопку **Commit changes** для отправки нового Pull Request. Он будет рассмотрен командой и включён в последующие релизы.

::: tip
Если языковой ключ не существует или вы не можете его найти, вы можете [связаться с нами для получения помощи](https://octobercms.com/contact).
:::

# Рендеринг представлений

Представления находятся в директории, имя которой совпадает с именем контроллера.

::: dir
├── plugins
|   └── acme
|       └── blog
|           ├── controllers
|           |   ├── users  _← Директория представлений_
|           |   |   ├── `_partial.php`  _← Файл частичного представления_
|           |   |   └── `index.php`  _← Файл представления_
|           |   └── Users.php  _← Класс контроллера_
|           └── Plugin.php
:::

## Частичные представления

Частичные представления панели управления — это файлы с расширением **php**, расположенные в [директории представлений контроллера](./controllers.md). Имена файлов частичных представлений должны начинаться с подчёркивания: **_partial.php**. Частичные представления могут быть отрендерены со страницы панели управления или из другого частичного представления. Используйте метод контроллера `makePartial` для рендеринга частичного представления. Метод принимает два параметра — имя частичного представления и необязательный массив переменных для передачи. Пример:

```php
<?= $this->makePartial('sidebar', ['showHeader' => true]) ?>
```

### Подсказки (Hint Partials)

Вы можете отображать информационные панели в панели управления, называемые подсказками, которые пользователь может скрыть. Первый параметр должен быть уникальным ключом для запоминания, была ли подсказка скрыта или нет. Второй параметр — это ссылка на частичное представление. Третий параметр может содержать дополнительные переменные для передачи в частичное представление, а также некоторые свойства подсказки.

```php
<?= $this->makeHintPartial('my_hint_key', 'my_hint_partial', ['foo' => 'bar']) ?>
```

Вы также можете отключить возможность скрытия подсказки, установив значение ключа в null. Такая подсказка будет отображаться всегда:

```php
<?= $this->makeHintPartial(null, 'my_hint_partial') ?>
```

Доступны следующие свойства:

Свойство | Описание
------------- | -------------
**type** | Устанавливает цвет подсказки, поддерживаемые типы: danger, info, success, warning. По умолчанию: info.
**title** | Добавляет раздел заголовка к подсказке.
**subtitle** | В дополнение к заголовку добавляет вторую строку в раздел заголовка.
**icon** | В дополнение к заголовку добавляет иконку в раздел заголовка.

### Проверка скрытия подсказок

При использовании подсказок может быть полезно проверить, скрыл ли их пользователь. Это легко сделать с помощью метода `isBackendHintHidden`. Он принимает единственный параметр — уникальный ключ, указанный при первоначальном вызове `makeHintPartial`. Метод возвращает true, если подсказка была скрыта, и false в противном случае:

```php
<?php if ($this->isBackendHintHidden('my_hint_key')): ?>
    <!-- Do something when the hint is hidden -->
<?php endif ?>
```

## Макеты и дочерние макеты

Макеты панели управления находятся в необязательной директории **layouts/** плагина. Пользовательский макет задаётся свойством `$layout` объекта контроллера. По умолчанию используется системный макет `default`.

```php
/**
 * @var string layout to use for the view.
 */
public $layout = 'mycustomlayout';
```

Макеты также предоставляют возможность добавления пользовательских CSS-классов к тегу BODY. Это можно задать через свойство `$bodyClass` контроллера.

```php
/**
 * @var string bodyClass (CSS) to add to the layout.
 */
public $bodyClass = 'compact-container';
```

Для макета по умолчанию доступны следующие классы body:

- **compact-container** — убирает отступы со всех сторон.
- **slim-container** — убирает отступы слева и справа.
- **breadcrumb-flush** — заставляет хлебные крошки страницы прилегать вплотную к элементу ниже.

### Форма с боковой панелью

Макеты также могут использоваться подобно частичным представлениям, действуя как глобальное частичное представление. Система предоставляет пример `form-with-sidebar`, демонстрирующий новый способ реализации структуры дочерних макетов.

Перед использованием этого стиля макета убедитесь, что ваш контроллер использует класс body `compact-container`, установив его в методе действия контроллера или конструкторе.

```php
$this->bodyClass = 'compact-container';
```

Этот макет использует два заполнителя: область основного контента **form-contents** и дополнительную боковую панель **form-sidebar**. Пример:

```php
<!-- Primary content -->
<?php Block::put('form-contents') ?>
    Main content
<?php Block::endPut() ?>

<!-- Complimentary sidebar -->
<?php Block::put('form-sidebar') ?>
    Side content
<?php Block::endPut() ?>

<!-- Layout execution -->
<?php Block::put('body') ?>
    <?= Form::open(['class'=>'layout stretch']) ?>
        <?= $this->makeLayout('form-with-sidebar') ?>
    <?= Form::close() ?>
<?php Block::endPut() ?>
```

Макет выполняется в последней секции путём переопределения заполнителя **body**, используемого каждым макетом панели управления. Он оборачивает всё HTML-тегом `<form />` и рендерит дочерний макет **form-with-sidebar**. Этот файл расположен в **modules/backend/layouts/form-with-sidebar.php**.

## Расширение макета

Метод `fireViewEvent` используется в нескольких местах для [расширения области панели управления](../extending.md). Событие `backend.layout.extendHead` может использоваться для расширения элемента head макета. Возвращаемое значение должно содержать разметку для включения. Следующий пример добавляет JavaScript-файл на каждую страницу панели управления.

```php
Event::listen('backend.layout.extendHead', function ($controller) {
    return '<script src="/app/assets/js/myscript.js"></script>';
});
```

Контроллер доступен (первый аргумент) в событии, что можно использовать для таргетирования конкретных контроллеров. Следующий пример добавляет определённые CSS-стили только к контроллеру записей Tailor.

```php
Event::listen('backend.layout.extendHead', function ($controller) {
    if ($controller instanceof \Tailor\Controllers\Entries) {
        return '<styles> /* ... */ </styles>';
    }
});
```

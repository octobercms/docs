# Виджеты

Виджеты — это повторно используемые элементы управления, имеющие пользовательский интерфейс и контроллер панели управления (класс виджета), который подготавливает данные виджета и обрабатывает AJAX-запросы, генерируемые пользовательским интерфейсом виджета.

## Общие виджеты

Виджеты являются аналогом [CMS-компонентов](../../cms/themes/components.md) для панели управления. Они похожи тем, что представляют собой модульные блоки функциональности, предоставляют частичные представления и именуются с помощью псевдонимов. Ключевое отличие в том, что виджеты панели управления используют YAML-разметку для своей конфигурации и привязываются к контроллерам панели управления вручную.

Классы виджетов находятся в директории **widgets** директории плагина. Имя внутренней директории совпадает с именем класса виджета в нижнем регистре. Виджеты могут предоставлять ресурсы и частичные представления. Пример структуры директории виджета:

::: dir
├── `widgets`
|   ├── form
|   |   ├── partials
|   |   |   └── _form.php  _← Файл частичного представления_
|   |   └── assets
|   |       ├── js
|   |       |   └── form.js  _← JavaScript-файл_
|   |       └── css
|   |           └── form.css  _← Файл стилей_
|   └── Form.php  _← Класс виджета_
:::

### Определение класса

Классы общих виджетов должны наследовать класс `Backend\Classes\WidgetBase`. Как и любой другой класс плагина, контроллеры общих виджетов должны принадлежать [пространству имён плагина](./plugins.md). Ниже приведён пример определения класса виджета.

```php
namespace Backend\Widgets;

use Backend\Classes\WidgetBase;

class Lists extends WidgetBase
{
    /**
     * @var string defaultAlias to identify this widget.
     */
    protected $defaultAlias = 'list';

    // ...
}
```

Класс виджета должен содержать метод **render()** для формирования разметки виджета путём рендеринга частичного представления виджета. Пример:

```php
public function render()
{
    return $this->makePartial('list');
}
```

Для передачи переменных в частичные представления вы можете добавить их в свойство `$vars`.

```php
public function render()
{
    $this->vars['var'] = 'value';

    return $this->makePartial('list');
}
```

Альтернативно вы можете передать переменные вторым параметром метода makePartial():

```php
public function render()
{
    return $this->makePartial('list', ['var' => 'value']);
}
```

## Привязка виджетов к контроллерам

::: aside
Привязка к контроллеру также необходима для того, чтобы сделать [AJAX-обработчики доступными](./ajax.md).
:::

Виджет должен быть привязан к контроллеру панели управления, прежде чем вы сможете начать его использовать на странице или в частичном представлении панели управления. Используйте метод виджета `bindToController` для привязки к контроллеру. Лучшее место для инициализации виджета — метод контроллера `beforeDisplay`, который вызывается из конструктора.

Например, создание нового экземпляра виджета и привязка его к контроллеру. Обратите внимание, что конструктор принимает контроллер как первый аргумент.

```php
public function beforeDisplay()
{
    $myWidget = new MyWidgetClass($this);
    $myWidget->alias = 'myWidget';
    $myWidget->bindToController();
}
```

После привязки виджета вы можете обращаться к нему в представлении или частичном представлении контроллера по его псевдониму через свойство `$this->widget`.

```php
<?= $this->widget->myWidget->render() ?>
```

## Выполнение кода перед AJAX-обработчиками

Иногда вам может потребоваться выполнить код перед запуском AJAX-обработчика. Определение метода `init` в виджете позволяет выполнять код перед каждым AJAX-обработчиком.

```php
function init()
{
    // From a widget class
}
```

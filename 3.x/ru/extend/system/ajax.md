# AJAX

Панель управления использует ту же [AJAX-библиотеку, что и CMS](../../cms/ajax/introduction.md)-страницы. Библиотека включена и загружается автоматически на страницах панели управления.

## AJAX-обработчики панели управления

AJAX-обработчики панели управления могут быть определены в классе контроллера или виджетах. В классе контроллера AJAX-обработчики определяются как публичные методы с именами, начинающимися со строки "on": **onCreateTemplate**, **onGetTemplateList** и т.д.

AJAX-обработчики панели управления могут возвращать массив данных, выбрасывать исключение или перенаправлять на другую страницу. Вы можете использовать `$this->vars` для установки переменных и метод контроллера `makePartial` для рендеринга частичного представления и возврата его содержимого как части данных ответа.

```php
public function onOpenTemplate()
{
    if (post('someVar') !== 'someValue') {
        throw new ApplicationException('Invalid value');
    }

    $this->vars['foo'] = 'bar';

    return [
        'partialContents' => $this->makePartial('some-partial')
    ];
}
```

### Вызов AJAX-запросов

AJAX-запрос может быть вызван через API атрибутов данных или JavaScript API. Подробнее см. [фронтенд AJAX-библиотеку](../ajax/introduction). Следующий пример показывает, как вызвать запрос кнопкой в панели управления.

```html
<button
    type="button"
    data-request="onDoSomething"
    class="btn btn-default">
    Do Something
</button>
```

## AJAX-обработчики поведений

Поскольку поведения объединяют свои методы с родительским контроллером, все AJAX-обработчики, определённые в поведении, доступны контроллеру. В некоторых случаях вы можете захотеть переопределить AJAX-обработчик в контроллере — для этого вызовите метод `asExtension`.

AJAX-обработчик контроллера имеет приоритет, затем запрашивается поведение `Backend\Behaviors\FormController` и вызывается его обработчик.

```php
function onDoSomething()
{
    // Custom logic here
    // ...

    // Call the extension handler
    return $this->asExtension('FormController')->doSomething();
}
```

## AJAX-обработчики виджетов

Виджеты реализуют тот же AJAX-подход, что и контроллеры панели управления. AJAX-обработчики — это публичные методы класса виджета с именами, начинающимися с префикса **on**. Единственное отличие между AJAX-обработчиками виджета и контроллера панели управления в том, что для ссылки на обработчик в частичных представлениях виджета следует использовать метод виджета `getEventHandler`.

```php
<a
    href="javascript:;"
    data-request="<?= $this->getEventHandler('onPaginate') ?>"
    title="Next page">Next</a>
```

При вызове из класса виджета или частичного представления AJAX-обработчик будет нацелен на сам виджет. Например, если виджет использует псевдоним **mywidget**, обработчик будет вызван как `mywidget::onName`. Код выше выведет следующее значение атрибута:

```html
data-request="mywidget::onPaginate"
```

# Файловые настройки

Файловые настройки хранят значения в файлах и могут быть переопределены переменными окружения или файлами приложения.

## Структура файла конфигурации

Плагины могут использовать файловую конфигурацию в поддиректории **config** директории плагина. Ниже приведён пример директории **config** плагина.

::: dir
├── plugins
|   └── acme
|       └── todo
|           └── `config`
|               ├── config.php  _← Файл конфигурации_
|               └── custom.php  _← Файл конфигурации_
:::

Файлы конфигурации — это PHP-скрипты, которые определяют и возвращают **массив**. Ниже приведён пример файла конфигурации **config.php**.

```php
return [
    'maxItems' => 10,
    'display' => 5
];
```

## Доступ к значениям конфигурации

Используйте фасад `Config` для доступа к значениям конфигурации, определённым в файле конфигурации. Метод `get` принимает имя плагина и имя конфигурации (первый аргумент) в следующем формате: **acme.demo::maxItems**. Вы также можете определить значение по умолчанию (второй аргумент), которое возвращается, если параметр конфигурации не существует.

```php
$maxItems = Config::get('acme.demo::maxItems', 50);
```

Использование другого имени файла конфигурации влияет на имя ключа. Например, файл конфигурации с именем **custom.php** добавит префикс `custom` к имени ключа в следующем формате: **acme.demo::custom.maxItems**. Следующий пример основан на файле конфигурации с именем **custom.php**.

```php
$maxItems = Config::get('acme.demo::custom.maxItems', 50);
```

## Переопределение значений конфигурации

Файл конфигурации плагина может быть переопределён приложением путём создания соответствующего локального файла конфигурации. Например, для переопределения **plugins/acme/demo/config/config.php** создайте файл **config/acme/todo/config.php**.


::: dir
├── config
|   └── `acme`
|       └── `todo`
|           └── config.php  _← Файл переопределения_
:::

Внутри переопределённого файла конфигурации вы можете возвращать только те значения, которые хотите переопределить.

```php
return [
    'maxItems' => 20
];
```

Если вы хотите использовать разные конфигурации для разных окружений (например: **dev**, **production**), рассмотрите использование хелпера `env()` для получения значения из переменной окружения. Функция `env()` принимает имя переменной окружения (первый аргумент) и необязательное значение по умолчанию, если переменная не существует (второй аргумент).

```php
<?php

return [
    'maxItems' => env('ACME_TODO_MAX_ITEMS', 25)
];
```

Это изменит значение `maxItems`, когда переменная окружения `ACME_TODO_MAX_ITEMS` будет установлена в любое другое значение. Например, внутри файла **.env** приложения. Смотрите [статью о конфигурации](../../setup/configuration.md), чтобы узнать, как изменять эти значения в зависимости от окружения.

```ini
ACME_TODO_MAX_ITEMS=10
```

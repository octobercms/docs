# Обновление фрагментов

Когда обработчик выполняется, он может подготавливать фрагменты для обновления на странице, как путём отправки (push), так и путём запроса (pull), которые могут быть отрендерены с предоставленными переменными.

## Запрос обновлений фрагментов (Pull)

Клиентский браузер может запрашивать обновление фрагментов с сервера при выполнении AJAX-запроса, что считается *запросом обновления содержимого*.

С помощью [тега `{% partial %}`](../../markup/tag/partial.md) следующий код рендерит фрагмент **mytime** внутри элемента `#myDiv` на странице при вызове [обработчика событий](./handlers.md) `onRefreshTime`.

```twig
<div id="myDiv">
    {% partial 'mytime' %}
</div>
```

[API атрибутов данных](./attributes-api.md) использует атрибут `data-request-update`.

```html
<!-- Attributes API -->
<button
    data-request="onRefreshTime"
    data-request-update="{ mytime: '#myDiv' }">
    Go
</button>
```

[JavaScript API](./javascript-api.md) использует опцию конфигурации `update`:

```js
// JavaScript API
oc.request('#mybutton', 'onRefreshTime', {
    update: { mytime: '#myDiv' }
});
```

### Самообновляющиеся фрагменты

[Тег `{% ajaxPartial %}`](../../markup/tag/ajax-partial.md) предназначен для рендеринга AJAX-фрагментов.

```twig
{% ajaxPartial 'mytime' %}
```

При использовании этого тега содержимое автоматически оборачивается в контейнер, что позволяет обновлять фрагмент только по имени. Просто передайте значение `true` вместо CSS-селектора контейнера.

```html
<button
    data-request="onRefreshTime"
    data-request-update="{ mytime: true }">
    Go
</button>
```

Вы также можете использовать имя фрагмента `_self` для обновления фрагмента изнутри самого себя.

```js
{ _self: true }
```

::: tip
Подробнее о теге `{% ajaxPartial %}` читайте в [статье о Twig-теге AJAX Partial](../../markup/tag/ajax-partial.md).
:::

### Глобальные обновления фрагментов

В некоторых случаях, например с [flash-сообщениями](../../cms/features/flash-messages.md), вы можете захотеть включить определённое обновление фрагмента в каждый ответ. Чтобы объединить определение обновления с каждым AJAX-запросом, добавьте мета-тег `ajax-request-update` в секцию head страницы и установите атрибут content в определение обновления.

```html
<head>
    <meta name="ajax-request-update" content="{ flash-messages: true }" />
</head>
```

## Определение обновления

Определение того, что должно быть обновлено, задаётся как JSON-подобный объект, где:

- левая сторона (ключ) — это **имя фрагмента**
- правая сторона (значение) — это **целевой элемент** для обновления

Следующий пример запрашивает обновление элемента `#myDiv` содержимым фрагмента **mypartial**.

```js
{ mypartial: '#myDiv' }
```

::: tip
Селектор должен начинаться с символа `#` или `.`, чтобы быть валидным.
:::

Несколько фрагментов разделяются запятыми.

```js
{ firstpartial: '#myDiv', secondpartial: '#otherDiv' }
```

Если имя фрагмента содержит слеш или дефис, важно заключить левую сторону в кавычки.

```js
{ 'folder/mypartial': '#myDiv', 'my-partial': '#myDiv' }
```

Целевой элемент всегда находится справа, так как он также может быть HTML-элементом в JavaScript.

```js
{ 'folder/mypartial': document.getElementById('myDiv') }
```

### Добавление и вставка содержимого

Если строка селектора предваряется символом `@`, содержимое, полученное от сервера, будет добавлено в конец элемента, вместо замены существующего содержимого.

Если строка селектора предваряется символом `^`, содержимое будет вставлено в начало.

```js
{ 'folder/append-partial': '@#myDiv' }

{ 'folder/prepend-partial': '^#myDiv' }
```

Альтернативно, вы можете добавить атрибут `data-ajax-update-mode` к целевому элементу.

```html
<div id="myDiv" data-ajax-update-mode="append"></div>

<div id="myDiv" data-ajax-update-mode="prepend"></div>
```

### Использование пользовательских HTML-селекторов

Если строка селектора начинается с символа `=`, вы можете использовать любой пользовательский HTML-селектор для нацеливания на элемент.

```js
{ 'folder/append': '=[data-field-name="address"]' }
```

## Отправка обновлений фрагментов (Push)

Для сравнения, [AJAX-обработчики](./handlers.md) могут отправлять обновления содержимого в клиентский браузер со стороны сервера. Для отправки обновления обработчик возвращает массив, где ключ — это HTML-элемент для обновления (с использованием простого CSS-селектора), а значение — содержимое для обновления.

::: aside
Имя ключа должно начинаться с идентификатора `#` или символа класса `.` для инициирования обновления содержимого.
:::

Следующий пример обновит элемент на странице с id **myDiv** содержимым фрагмента **mypartial**. Обработчик `onRefreshTime` вызывает метод `renderPartial` для рендеринга содержимого фрагмента в PHP.

```php
function onRefreshTime()
{
    return [
        '#myDiv' => $this->renderPartial('mypartial')
    ];
}
```

## Передача переменных фрагментам

В зависимости от контекста выполнения, [AJAX-обработчик событий](./handlers.md) предоставляет переменные фрагментам по-разному.

- Используйте `$this[]` внутри [PHP-секции](../themes/themes.md) страницы или макета.
- Используйте `$this->page[]` внутри [класса компонента](../themes/components.md).
- Используйте `$this->vars[]` в [области администрирования](../../extend/system/controllers.md).

Эти примеры предоставят переменную **result** фрагменту для каждого контекста:

```php
// From page or layout PHP code section
$this['result'] = 'Hello world!';

// From a component class
$this->page['result'] = 'Hello world!';

// From a backend controller or widget
$this->vars['result'] = 'Hello world!';
```

Это значение может быть доступно с помощью Twig во фрагменте:

```twig
<!-- Hello world! -->
{{ result }}
```

# API атрибутов данных

API атрибутов данных позволяет выполнять AJAX-запросы без использования JavaScript. Во многих случаях API атрибутов данных менее многословен, чем JavaScript API — вы пишете меньше кода для достижения того же результата. Поддерживаемые AJAX-атрибуты данных:

data-request Attribute | Description
------------- | -------------
**data-request** | указывает имя AJAX-обработчика.
**data-request-confirm** | указывает сообщение подтверждения. Диалог подтверждения отображается перед отправкой запроса. Если пользователь нажмёт кнопку «Отмена», запрос не будет отправлен.
**data-request-redirect** | указывает URL для перенаправления браузера после успешного AJAX-запроса.
**data-request-url** | указывает URL, на который отправляется запрос. По умолчанию: `window.location.href`
**data-request-update** | указывает список фрагментов и элементов страницы (CSS-селекторов) для обновления. Формат: `partial: selector, partial: selector`. В некоторых случаях необходимо использовать кавычки, например: `'my-partial': '#myelement'`. Строка селектора должна начинаться с символа `#` или `.`, также можно добавить `@` для добавления содержимого в конец элемента, `^` для добавления в начало, `!` для замены и `=` для использования любого CSS-селектора.
**data-request-data** | указывает дополнительные POST-параметры для отправки на сервер. Формат: `var: value, var: value`. При необходимости используйте кавычки: `var: 'some string'`. Атрибут может использоваться на вызывающем элементе, например на кнопке, которая также имеет атрибут `data-request`, на ближайшем элементе вызывающего элемента и на родительском элементе формы. Фреймворк объединяет значения атрибутов `data-request-data`. Если атрибут на разных элементах определяет параметры с одинаковым именем, фреймворк использует следующий приоритет: `data-request-data` вызывающего элемента, `data-request-data` ближайших родительских элементов, данные полей ввода формы.
**data-request-query** | указывает дополнительные GET-параметры для отправки на сервер и добавления к текущей строке запроса URL.
**data-request-before-update** | указывает JavaScript-код для выполнения непосредственно перед обновлением содержимого страницы.
**data-request-success** | указывает JavaScript-код для выполнения после успешного завершения запроса. Переменная `data` доступна в этой функции и содержит данные ответа.
**data-request-error** | указывает JavaScript-код для выполнения при возникновении ошибки запроса. Переменная `data` доступна в этой функции и содержит данные ответа.
**data-request-complete** | указывает JavaScript-код для выполнения при успешном завершении запроса или при возникновении ошибки. Переменная `data` доступна в этой функции и содержит данные ответа.
**data-request-cancel** | указывает JavaScript-код для выполнения, если пользователь прерывает запрос или отменяет его через диалог подтверждения.
**data-request-message** | отображает сообщение о ходе выполнения с указанным текстом, показываемое во время выполнения запроса. Эта опция используется [функцией flash-сообщений](../features/flash-messages.md).
**data-request-loading** | указывает CSS-селектор элемента, отображаемого во время выполнения запроса. Вы можете использовать эту опцию для показа индикатора загрузки AJAX. Функция использует CSS-свойство display со значениями `block` и `none` для управления видимостью элемента.
**data-request-progress-bar** | включает [индикатор прогресса](../features/loaders.md) при выполнении AJAX-запроса.
**data-request-form** | явно указывает элемент формы для получения данных формы. Если не указан, используется ближайшая форма к вызывающему элементу, включая случай, когда сам элемент является формой.
**data-request-flash** | при включении инструктирует сервер очистить и отправить любые flash-сообщения с ответом. Эта опция используется [функцией flash-сообщений](../features/flash-messages.md).
**data-request-files** | при указании запрос будет принимать загрузку файлов с использованием интерфейса `FormData`.
**data-request-download** | при указании принимаются загрузки файлов с ответом `Content-Disposition`. Этот атрибут может быть добавлен анонимно или установлен в имя загружаемого файла.
**data-request-bulk** | при указании запрос будет отправлен как JSON для массовых операций с данными.
**data-browser-target** | при указании вместе с `data-request-download` вывод будет направлен в указанное окно, например `_blank`.
**data-browser-validate** | при указании перед отправкой запроса будет выполнена клиентская валидация на стороне браузера.
**data-browser-redirect-back** | при перенаправлении, если предыдущий URL из браузера доступен, он будет использован вместо предоставленного URL перенаправления.
**data-auto-submit** | автоматически запускает AJAX-запрос для элементов, которые также имеют атрибут `data-request`. Запрос отправляется, когда окно браузера активно, с использованием [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API). Необязательное значение атрибута может определять интервал в миллисекундах, который фреймворк ожидает перед отправкой запроса.
**data-track-input** | может быть применён к текстовому, числовому или полю ввода пароля, которое также имеет атрибут `data-request`. При определении поле ввода автоматически отправляет AJAX-запрос, когда пользователь вводит что-то в поле. Необязательное значение атрибута может определять интервал в миллисекундах, который фреймворк ожидает перед отправкой запросов.

Когда атрибут `data-request` указан для элемента, элемент инициирует AJAX-запрос при взаимодействии пользователя с ним. В зависимости от типа элемента запрос инициируется по следующим событиям:

Element | Event
------------- | -------------
**Forms** | при отправке формы.
**Links, buttons** | при нажатии на элемент.
**Text, number, and password fields** | при изменении текста и только если указан атрибут `data-track-input`.
**Dropdowns, checkboxes, radios** | при выборе элемента.

## Примеры использования

Вызов обработчика `onCalculate` при отправке формы. Обновление элемента с идентификатором "result" фрагментом **calcresult**.

```html
<form data-request="onCalculate" data-request-update="{ calcresult: '#result' }">
```

Запрос подтверждения при нажатии кнопки «Удалить» перед отправкой запроса.

```html
<form ... >
    ...
    <button data-request="onDelete" data-request-confirm="Are you sure?">Delete</button>
```

Перенаправление на другую страницу после успешного запроса.

```html
<form data-request="onLogin" data-request-redirect="/admin">
```

Показ всплывающего окна после успешного запроса.

```html
<form data-request="onLogin" data-request-success="alert('Yay!')">
```

Отправка POST-параметра `mode` со значением `update`.

```html
<form data-request="onUpdate" data-request-data="{ mode: 'update' }">
```

Отправка POST-параметра `id` со значением `7` через несколько элементов.

```html
<div data-request-data="{ id: 7 }">
    <button data-request="onDelete">Delete</button>
    <button data-request="onSave">Update</button>
</div>
```

Отправка GET-параметра `page` со значением `6` в текущем запросе.

```html
<button data-request="onSetPage" data-request-query="{ page: 6 }">
    Page 6
</button>
```

Показ [flash-сообщения](../features/flash-messages.md) во время загрузки запроса.

```html
<button data-request="onUpdate" data-request-message="Loading...">
    Save Changes
</button>
```

Включение [загрузки файлов](../../extend/services/request-input.md) в запрос.

```html
<form data-request="onSubmit" data-request-files>
    <input type="file" name="photo" accept="image/*" />
    <button type="submit">Submit</button>
</form>
```

Включение [скачивания файлов](../../extend/services/response-view.md) в ответ.

```html
<button data-request="onDownloadFile" data-request-download>
    Download
</button>
```

Для указания пользовательского имени файла и открытия загрузки в новом окне, например для предварительного просмотра PDF.

```html
<button
    data-request="onDownloadFile"
    data-request-download="sample.pdf"
    data-browser-target="_blank">
    Download
</button>
```

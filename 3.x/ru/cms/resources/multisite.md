# Мультисайт

<VideoBlockLink src="https://www.youtube.com/watch?v=_kX7P3SEHg8" title="Демонстрация мультисайта" description="Это видео демонстрирует, как создавать мультиязычные сайты с помощью October CMS Multisite." prompt="Смотреть демонстрацию" />

Функция мультисайта позволяет управлять несколькими веб-сайтами из одной установки October CMS и назначать контент в зависимости от доменного имени. Например, интернет-магазин с различными региональными поддоменами. Вы также можете использовать эту функцию для управления переводами локализованного сайта.

## Управление сайтами

Создавать сайты можно на странице **Настройки → Управление сайтами** в панели администрирования. Каждая установка включает основной сайт, который действует как сайт по умолчанию для каждого запроса.

Каждый сайт определяется следующей конфигурацией:

- **Включён** — определяет доступность сайта на фронтенде и в панели администрирования.
- **Название** — указывает название сайта.
- **Уникальный код** — указывает уникальный код сайта для поиска через API.
- **Тема** — CMS-тема, используемая при активном сайте.
- **Локаль** — локаль приложения для этого сайта.
- **Часовой пояс** — часовой пояс для этого сайта.
- **Пользовательский URL приложения** — URL, используемый при активном сайте для таких вещей, как почтовые шаблоны или когда политика ссылок принудительно устанавливает URL.
- **Использовать префикс маршрута CMS** — определяет префикс для включения перед каждым маршрутом страницы. Может идентифицировать этот сайт при использовании общего имени хоста.
- **Определить совпадающие имена хостов** — сопоставляет сайт с определёнными именами хостов. Рекомендуется включить для продуктивных сайтов из соображений безопасности. Поддерживаются подстановочные значения, например: `*.mydomain.tld`.
- **Отображать цвет для этого сайта** — при включении отображает баннер в верхней части панели администрирования. Полезно для идентификации активного сайта или различения сред, например, красный для разработки, зелёный для стейджинга и без цвета для продакшена.

При создании более одного сайта каждый из них можно выбрать в панели администрирования через выпадающее меню выбора сайта.

## Компонент Site Picker

Компонент `sitePicker` позволяет управлять ссылками на другие сайты. Лучшее место для его размещения — шаблон страницы или макета.

::: cmstemplate
```ini
[sitePicker]
```
```twig
{% set availableSites = sitePicker.sites %}
```
:::

Обратитесь к [статье о компоненте Site Picker](../components/sitepicker.md), чтобы узнать, как отображать URL сайтов и генерировать альтернативные ссылки на страницы.

## Определение языка браузера

October CMS настроен на автоматическое определение подходящего сайта на основе предпочтительного языка браузера при выполнении следующих условий:

- Все сайты в группе имеют установленный префикс
- Нет других сайтов, соответствующих базовому URL

Например, если основной сайт — **English** с префиксом маршрута `/en`, а другой сайт **French** имеет префикс `/fr`, то наблюдается следующее поведение.

Базовый URL | Поведение
-------- | --------
https://yoursite.tld/en | Отображает **английский** сайт
https://yoursite.tld/fr | Отображает **французский** сайт
https://yoursite.tld | Перенаправление на основе языковых предпочтений

Когда пользователь посещает базовый URL, его предпочтительный язык определяется автоматически и выполняется перенаправление на соответствующий сайт. Сопоставление сайта основано на значении его локали, и если совпадение не найдено, используется основной сайт.

::: tip
Вы можете изменить это поведение, используя значение `redirect_policy` в файле **config/cms.php**.
:::

## Группы сайтов

В начальном состоянии мультисайт полезен для создания нескольких сайтов на одном языке или одного сайта на нескольких языках. Группировка сайтов позволяет расширить эту концепцию для создания нескольких сайтов с несколькими языками. Создавайте группы сайтов, перейдя в **Настройки → Управление сайтами → Управление группами сайтов**. После создания группы для каждого сайта появится поле выбора группы.

На практике каждая группа сайтов представляет веб-сайт, а определения сайтов в группе представляют сайт на альтернативном языке. Следующий пример показывает конфигурацию группированных сайтов для сайта о кошках и собаках с двумя языками для каждого.

Группа сайтов | Название сайта
---------- | -----------
Dogs       | English
Dogs       | French
Cats       | English
Cats       | French

Группированные сайты реплицируют поля только внутри своей группы. Например, если [чертёж Tailor](../tailor/introduction.md) использует опцию `multisite: sync`, записи будут синхронизироваться только между сайтами одной группы.

## Ограничения ролей

Определения сайтов могут ограничивать видимость на основе роли администратора, что позволяет использовать выделенные роли для управления конкретными сайтами. Для включения ограничений ролей мультисайта:

1. Перейдите в **Управление сайтами** и выберите определение сайта.
2. Установите флажок **Определить роли администраторов**.
3. Выберите роли, которым разрешён просмотр сайта.
4. Нажмите **Сохранить**.

При включении сайт будет виден в панели администрирования только администраторам с указанными ролями. Например, для создания сайта, доступного только разработчикам, выберите роль **Developer** в поле.

## Функции мультисайта

Некоторые основные функции не поддерживают мультисайт по умолчанию, например конфигурация почты. Вы можете выборочно включить функции мультисайта с помощью файла **config/multisite.php** в разделе `features`. Следующие ключи функций доступны для использования с несколькими определениями сайтов.

Функция | Описание
------- | --------------------------
`cms_maintenance_setting` | Настройки режима обслуживания уникальны для каждого сайта
`backend_mail_setting` | Настройки почты уникальны для каждого сайта
`system_asset_combiner` | Ключи кэша комбинатора ресурсов уникальны для сайта

### Отключение мультисайта

Вы можете полностью отключить функции мультисайта, установив конфигурацию `enabled` в значение `false`.

```php
'enabled' => false
```

## PHP-интерфейс

[Сервис сайта](../../extend/services/site.md) включает глобальный фасад `Site`, предоставляющий инструменты для работы с мультисайтом. Например, следующий код находит модель в контексте сайта с ID **2**.

```php
$model = Site::withContext(2, function() {
    return Model::find(1);
});
```

Обратитесь к [статье о сервисе Site](../../extend/services/site.md), чтобы узнать больше.

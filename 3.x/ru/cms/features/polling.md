# Поллинг

Поллинг — это техника, используемая для отложенного или повторяющегося AJAX-обновления путём добавления атрибута `data-auto-submit` на элемент запроса. Эту функцию следует использовать с осторожностью, поскольку она может увеличить нагрузку на сервер при масштабировании. Для смягчения этого эффекта атрибут срабатывает только когда окно браузера пользователя активно.

## Отложенная загрузка

Запросы поллинга часто используются совместно с [Twig-тегом AJAX-фрагмента](../../markup/tag/ajax-partial.md), поскольку он позволяет самообновлять содержимое фрагмента. Рассмотрим следующий AJAX-обработчик, определённый на странице, который загружает результаты. Предполагая, что это ресурсоёмкий поиск, мы можем запросить его после завершения загрузки страницы.

```php
public function onFetchResults()
{
    $this['results'] = [1, 2, 3];
}
```

Следующий шаг — включить AJAX-фрагмент с именем **posts.htm** где-нибудь на странице.

```twig
{% ajaxPartial 'posts' %}
```

Внутри фрагмента содержимое выводит данные, если переменная `results` существует. В противном случае отображается сообщение о загрузке с запросом `data-auto-submit` для загрузки результатов вторичным запросом.

```twig
{% if results %}
    <h3>Found results</h3>
    {{ d(results) }}
{% else %}
    <h3>Loading the results...</h3>
    <div
        data-request="onFetchResults"
        data-request-update="{ _self: true }"
        data-auto-submit>
    </div>
{% endif %}
```

## Повторяющиеся запросы

Для повторяющихся запросов обновления содержимого можно установить значение `data-auto-submit` (в миллисекундах) для автоматического выполнения запроса с задержкой. Например, фрагмент, отрендеренный с помощью `{% ajaxPartial %}`, содержит следующую разметку.

```twig
<div>
    {% set launchDate = carbon('2025-01-01') %}
    {% set days = launchDate.diffInDays %}
    {% set hours = launchDate.subDays(days).diffInHours %}
    {% set minutes = launchDate.subHours(hours).diffInMinutes %}
    {% set seconds = launchDate.subMinutes(minutes).diffInSeconds %}

    <h2>
        Launch in...
        {{ days }} days,
        {{ hours }} hours,
        {{ minutes }} minutes,
        {{ seconds }} seconds
    </h2>
</div>

<div
    data-request="onAjax"
    data-request-update="{ _self: true }"
    data-auto-submit="2000"></div>
```

Этот фрагмент отображает таймер обратного отсчёта и включает элемент "div" для автоматического самообновления. Результирующее обновление также содержит этот элемент, поэтому запрос повторяется непрерывно каждые 2 секунды.

Поллинг можно остановить, не включая элемент в последующие запросы. Например, следующий код остановит поллинг, если переменная `launchDone` установлена в true.

```twig
{% if not launchDone %}
    <div
        data-request="onAjax"
        data-request-update="{ _self: true }"
        data-auto-submit="2000"></div>
{% endif %}
```

## Отложенная загрузка фрагментов

Тег `data-auto-submit` используется Twig-тегом `{% ajaxPartial lazy %}` для отложенной загрузки фрагментов. Разметка автоматически включается при первом рендеринге страницы для динамической загрузки содержимого фрагмента.

```twig
{% ajaxPartial 'posts' lazy %}
```

Обратитесь к [Twig-тегу AJAX-фрагмента](../../markup/tag/ajax-partial.md), чтобы узнать больше.

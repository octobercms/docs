# Collection

Компонент `collection` отображает коллекцию записей на странице. Компонент collection может использоваться на любой странице, макете или фрагменте.

## Доступные свойства

Компонент поддерживает следующие свойства.

Свойство | Описание
-------- | -------------
**handle** | Handle [чертежа записи](../tailor/blueprints.md).
**recordsPerPage** | Количество записей для отображения на одной странице. Оставьте пустым для отключения пагинации.
**pageNumber** | Это значение используется для определения текущей страницы пользователя.
**sortColumn** | Имя столбца для сортировки записей.
**sortDirection** | Направление сортировки записей. Поддерживаемые значения: `asc` и `desc`.

## Базовое использование

Следующий пример добавляет коллекцию записей **Blog\Post** на страницу. Коллекция доступна в Twig через перебор стандартной переменной `collection`.

::: cmstemplate
```ini
[collection]
handle = "Blog\Post"
```
```twig
{% for post in collection %}
    <h1>{{ post.title }}</h1>
{% endfor %}
```
:::

Когда на одной странице используется несколько коллекций, компоненту можно назначить имя **posts** с помощью псевдонима, и это имя переменной становится доступным на странице. Следующая коллекция доступна через переменную `posts`.

::: cmstemplate
```ini
[collection posts]
handle = "Blog\Post"
```
```twig
{% for post in posts %}
    <h1>{{ post.title }}</h1>
{% endfor %}
```
:::

Используйте выражение `is empty` или `is not empty` для проверки наличия хотя бы одной записи в коллекции.

```twig
{% if posts is not empty %}
    {# ... #}
{% endif %}
```

## Выполнение запросов

При обращении к переменной компонента через метод она переключается на [запрос к модели базы данных](../../extend/database/query.md). Например, чтобы показать только записи с полем `color` со значением **blue**, используйте метод запроса `where`. Тег `{% set %}` присвоит результат новой переменной.

```twig
{% set bluePosts = posts.where('color', 'blue').get() %}
```

Чтобы показать только публикации со связанным автором, можно использовать метод запроса `whereRelation`. Для завершения запроса используйте метод `get()`. Следующий пример выводит публикации, назначенные `author` со slug **bella-vista**.

```twig
{% set authorPosts = posts.whereRelation('author', 'slug', 'bella-vista').get() %}
```

### Доступ к типу записи

Для фильтрации записей по их типу выполните запрос `where()` по атрибуту `content_group`. Следующий пример выведет публикации с типом записи **featured_post**.

```twig
{% set featuredPosts = posts.where('content_group', 'featured_post').get() %}
```

### Пагинация записей

Вы также можете применить пагинацию к коллекции с помощью метода `paginate()`. Следующий пример пагинирует публикации по **10** на страницу и отображает навигацию по страницам.

```twig
{% set authorPosts = posts.whereRelation(...).paginate(10) %}

{{ pager(authorPosts) }}
```

::: tip
Обратитесь к [функции пагинации](../features/pagination.md), чтобы узнать больше о разбиении записей на страницы.
:::

### Поиск записей

Для поиска записей используйте [метод `searchWhere()`](../../extend/database/query.md) для выполнения поискового запроса по значению столбца. Следующий пример ищет записи по указанному термину и столбцам с использованием регистронезависимого запроса.

```twig
{% set foundPages = pages.searchWhere(searchTerm, ['title', 'content']).get() %}
```

Вы также можете использовать [метод `searchWhereRelation()`](../../extend/database/relations.md) для поиска связанных записей, где имя связи включается в метод для запроса наличия связи.

```twig
{% set foundPages = pages.searchWhereRelation(searchTerm, 'author', ['title']).get() %}
```

## Жадная загрузка связанных записей

В некоторых случаях, из соображений производительности, вам может потребоваться жадная загрузка связанных записей. Используйте метод `load` на коллекции, передавая имя связи. В следующем примере связь `categories` будет загружена с каждой публикацией в коллекции.

```twig
{% do authorPosts.load('categories') %}
```

## Подсчёт записей

Допустим, вы хотите отобразить список категорий блога и подсчитать количество публикаций в каждой категории. Сначала определите [обратную связь](../../element/content/field-entries.md) в чертеже категории как **posts**.

```yaml
posts:
    type: entries
    source: Blog\Post
    inverse: categories
    hidden: true
```

Затем вызовите функцию `withCount` на компоненте коллекции, затем `get` для получения коллекции записей категорий. Это создаст атрибут **post_count** на каждой категории.

```twig
{% set categories = collection.withCount('posts').get() %}
{% for category in categories %}
    <h5>{{ category.title }} ({{ category.post_count }} posts)</h5>
{% endfor %}
```

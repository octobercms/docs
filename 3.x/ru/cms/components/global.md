# Global

Компонент `global` делает глобальную запись доступной на странице, макете или фрагменте. Компонент global может использоваться на любой странице, макете или фрагменте.

## Доступные свойства

Компонент поддерживает следующие свойства.

Свойство | Описание
-------- | -------------
**handle** | Handle [глобального чертежа](../tailor/blueprints.md).

## Базовое использование

Следующий пример добавляет глобальную запись с handle **Blog\Config** на страницу. Компоненту назначается имя **blogConfig** с помощью псевдонима, и это имя переменной становится доступным на странице. Страница обращается к текстовому полю `about_this_blog` и отображает его.

::: cmstemplate
```ini
[global blogConfig]
handle = "Blog\Config"
```
```twig
<p>{{ blogConfig.about_this_blog }}</p>
```
:::

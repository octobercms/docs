# Section

Компонент `section` определяет раздел сайта с привязанной записью. Этот раздел будет использоваться при предварительном просмотре записи из панели администрирования.

## Доступные свойства

Компонент поддерживает следующие свойства.

Свойство | Описание
-------- | -------------
**handle** | Handle [чертежа записи](../tailor/blueprints.md).
**identifier** | Ключ идентификатора для поиска записи, поддерживаемые значения: `slug`, `fullslug` или `id`. По умолчанию: `slug`
**value** | Значение идентификатора для поиска записи, необязательно. Оставьте пустым для использования ключа идентификатора в качестве имени URL-параметра. Может быть жёстко задано или использовать пользовательский параметр, например: `{{ :slug }}`
**isDefault** | Сделать эту страницу страницей по умолчанию при предварительном просмотре записи. По умолчанию: `true`.

## Базовое использование

Следующий пример создаёт раздел для записи **Blog\Author** и находит его, используя [URL-параметр](../themes/pages.md) `:slug` по умолчанию. Имя автора отображается как заголовок через Twig-переменную `{{ section.title }}`.

::: cmstemplate
```ini
url = "author/:slug"

[section]
handle = "Blog\Author"
```
```twig
<h1>Posts by {{ section.title }}</h1>
```
:::

Когда на одной странице используется несколько секций, псевдоним компонента может назначить другое имя переменной. Следующий псевдоним **author** делает заголовок доступным через Twig-переменную `{{ author.title }}`.

::: cmstemplate
```ini
[section author]
handle = "Blog\Author"
```
```twig
<h1>Posts by {{ author.title }}</h1>
```
:::

## Изменение идентификатора поиска

Идентификатор по умолчанию — `slug`, его можно изменить через свойство `identifier`, например, для поиска записи по столбцу `id`. Обратите внимание, что URL страницы также меняется на параметр `:id`.

```ini
url = "author/:id"

[section]
handle = "Blog\Author"
identifier = "id"
```

Вы можете жёстко задать поиск идентификатора с помощью свойства `value`. Например, установка значения **7** покажет запись со статическим поиском.

```ini
url = "author/ceo"

[section]
handle = "Blog\Author"
identifier = "id"
value = 7
```

Свойство `value` также принимает внешние параметры. Следующий пример использует URL-параметр **foobar** для поиска записи.

```ini
url = "author/:foobar"

[section]
handle = "Blog\Author"
identifier = "id"
value = "{{ :foobar }}"
```

::: warning
Предварительный просмотр ссылок и использование [виджета поиска страниц](../../element/form/widget-pagefinder.md) не поддерживают идентификаторы с пользовательскими значениями.
:::

## Проверка существования записи

В большинстве случаев вы захотите отобразить страницу 404, если запись не найдена. Это возможно с помощью оператора `{% if %}` в сочетании с функцией `abort(404)`.

```twig
{% if author is empty %}
    {% do abort(404) %}
{% endif %}
```

::: tip
[Twig-функция `abort()`](../../markup/function/abort.md) используется для отображения страницы 404, когда запись не найдена.
:::

## Доступ к типу записи

При использовании функции [Групп контента](./blueprints.md) чертежа записи вы можете получить доступ к коду группы через атрибут `content_group`. Например, публикация может иметь группу контента **regular_post** и **markdown_post**, где содержимое обрабатывается по-разному.

```twig
{% if post.content_group == 'markdown_post' %}
    <!-- Render content as Markdown -->
    {{ post.content|md }}
{% else %}
    <!-- Render content as HTML -->
    {{ post.content|raw }}
{% endif %}
```

## Использование полного slug

Если тип записи — `structure`, у неё доступен атрибут **fullslug**. Для использования полного slug в URL страницы он должен быть определён как [URL-параметр с подстановочным знаком](../themes/pages.md). Свойство `identifier` компонента должно быть установлено в **fullslug**.

```ini
url = "/wiki/:fullslug*"

[section article]
handle = "Wiki\Article"
identifier = "fullslug"
```

В качестве альтернативного подхода мы рекомендуем нацеливаться на **id** и размещать его в конце URL. Это позволяет свободно перемещать запись без нарушения ссылок на сайте. Следующий пример показывает, как достичь этого с перенаправлением для ранее использовавшихся URL.

::: cmstemplate
```ini
url = "/wiki/:fullslug*/:id"

[section article]
handle = "Wiki\Article"
identifier = "id"
```
```twig
{% if article is empty %}
    {% do abort(404) %}
{% elseif article.fullslug != this.param.fullslug %}
    {% do redirect(this|page({ fullslug: article.fullslug }), 301) %}
{% endif %}

<!-- Contents here -->
```
:::

::: tip
[Twig-функция `redirect()`](../../markup/function/redirect.md) используется для постоянного перенаправления 301, когда slug не совпадает. [Twig-фильтр `|page`](../../markup/filter/page.md) передаёт текущую страницу и перезаписывает URL-параметр `fullslug` на правильное значение.
:::

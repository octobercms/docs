# Дочерние темы

Дочерние темы обеспечивают возможность наследования тем. Хорошим примером использования является ситуация, когда у вас есть сторонняя тема или тема в режиме «только для чтения». Дочерняя тема ссылается на родительскую и использует её в качестве резервного источника.

Если страница с именем `home.htm` существует в родительской теме, но отсутствует в дочерней, она обрабатывается так, как если бы она существовала: URL активен, и вы можете открыть страницу как обычно. При сохранении страницы в панели администрирования в дочерней теме создаётся новый файл, переопределяющий содержимое.

Чтобы включить эту функцию для темы, перейдите в **Настройки → Фронтенд-тема**, выберите **Редактировать свойства** и выберите родительскую тему из выпадающего списка **Родительская тема**.

## Файл блокировки темы

При установке темы от стороннего разработчика через Composer важно учитывать, что при обновлении темы все файлы могут быть перезаписаны. Это может привести к потере любых внесённых в тему изменений. В качестве защитного механизма в тему включается файл `.themelock`, который защищает тему от изменений, которые могут быть утрачены при обновлении системы.

Когда файл `.themelock` присутствует в директории темы:

- Тема может быть выбрана только в качестве родительской
- Тема не отображается в интерфейсе панели администрирования
- Тема не может быть выбрана как активная

## Создание новой дочерней темы

Команда `theme:copy` может использоваться для создания новых тем, включая дочерние. Следующая команда создаёт новую тему `demo-copy` из исходной темы `demo` путём копирования директории и её содержимого. Файл `.themelock` будет удалён в процессе копирования.

```bash
php artisan theme:copy demo demo-copy
```

Чтобы создать дочернюю тему, наследующую родительскую, укажите опцию `--child`.

```bash
php artisan theme:copy demo demo-child --child
```

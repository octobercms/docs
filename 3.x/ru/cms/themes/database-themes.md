# Темы на основе базы данных

В некоторых случаях у вас может не быть доступа на запись в файловую систему для внесения изменений в тему. Темы на основе базы данных позволяют хранить все изменения CMS-шаблонов в базе данных.

:::aside
Файлы ресурсов, такие как изображения и таблицы стилей, не сохраняются в базе данных и не могут быть изменены без доступа к файловой системе.
:::

Чтобы включить эту функцию для отдельной темы, перейдите в **Настройки → Фронтенд-тема**, выберите **Редактировать свойства** и установите флажок **Сохранять изменения в базе данных**.

Также вы можете включить эту функцию глобально для всех тем с помощью параметра конфигурации `cms.database_templates` или переменной окружения.

```text
CMS_DB_TEMPLATES=true
```

## Импорт из базы данных в файловую систему

Команда `theme:copy` может использоваться для копирования версии темы из базы данных в файловую систему. Просто вызовите команду с опцией `--import-db`.

```bash
php artisan theme:copy demo --import-db
```

Чтобы одновременно удалить все шаблоны из базы данных, используйте опцию `--purge-db`.

```bash
php artisan theme:copy demo --import-db --purge-db
```

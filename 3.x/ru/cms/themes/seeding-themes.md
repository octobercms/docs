# Сидинг тем

Темы поддерживают возможность импорта демонстрационного содержимого из сид-скриптов, включая содержимое базы данных и [блюпринты Tailor](../../cms/tailor/introduction.md). Для этого используется специальная папка внутри темы под названием **seeds** с определённой структурой директорий.

## Структура директорий

Ниже представлен пример структуры директории seeds. Директория **blueprints** содержит шаблоны блюпринтов, используемые темой — они автоматически импортируются в директорию **app/blueprints** во вложенную директорию с именем **mywebsite**. Файл **data.yaml** содержит инструкции по импорту содержимого в базу данных.

::: dir
├── themes
|   └── mywebsite
|       └── `seeds`  _← Директория сидов темы_
|           ├── blueprints
|           |   └── post.yaml  _← Файл блюпринта_
|           ├── lang
|           |   └── en.json  _← Языковой файл_
|           ├── data
|           |   └── blog-posts.json  _← Файл данных_
|           └── data.yaml  _← Скрипт сидинга_
:::

## Импорт блюпринтов

::: aside
Поскольку блюпринты не зависят от конкретной файловой структуры или структуры директорий, их можно свободно перемещать.
:::

При импорте блюпринтов просто поместите файлы блюпринтов в директорию **blueprints**. Конфигурация не требуется — при сидинге все блюпринты просто копируются в директорию **app/blueprints**. Внутри неё создаётся новая директория с тем же именем, что и у темы. Блюпринты помещаются в эту новую директорию.

## Импорт языковых файлов

В качестве дополнительной возможности языковые файлы могут быть импортированы в директорию **app/lang** путём размещения [JSON-файлов локализации](../../extend/system/localization.md) в директории **lang**. Это позволяет переводить метки и другие описания внутри блюпринтов. Если языковой файл уже существует в директории языков приложения, языковые строки будут объединены.

## Импорт данных

Файл **data.yaml** содержит специальный формат, используемый для импорта содержимого в базу данных. В приведённом ниже примере два набора данных импортируются в базу данных для содержимого записей Tailor.

```yaml
-
    name: Blog Post Data
    class: Tailor\Models\RecordImport
    file: seeds/data/blog-posts.json
    attributes:
        file_format: json
        blueprint_uuid: edcd102e-0525-4e4d-b07e-633ae6c18db6
-
    name: Blog Category Data
    class: Tailor\Models\RecordImport
    file: seeds/data/blog-categories.json
    attributes:
        file_format: json
        blueprint_uuid: b022a74b-15e6-4c6b-9eb9-17efc5103543
```

YAML-файл должен определять массив, каждый элемент которого поддерживает следующие свойства.

Свойство | Описание
------------- | -------------
**name** | задаёт имя шага импорта для отображения пользователю.
**class** | ссылается на модель, реализующую интерфейс `Backend\Models\ImportModel`.
**file** | ссылается на JSON-файл данных, содержащий импортируемое содержимое.
**attributes** | список атрибутов, устанавливаемых для модели импорта перед выполнением импорта.

### Пример файла данных

Ниже приведён пример JSON-файла, который может использоваться для импорта категорий блога. Каждый элемент JSON-массива создаёт импортированную запись в базе данных с указанными атрибутами. Указание атрибута **id** позволяет связывать записи между несколькими импортами.

```json
[
    {
        "id": 1,
        "title": "Announcements",
        "slug": "announcements"
    },
    {
        "id": 2,
        "title": "News",
        "slug": "news"
    }
]
```

## Запуск сидинга темы

Для запуска сидинга темы используется artisan-команда `theme:seed`.

```bash
php artisan theme:seed <theme name>
```

Вы также можете использовать опцию `--root`, чтобы указать команде импортировать блюпринты в корневую директорию вместо вложенной.

```bash
php artisan theme:seed <theme name> --root
```

:::tip
Сидинг темы также можно выполнить через панель администрирования, перейдя в **Настройки → Фронтенд-тема → Управление → Наполнение содержимым**.
:::

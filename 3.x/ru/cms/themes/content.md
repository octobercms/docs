# Блоки содержимого

Блоки содержимого могут быть текстовыми, HTML или [Markdown](http://daringfireball.net/projects/markdown/syntax) блоками, которые редактируются отдельно от страницы или макета. Они предназначены для хранения только статического содержимого и поддерживают базовые шаблонные переменные. [Фрагменты](./partials.md) более гибки и должны использоваться для генерации динамического содержимого.

## Введение

Файлы блоков содержимого располагаются в подкаталоге **/content** каталога темы. Для файлов содержимого поддерживаются следующие расширения.

Extension | Description
------------- | -------------
**html** | Используется для HTML-разметки (WYSIWYG-редактор).
**htm** | Используется для HTML-разметки (редактор кода).
**txt** | Используется для обычного текста.
**md** | Используется для синтаксиса Markdown.

Расширение влияет на режим отображения блока содержимого в интерфейсе администрирования — WYSIWYG-редактор, редактор кода или редактор Markdown. Оно также определяет способ рендеринга блоков на сайте; например, блоки Markdown будут преобразованы в HTML перед отображением.

## Рендеринг блоков содержимого

Используйте тег `{% content 'file.htm' %}` для рендеринга блока содержимого на [странице](./pages.md), во [фрагменте](./partials.md) или в [макете](./layouts.md).

Этот пример показывает полную страницу с рендерингом блока содержимого.

::: cmstemplate
```ini
url = "/contacts"
```
```twig
<div class="contacts">
    {% content 'contacts.html' %}
</div>
```
:::

Ещё один пример рендеринга Markdown с расширением `md`.

```twig
{% content 'my-markdown.md' %}
```

## Передача переменных в блоки содержимого

Иногда может потребоваться передать переменные в блок содержимого из внешнего кода. Хотя блоки содержимого не поддерживают разметку Twig, они поддерживают использование переменных с базовым синтаксисом. Вы можете передавать переменные в блоки содержимого, указывая их после имени блока содержимого в теге `{% content %}`.

Передача переменной с именем `name` и значением **John** в блок содержимого.

```twig
{% content 'welcome.htm' name='John' %}
```

Внутри блока содержимого переменные доступны с использованием одинарных *фигурных скобок*.

```html
<h1>This is a demo for {name}</h1>
```

::: tip
Более подробную информацию об использовании переменных можно найти в [руководстве по разметке](../../markup/tag/content.md).
:::

### Глобальные переменные

Вы можете зарегистрировать переменные, глобально доступные для всех блоков содержимого, с помощью метода `View::share`.

```php
View::share('site_name', 'October CMS');
```

Обычно этот метод размещается внутри метода register или boot [файла регистрации плагина](../../extend/system/plugins.md). Используя приведённый выше пример, переменная `{site_name}` будет доступна внутри всех блоков содержимого.

```html
<p>Welcome to {site_name}</p>
```

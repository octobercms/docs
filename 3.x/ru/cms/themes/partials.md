# Фрагменты

Фрагменты — это мощные элементы, позволяющие повторно использовать HTML на разных страницах или макетах, например, подвал страницы, используемый в различных [макетах страниц](./layouts.md). Фрагменты также являются мощным инструментом для динамического [обновления содержимого страницы с помощью AJAX](../ajax/update-partials.md).

Файлы шаблонов фрагментов располагаются в каталоге **partials** вашей темы. Файлы фрагментов должны иметь расширение **htm**. Далее приведён пример простейшего фрагмента.

```html
<p>This is a partial</p>
```

Секция конфигурации является необязательной для фрагментов и может содержать необязательный параметр **description**, который отображается в интерфейсе администрирования. Этот пример показывает фрагмент с определённым описанием.

::: cmstemplate
```ini
description = "Demo partial"
```
```html
<p>This is a partial</p>
```
:::

Секция конфигурации фрагмента также может содержать определения компонентов. Более подробно компоненты описаны в [статье о компонентах](./components.md).

## Рендеринг фрагментов

::: aside
Помните, что при обращении к фрагменту из подкаталога необходимо указывать имя подкаталога.
:::

Twig-тег `{% partial "partial-name" %}` выполняет рендеринг фрагмента. Тег имеет один обязательный параметр — имя файла фрагмента без расширения. Тег `{% partial %}` может использоваться внутри страницы, макета или другого фрагмента. Ниже приведён пример страницы, ссылающейся на фрагмент.

```twig
<div class="sidebar">
    {% partial "sidebar-contacts" %}
</div>
```

## Передача переменных во фрагменты

Часто возникает необходимость передавать переменные во фрагмент из внешнего кода. Это делает фрагменты ещё более полезными. Например, у вас может быть фрагмент, который выводит список записей блога. Если вы можете передать коллекцию записей во фрагмент, то один и тот же фрагмент можно использовать на странице архива блога, на странице категории блога и так далее. Вы можете передавать переменные во фрагменты, указывая их после имени фрагмента в теге `{% partial %}`.

```twig
<div class="sidebar">
    {% partial "blog-posts" posts=posts %}
</div>
```

Вы также можете предоставлять новые переменные для использования во фрагменте.

```twig
<div class="sidebar">
    {% partial "sidebar-contacts" city="Vancouver" country="Canada" %}
</div>
```

Внутри фрагмента переменные доступны как любые другие переменные разметки.

```twig
<p>Country: {{ country }}, city: {{ city }}.</p>
```

### Область видимости переменных

Содержимое фрагмента будет иметь доступ к переменным из текущего контекста и дополнительно предоставленным переменным.

```twig
{% partial "mypartial" foo="bar" %}
```

В следующем примере переменная `foo` будет доступна внутри шаблона фрагмента `mypartial`.

```twig
{% set foo = "bar" %}
{% partial "mypartial" %}
```

Вы можете отключить доступ к контексту, добавив ключевое слово `only`. В этом примере будет доступна только переменная `foo`.

```twig
{% partial "mypartial" foo="bar" only %}
```

В следующем примере никакие переменные не будут доступны.

```twig
{% partial "mypartial" only %}
```

### Парсинг разметки как переменной

Можно передать разметку во фрагмент, добавив атрибут `body` к тегу фрагмента.

```twig
{% partial "card" body %}
    This is the card contents
{% endpartial %}
```

Содержимое доступно внутри фрагмента как переменная `body`.

```twig
{{ body|raw }}
```

В сочетании с [тегом разметки placeholder](../../markup/tag/placeholder.md) это позволяет создавать составные фрагменты.

```twig
{% partial "card" image="img.jpg" body %}
    {% put header %}
        <h2>This is the card header</h2>
    {% endput %}
    This is the card contents
{% endpartial %}
```

Фрагмент **card** состоит из двух областей содержимого и переменной изображения.

```twig
<div class="header">
    <div class="image">
        <img src="{{ image }}" />
    </div>
    {% placeholder header %}
</div>
<div class="body">
    {{ body|raw }}
</div>
```

## Динамические фрагменты

Фрагменты, как и страницы, могут использовать любые возможности Twig. Подробнее см. раздел [Динамические страницы](pages.md) документации.

### Жизненный цикл выполнения фрагмента

Существуют специальные функции, которые можно определить в секции PHP фрагментов: `onStart` и `onEnd`. Функция `onStart` выполняется перед рендерингом фрагмента и до выполнения [компонентов фрагмента](./components.md). Функция `onEnd` выполняется перед рендерингом фрагмента и после выполнения компонентов фрагмента. В функциях `onStart` и `onEnd` вы можете передавать переменные в окружение Twig. Используйте `$this` с нотацией массива для передачи переменных на страницу.

::: cmstemplate
```ini
```
```php
<?
function onStart()
{
    $this['hello'] = "Hello world!";
}
?>
```
```twig
<h3>{{ hello }}</h3>
```
:::

Внешние переменные, назначенные фрагменту, доступны в PHP через объект `$this`.

::: cmstemplate
```ini
```
```php
<?
function onStart()
{
    $this['location'] = $this->city . ', ' . $this->country;
}
?>
```
```twig
<p>{{ location }} is the same as {{ city }}, {{ country }}.</p>
```
:::

Язык шаблонов, предоставляемый October CMS, описан в [руководстве по разметке](../../markup/templating.md). Общая последовательность выполнения обработчиков описана в разделе [Динамические макеты](./layouts.md) документации.

### Вызов AJAX-обработчиков во фрагментах

Поскольку фрагменты инициализируются поздно, во время рендеринга страницы, к жизненному циклу обычных фрагментов применяются некоторые ограничения. Чтобы преодолеть это, вы можете использовать `{% ajaxPartial %}`, чтобы разрешить вызов AJAX-обработчиков внутри вашего фрагмента.

```twig
{% ajaxPartial "contact-form" %}
```

::: tip
Подробнее о теге `{% ajaxPartial %}` см. в [статье о Twig-теге AJAX Partial](../../markup/tag/ajax-partial.md).
:::

При вызове обработчика из AJAX-фрагмента жизненный цикл работает иначе по сравнению с обычным AJAX-обработчиком.

1. Обработчик выполняется после функции `onEnd` фрагмента.
1. Выполняется полный жизненный цикл страницы, включая логику в макете, на странице и в родительских фрагментах.
1. Все переменные доступны во время запроса, включая переменные, установленные с помощью Twig.
1. Функции жизненного цикла фрагмента не поддерживают возврат значений.

# Локализация

::: aside
Ознакомьтесь со [статьёй о мультисайте](../resources/multisite.md), чтобы узнать, как установить активный язык для вашего сайта.
:::

Темы могут предоставлять ключи локализации через файлы, размещённые в поддиректории **lang** директории темы. Эти ключи локализации регистрируются автоматически и могут использоваться внутри содержимого темы или в качестве меток форм панели администрирования аналогично [локализации плагинов](../../extend/system/localization.md).

### Структура файлов локализации

Ниже приведён пример директории **lang** темы.

::: dir
├── themes
|   └── website
|       └── `lang`  _← Директория локализации_
|           ├── en.json  _← Файл локализации_
|           └── fr.json  _← Файл локализации_
:::

Файл локализации представляет собой JSON-файл, в котором строки используют перевод «по умолчанию» в качестве ключа. Например, если ваше приложение имеет французский перевод, вам следует создать файл `lang/fr.json`.

```json
{
    "I love programming.": "j'adore programmer"
}
```

Вы также можете определять ключи на основе кодов, используя полный языковой ключ в JSON-файле, например, `theme.options.website_name` для темы **acme**:

```json
{
    "theme.options.website_name": "October CMS"
}
```

Доступ к языковым строкам в файлах темы осуществляется с помощью Twig-фильтра `trans`.

::: tip
Ознакомьтесь с [руководством по разметке](../../markup/filter/trans.md), чтобы узнать больше о переводах в Twig.
```twig
<!-- j'adore programmer -->
{{ 'I love programming.'|trans }}

<!-- October CMS -->
{{ 'theme.options.website_name'|trans }}
```
:::

# {% for %}

Теги `{% for %}` и `{% endfor %}` выполняют итерацию по каждому значению в коллекции. Коллекция может быть массивом или объектом, реализующим интерфейс `Traversable`.

```twig
<ul>
    {% for user in users %}
        <li>{{ user.username }}</li>
    {% endfor %}
</ul>
```

Вы также можете получить доступ и к ключам, и к значениям:

```twig
<ul>
    {% for key, user in users %}
        <li>{{ key }}: {{ user.username }}</li>
    {% endfor %}
</ul>
```

Если коллекция пуста, можно отобразить альтернативный блок с помощью else:

```twig
<ul>
    {% for user in users %}
        <li>{{ user.username }}</li>
    {% else %}
        <li><em>There are no users found</em></li>
    {% endfor %}
</ul>
```

## Итерация по коллекции

Если вам нужно выполнить итерацию по коллекции чисел, можно использовать оператор `..`:

```twig
{% for i in 0..10 %}
    - {{ i }}
{% endfor %}
```

Приведённый выше фрагмент кода выведет все числа от 0 до 10.

Это также полезно для букв:

```twig
{% for letter in 'a'..'z' %}
    - {{ letter }}
{% endfor %}
```

Оператор `..` принимает любое выражение с обеих сторон:

```twig
{% for letter in 'a'|upper..'z'|upper %}
    - {{ letter }}
{% endfor %}
```

## Добавление условия

В отличие от PHP, в цикле нет функции `break` или `continue`, однако вы можете фильтровать коллекцию. Следующий пример пропускает всех `users`, которые не активны.

```twig
<ul>
    {% for user in users %}
        {% if user.active %}
            <li>{{ user.username }}</li>
        {% endif %}
    {% endfor %}
</ul>
```

## Переменная loop

Внутри блока цикла `for` вы можете обращаться к некоторым специальным переменным:

Переменная | Описание
------------- | -------------
`loop.index` | Текущая итерация цикла (начиная с 1)
`loop.index0` | Текущая итерация цикла (начиная с 0)
`loop.revindex` | Количество итераций до конца цикла (начиная с 1)
`loop.revindex0` | Количество итераций до конца цикла (начиная с 0)
`loop.first` | True, если первая итерация
`loop.last` | True, если последняя итерация
`loop.length` | Количество элементов в коллекции
`loop.parent` | Родительский контекст

```twig
{% for user in users %}
    {{ loop.index }} - {{ user.username }}
{% endfor %}
```

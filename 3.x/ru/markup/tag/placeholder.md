# {% placeholder %}

Тег `{% placeholder %}` рендерит секцию-плейсхолдер, которая обычно [используется внутри макетов](../../cms/themes/layouts.md). Этот тег возвращает любое содержимое плейсхолдера, добавленное с помощью тега `{% put %}`, или любое содержимое по умолчанию (необязательно).

```twig
{% placeholder name %}
```

Контент затем может быть внедрён в плейсхолдер на любой последующей странице или во фрагменте.

```twig
{% put name %}
    <p>Place this text in the name placeholder</p>
{% endput %}
```

## Замена содержимого

По умолчанию `{% put %}` добавляет содержимое к плейсхолдеру. Используйте атрибут `replace`, чтобы заменить содержимое.

```twig
{% put name replace %}
    <p>Replace all the content inside with this</p>
{% endput %}
```

## Обработка множественных вызовов

В некоторых случаях вы можете вызывать тег `{% put %}` внутри фрагмента для включения некоторых ресурсов на страницы. При включении этого фрагмента несколько раз на одной странице скрипт может быть вставлен дважды. Атрибут `once` гарантирует, что содержимое устанавливается только один раз для каждого шаблона. Ключ кэша использует имя файла CMS-шаблона, чтобы определить, было ли содержимое уже вставлено.

```twig
{% put scripts once %}
    <script src="https://cdnjs.cloudflare.com/ajax/libs/tiny-slider/2.9.2/min/tiny-slider.js"></script>
{% endput %}
```

## Содержимое плейсхолдера по умолчанию

Плейсхолдеры могут иметь содержимое по умолчанию, которое может быть заменено или дополнено страницей. Если тег `{% put %}` для плейсхолдера с содержимым по умолчанию не определён на странице, отображается содержимое плейсхолдера по умолчанию. Пример определения плейсхолдера в шаблоне макета:

```twig
{% placeholder sidebar default %}
    <p><a href="/contacts">Contact us</a></p>
{% endplaceholder %}
```

Страница может добавить дополнительный контент в плейсхолдер. Тег `{% default %}` указывает место, где должно отображаться содержимое плейсхолдера по умолчанию. Если этот тег не используется, содержимое плейсхолдера полностью заменяется.

```twig
{% put sidebar %}
    <p><a href="/services">Services</a></p>
    {% default %}
{% endput %}
```

## Проверка существования плейсхолдера

В шаблоне макета можно проверить, существует ли содержимое плейсхолдера, с помощью функции `hasPlaceholder()`. Это позволяет генерировать различную разметку в зависимости от того, предоставляет ли страница содержимое плейсхолдера. Пример:

```twig
{% if hasPlaceholder('sidemenu') %}
    <!-- Markup for a page with a sidebar -->
    <div class="row">
        <div class="col-md-3">
            {% placeholder sidemenu %}
        </div>
        <div class="col-md-9">
            {% page %}
        </div>
    </div>
{% else %}
    <!-- Markup for a page without a sidebar -->
    {% page %}
{% endif %}
```

## Использование плейсхолдеров как переменных

Плейсхолдеры могут быть полезны для установки наследуемых переменных, например, активной ссылки в навигации страницы. Тег `{% put %}` позволяет устанавливать значения напрямую. Например, установка значения `activeNav` в **home** внутри шаблона страницы.

```twig
{% put activeNav = 'home' %}
```

К переменной можно обратиться внутри шаблона макета с помощью функции `placeholder()`. Таким образом мы можем определить активную ссылку на основе значения, установленного страницей.

```twig
{% set active = placeholder('activeNav') %}

<ul>
    <li class="{{ active == 'home' ? 'active' }}">Home</li>
    <li class="{{ active == 'blog' ? 'active' }}">Blog</li>
    <li class="{{ active == 'contact' ? 'active' }}">Contact</li>
</ul>
```

Можно указать значение по умолчанию (второй аргумент) в качестве запасного варианта.

```twig
{% set active = placeholder('activeNav', 'home') }} %}
```

## Системные плейсхолдеры

October CMS определяет статические плейсхолдеры, используемые системой. Пакеты используют эти плейсхолдеры для внедрения своих зависимостей на страницу через PHP- или Twig-интерфейс.

### {% scripts %}

Тег `{% scripts %}` вставляет ссылки на JavaScript-файлы, внедрённые приложением. Тег обычно определяется перед закрывающим тегом BODY.

```twig
<body>
    ...
    {% scripts %}
</body>
```

> **Примечание**: Этот тег должен появляться только один раз в данном цикле страницы, чтобы избежать дублирования ссылок.

#### Внедрение скриптов

Ссылки на JavaScript-файлы могут быть программно внедрены в PHP через [компоненты](../../extend/cms-components.md) или [страницы](../../cms/themes/pages.md).

```php
function onStart()
{
    $this->addJs('assets/js/app.js');
}
```

Вы также можете внедрить необработанную разметку в тег `{% scripts %}`, используя анонимный плейсхолдер **scripts** [в макете](../../cms/themes/layouts.md). Используйте тег `{% put %}` на страницах или в макетах для добавления содержимого в плейсхолдер.

```twig
{% put scripts %}
    <script type="text/javascript" src="/themes/demo/assets/js/menu.js"></script>
{% endput %}
```

### {% styles %}

Тег `{% styles %}` рендерит CSS-ссылки на файлы стилей, внедрённые приложением. Тег обычно определяется в секции HEAD страницы или макета.

```twig
<head>
    ...
    {% styles %}
</head>
```

> **Примечание**: Этот тег должен появляться только один раз в данном цикле страницы, чтобы избежать дублирования ссылок.

#### Внедрение стилей

Ссылки на файлы стилей могут быть программно внедрены в PHP через [компоненты](../../extend/cms-components.md) или [страницы](../../cms/themes/pages.md).

```php
function onStart()
{
    $this->addCss('assets/css/hello.css');
}
```

Вы также можете внедрить необработанную разметку в тег `{% styles %}`, используя анонимный плейсхолдер **styles** [в макете](../../cms/themes/layouts.md). Используйте тег `{% put %}` на страницах или в макетах для добавления содержимого в плейсхолдер.

```twig
{% put styles %}
    <link href="/themes/demo/assets/css/page.css" rel="stylesheet" />
{% endput %}
```

### {% meta %}

Тег `{% meta %}` рендерит мета-контент, например, информацию Open Graph. Тег обычно определяется в секции HEAD страницы или макета, перед стилями и скриптами.

```twig
<head>
    {% meta %}
    ...
</head>
```

> **Примечание**: Этот тег должен появляться только один раз в данном цикле страницы, чтобы избежать дублирования ссылок.

#### Внедрение мета-данных

Вы можете внедрить необработанную разметку в тег `{% meta %}`, используя анонимный плейсхолдер **meta** [в макете](../../cms/themes/layouts.md). Используйте тег `{% put %}` на страницах или в макетах для добавления содержимого в плейсхолдер.

```twig
{% put meta %}
    <meta name="turbo-visit-control" content="error">
{% endput %}
```

## Пользовательские атрибуты

Тег `placeholder` принимает два необязательных атрибута — `title` и `type`. Атрибут `title` не используется самой CMS, но может использоваться другими плагинами. Атрибут `type` управляет типом плейсхолдера. В настоящее время поддерживаются два типа — **text** и **html**. Содержимое текстовых плейсхолдеров экранируется перед отображением. Атрибуты title и type должны определяться после имени плейсхолдера и атрибута `default`, если он присутствует. Пример:

```twig
{% placeholder ordering title="Ordering information" type="text" %}
```

Пример плейсхолдера с содержимым по умолчанию, атрибутами title и type.

```twig
{% placeholder ordering default title="Ordering information" type="text" %}
    There is no ordering information for this product.
{% endplaceholder %}
```

# {% flash %}

::: aside
Обратитесь к [статье о Flash-сообщениях](../../cms/features/flash-messages.md), чтобы узнать больше об использовании flash-сообщений.
:::

Теги `{% flash %}` и `{% endflash %}` рендерят все flash-сообщения, сохранённые в сессии пользователя и установленные PHP-классом `Flash`. Переменная `message` внутри будет содержать текст flash-сообщения, а разметка внутри будет повторяться для нескольких flash-сообщений.

```twig
<ul>
    {% flash %}
        <li>{{ message }}</li>
    {% endflash %}
</ul>
```

Вы можете использовать переменную `type`, которая представляет тип flash-сообщения — **success**, **error**, **info** или **warning**.

```twig
{% flash %}
    <div class="alert alert-{{ type }}">
        {{ message }}
    </div>
{% endflash %}
```

Вы также можете указать `type` для фильтрации flash-сообщений определённого типа. Следующий пример покажет только сообщения **success** — если есть сообщение **error**, оно не будет отображено.

```twig
{% flash success %}
    <div class="alert alert-success">{{ message }}</div>
{% endflash %}
```

## Сохранение flash-сообщений в Twig-переменную

В любом шаблоне вы можете сохранить flash-сообщения в переменную с помощью функции `flash()`. Это позволяет манипулировать выводом перед отображением. Функция возвращает массив с одним flash-сообщением на каждый тип.

```twig
{% set messages = flash() %}
```

Первый аргумент может указывать тип сообщения — в этом случае возвращается сообщение как строка.

```twig
{% set successMessage = flash('success') %}
```

Если первый аргумент установлен в **all**, функция вернёт массив типов, каждый из которых является массивом всех flash-сообщений.

```twig
{% set allMessages = flash('all') %}
```

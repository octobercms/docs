# {% component %}

Тег `{% component %}` парсит стандартную разметку [CMS-компонента](../../cms/themes/components.md) и отображает её на странице. Не все компоненты предоставляют стандартную разметку — документация плагина подскажет правильное использование.

```twig
{% component "blogPosts" %}
```

Это отобразит фрагмент компонента с фиксированным именем **default.htm** и по сути является псевдонимом для следующего:

```twig
{% partial "blogPosts::default" %}
```

## Переменные

Некоторые компоненты поддерживают передачу переменных во время рендеринга.

```twig
{% component "blogPosts" postsPerPage="5" %}
```

## Настройка компонентов

В большинстве случаев тег `{% component %}` не нужен, а разметка предоставляется как пример использования API компонента. Компоненты предназначены для настройки, и это можно сделать двумя способами:

1. Перемещение стандартной разметки во фрагмент
1. Переопределение фрагментов компонента с помощью темы

[Статья о CMS-компонентах](../../cms/themes/components.md) описывает процесс настройки стандартной разметки.

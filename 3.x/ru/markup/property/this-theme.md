# this.theme

Вы можете получить доступ к текущему объекту темы через `this.theme`, который возвращает объект `Cms\Classes\Theme` — ссылку на [объект настройки темы](../../cms/themes/settings.md).

## Свойства

`this.theme` предоставляет прямой доступ к значениям полей формы, определённым любой настройкой темы. Он также имеет следующие встроенные свойства.

### id

Преобразует имя директории темы в CSS-совместимый идентификатор.

```twig
<body class="theme-{{ this.theme.id }}">
```

Если директория темы — **website**, это сгенерирует имя класса `theme-website`.

### config

Массив, содержащий все значения конфигурации темы из файла `theme.yaml`.

```twig
<meta name="description" content="{{ this.theme.config.description }}">
```

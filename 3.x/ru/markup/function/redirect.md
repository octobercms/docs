# redirect()

Функция `redirect()` перенаправляет ответ на URL или страницу темы.

Для выполнения перенаправления передайте первый аргумент как место назначения — либо имя CMS-страницы, либо URL-адрес.

```twig
{% if record.notFound %}
    {% do redirect('404') %}
{% endif %}
```

Параметры страницы можно передать как второй аргумент.

```twig
{% do redirect('docs', { slug: 'home' }) %}
```

Для перенаправления на URL передайте полный адрес вместо имени страницы.

```twig
{% do redirect('https://octobercms.com') %}
```

Чтобы включить код перенаправления, например `302` (временное) или `301` (постоянное), используйте второй или третий аргумент. По умолчанию используется код `302`.

```twig
{% do redirect('https://octobercms.com', 301) %}
```

# config()

Вы можете получить доступ к значениям конфигурации с помощью вспомогательной функции `config()`. Она возвращает текущее значение из хранилища конфигурации.

Следующий пример выведет значение, хранящееся в `app.locale`.

```twig
{{ config('app.locale') }}
```

Приведённый выше код является PHP-эквивалентом следующего:

```php
<?= Config::get('app.locale') ?>
```

## env()

Сопутствующая функция `env()` может использоваться для доступа к переменным окружения.

Следующий пример выведет значение, хранящееся в переменной окружения `APP_ENV`. Второй аргумент — значение по умолчанию, когда ключ ENV не существует.

```twig
{{ env('APP_ENV', 'production') }}
```

Приведённый выше код является PHP-эквивалентом следующего:

```php
<?= env('APP_ENV', 'production') ?>
```

::: warning
Функции `config()` и `env()` недоступны, когда включён [безопасный режим](../../setup/configuration.md).
:::

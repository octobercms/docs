# abort()

Функция `abort()` прерывает успешный путь запроса, изменяя код ответа и содержимое. Это полезно для установки пользовательского HTTP-кода или отображения страницы 404, когда запись не найдена.

```twig
{% if record.notFound %}
    {% do abort(404) %}
{% endif %}
```

Чтобы установить код ответа и отобразить страницу 404 темы, используйте код `404`.

```twig
{% do abort(404) %}
```

Любой другой код отобразит страницу ошибки с необязательным сообщением в качестве второго аргумента.

```twig
{% do abort(403, 'Access Denied') %}
```

Чтобы установить HTTP-код в заголовке без изменения содержимого ответа, передайте `false` в качестве второго аргумента.

```twig
{% do abort(404, false) %}
```

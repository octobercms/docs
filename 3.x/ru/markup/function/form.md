# form()

Функции с префиксом `form_` выполняют задачи, полезные при работе с формами. Вспомогательные функции напрямую соответствуют PHP-классу `Form` и его методам. Например:

```twig
{{ form_close() }}
```

Приведённый выше код является PHP-эквивалентом следующего:

```php
<?= Form::close() ?>
```

> **Примечание**: Методы в *camelCase* должны быть преобразованы в *snake_case*.

## form_open()

Выводит стандартный открывающий тег `<form>` вместе со скрытыми полями `_session_key` и `_token` для защиты от CSRF. Если вы используете [AJAX-фреймворк](../../cms/ajax/introduction.md), рекомендуется использовать `form_ajax()`.

```twig
{{ form_open() }}
```

Атрибуты можно передать в первом аргументе.

```twig
{{ form_open({ class: 'form-horizontal' }) }}
```

Приведённый выше пример выведет следующее:

```html
<form class="form-horizontal">
```

Существуют также некоторые специальные опции, которые можно использовать наряду с атрибутами.

```twig
{{ form_open({ request: 'onUpdate' }) }}
```

Функция поддерживает следующие опции:

Опция | Описание
------------- | -------------
**method** | Метод запроса. Соответствует атрибуту **method** тега FORM. Например: POST, GET, PUT, DELETE
**request** | Имя обработчика для выполнения на сервере при отправке формы. Подробнее об обработчиках событий см. в статье об [AJAX-обработчиках](../../cms/ajax/handlers.md).
**url** | Указывает URL для отправки формы. Соответствует атрибуту **action** тега FORM.
**files** | Определяет, будет ли форма отправлять файлы. Допустимые значения: **true** и **false**.
**model** | Объект модели для привязки модели к форме.

## form_ajax()

Выводит открывающий тег FORM с поддержкой AJAX. Первый параметр функции `form_ajax()` — имя AJAX-обработчика. Обработчик может быть определён в PHP-секции макета или страницы, а также в компоненте. Подробнее об AJAX см. в статье об [AJAX-фреймворке](../ajax/introduction.md).

```twig
{{ form_ajax('onUpdate') }}
```

Атрибуты можно передать во втором аргументе.

```twig
{{ form_ajax('onSave', { class: 'form-horizontal'}) }}
```

Приведённый выше пример выведет следующее:

```html
<form data-request="onSave" class="form-horizontal">
```

Существуют также некоторые специальные опции, которые можно использовать наряду с атрибутами.

```twig
{{ form_ajax('onDelete', { data: { id: 2 }, confirm: 'Really delete this record?' }) }}

{{ form_ajax('onRefresh', { update: { statistics: '#statsPanel' } }) }}
```

> **Примечание**: При попытке сослаться на псевдоним компонента с помощью `__SELF__` в качестве аргумента `form_ajax()` необходимо сначала построить строку вне самого вызова. Пример:

```twig
{% set targetPartial = "'" ~ __SELF__ ~ "::statistics': '#statsPanel'" %}
{{ form_ajax('onUpdate', { update: targetPartial }) }}
```

Функция поддерживает следующие опции:

Опция | Описание
------------- | -------------
**success** | Строка JavaScript для выполнения при успешном результате.
**error** | Строка JavaScript для выполнения при неудачном результате.
**confirm** | Сообщение подтверждения для отображения перед отправкой запроса.
**redirect** | При успешном результате перенаправить на URL.
**update** | Массив фрагментов для обновления при успехе в следующем формате: { 'partial': '#element' }.
**data** | Дополнительные данные для включения в запрос в следующем формате: { 'myvar': 'myvalue' }.

## form_close()

Выводит стандартный закрывающий тег FORM. Этот тег обычно доступен для обеспечения единообразия использования.

```twig
{{ form_close() }}
```

Приведённый выше пример выведет следующее:

```html
</form>
```

## Передача атрибутов генерируемому элементу

Вы можете передать дополнительные атрибуты методу `Form::open()`, передав массив имён и значений атрибутов для рендеринга в итоговом сгенерированном элементе `<form>`.

```php
<?= Form::open(array('id' => 'example', 'class' => 'something')) ?>
    // ..
<?= Form::close() ?>
```

Приведённый выше пример выведет следующее:

```html
<form method="POST" action="" accept-charset="UTF-8" id="example" class="something">

</form>
```

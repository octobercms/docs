# dump()

Функция `dump()` выводит информацию о переменной шаблона. Это полезно при отладке шаблона, который работает не так, как ожидалось.

```twig
{{ dump(user) }}
```

Вы можете проверить несколько переменных, передав их как дополнительные аргументы:

```twig
{{ dump(user, categories) }}
```

Если вы не передаёте никакого значения, выводятся все переменные из текущего контекста:

```twig
{{ dump() }}
```

## d()

Функция `d()` является более коротким синтаксисом для отладки в Twig. Она показывает меньше деталей об объекте, но позволяет легче увидеть все значения сразу. Она рекурсивно выводит предоставленные переменные так же, как PHP-функция `dd()`.

```twig
{{ d(user) }}
```

Вы также можете передать несколько переменных в аргументах.

```twig
{{ d(variable1, variable2) }}
```

Функция `dd()` — альтернатива, которая выводит значения и затем завершает процесс.

```twig
{{ dd('dump and die') }}
```

::: warning
Функции `dump()` и `d()` недоступны, когда включён [безопасный режим](../../setup/configuration.md).
:::

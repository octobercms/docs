# Шаблонизация

October CMS расширяет [язык шаблонов Twig](https://twig.symfony.com/doc/) набором функций, тегов, фильтров и переменных. Эти расширения позволяют использовать возможности CMS и получать доступ к информации об окружении страницы внутри шаблонов.

## Переменные

Переменные шаблона выводятся на странице с помощью *двойных фигурных скобок*.

```twig
{{ variable }}
```

Переменные также могут представлять *выражения*.

```twig
{{ isAjax ? 'Yes' : 'No' }}
```

Переменные можно конкатенировать с помощью символа `~`.

```twig
{{ 'Your name: ' ~ name }}
```

October предоставляет глобальные переменные через переменную `this`, перечисленные в разделе **Переменные**.

## Теги

Теги — это уникальная особенность Twig, они заключаются в символы `{% %}`.

```twig
{% tag %}
```

Теги обеспечивают более наглядный способ описания логики шаблона.

```twig
{% if stormCloudComing %}
    Stay inside
{% else %}
    Go outside and play
{% endif %}
```

Тег `{% set %}` может использоваться для установки переменных внутри шаблона.

```twig
{% set activePage = 'blog' %}
```

Теги могут иметь различный синтаксис и перечислены в разделе **Теги**.

## Фильтры

Фильтры действуют как модификаторы переменных для отдельного экземпляра и применяются с помощью *символа вертикальной черты* (pipe), за которым следует имя фильтра.

```twig
{{ 'string'|filter }}
```

Фильтры могут принимать аргументы, как функции.

```twig
{{ price|currency('USD') }}
```

Фильтры можно применять последовательно.

```twig
{{ 'October Glory'|upper|replace({'October': 'Morning'}) }}
```

Фильтры перечислены в разделе **Фильтры**.

## Функции

Функции позволяют выполнять логику, а возвращаемый результат действует как переменная.

```twig
{{ function() }}
```

Функции могут принимать аргументы.

```twig
{{ dump(variable) }}
```

Функции перечислены в разделе **Функции**.

## Логика доступа

::: v-pre
Самое важное, что нужно знать о Twig, — это то, как он обращается к PHP-слою. Для удобства `{{ foo.bar }}` выполняет следующие проверки для PHP-объекта:
:::

1. Проверяет, является ли `foo` массивом, а `bar` — допустимым элементом.
1. Если нет, и если `foo` — объект, проверяет, является ли `bar` допустимым свойством.
1. Если нет, и если `foo` — объект, проверяет, является ли `bar` допустимым методом (даже если bar — конструктор, используйте `__construct()`).
1. Если нет, и если `foo` — объект, проверяет, является ли `getBar` допустимым методом.
1. Если нет, и если `foo` — объект, проверяет, является ли `isBar` допустимым методом.
1. Если нет, возвращает значение `null`.

## Неподдерживаемые функции

Некоторые возможности Twig не поддерживаются October CMS. Они перечислены ниже вместе с эквивалентными функциями.

Тег | Эквивалент
------------- | -------------
`{% extend %}` | Используйте [Макеты](../cms/themes/layouts.md) или `{% placeholder %}`
`{% include %}` | Используйте `{% partial %}` или `{% content %}`

# |resize

Фильтр `|resize` пытается изменить размер предоставленного источника изображения, используя заданную конфигурацию изменения размера, и выводит URL к изменённому изображению.

```twig
{{ 'image.jpg'|resize(100, 100) }}
```

Фильтр принимает три аргумента: `|resize(width, height, options)`.

Если фильтр может изменить размер предоставленного изображения, возвращается URL к ресайзеру изображений (например: `/resize/filename.png`). При последующих запросах возвращается прямой URL к изменённому изображению. Если фильтр не может обработать предоставленное изображение, он возвращает оригинальный URL без изменений.

Следующий пример изменит размер медиа-изображения banner.jpg до соотношения 1920 x 1080.

```twig
<img src="{{ 'banner.jpg'|media|resize(1920, 1080) }}" />
```

Вы также можете передать третий аргумент с опциями. В этом примере изображение будет обрезано.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, { mode: 'crop' }) }}" />
```

Подробнее о доступных параметрах `options` см. в [статье о ресайзере изображений](../../extend/services/resizer.md).

## Пользовательские имена файлов

По умолчанию ресайзер присваивает случайное имя файла изменённым изображениям. Вы можете использовать оригинальное имя файла, передав `true` в опцию `filename` ресайзера.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, { filename: true }) }}" />
```

Опция `filename` также поддерживает пользовательское имя файла в виде строки. Имя файла не должно содержать расширение, так как используется оригинальное.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, { filename: 'my-seo-friendly-name' }) }}" />
```

Вы можете изменить расширение с помощью опции `extension`. Этот процесс попытается конвертировать один тип файла в другой, например, JPG в PNG.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, {
    filename: 'my-seo-friendly-name',
    extension: 'png'
}) }}" />
```

## Пользовательские имена папок

При использовании пользовательских имён файлов имя файла всё ещё будет содержать хэш в конце для обеспечения уникальности в директории ресурсов ресайзера. В большинстве случаев этого достаточно для удовлетворения базовых требований SEO. Например, файл будет выглядеть в системе следующим образом.

- `.../800_600_0_0_auto/my-seo-friendly-name_001a14981ffe90700046616c5f415467.png`

Можно указать `group` в качестве имени папки — это поместит изображение в выделенную группу ресурсов.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, {
    filename: 'my-seo-friendly-name',
    group: '2024-banners'
}) }}" />
```

Например, приведённый выше код поместит файл в следующую директорию:

- `.../800_600_0_0_auto/2024-banners/my-seo-friendly-name.png`

Однако имейте в виду, что этот подход подвержен конфликтам имён. Если другой файл будет изменён с тем же именем и параметрами, он выведет оригинальный файл, так как к пути не добавляется уникальный хэш.

## Доступные источники

Вы можете ссылаться на изображения из нескольких источников, включая следующие пути:

- `/app`
- `/plugins`
- `/themes`
- `/modules`
- `/storage/app/uploads`
- `/storage/app/media`

Например:

```twig
{{ '/plugins/acme/blog/assets/images/someimage.png'|resize(...) }}
```

## PHP-интерфейс

Вы можете изменять размер изображений в PHP с помощью класса `System\Classes\ResizeImages` и метода `resize`. Возвращаемое значение — URL к изменённому изображению.

```php
ResizeImages::resize('path/to/asset.jpg');
```

Метод принимает ширину (второй аргумент), высоту (третий аргумент) и [опции ресайзера](../../extend/services/resizer.md) (четвёртый аргумент).

```php
ResizeImages::resize('path/to/asset.jpg', 800, 600, ['mode' => 'crop']);
```

# |app

Фильтр `|app` возвращает адрес относительно публичного пути сайта. Результатом является абсолютный URL, включающий доменное имя и протокол, к местоположению, указанному в параметре фильтра. Фильтр может применяться к любому пути.

```twig
<link rel="icon" href="{{ '/favicon.ico'|app }}" />
```

Если адрес сайта — __https://octobercms.com__, приведённый выше пример выведет следующее:

```html
<link rel="icon" href="https://octobercms.com/favicon.ico" />
```

Его также можно использовать для статических URL:

```twig
<a href="{{ '/about-us'|app }}">
    About Us
</a>
```

Результат будет следующим:

```html
<a href="https://octobercms.com/about-us">
    About us
</a>
```

> **Примечание**: Для ссылок на другие страницы рекомендуется фильтр `|page`.

# |theme

Фильтр `|theme` возвращает адрес относительно пути активной темы сайта. Результатом является абсолютный URL, включающий домен и протокол, к ресурсу, указанному в параметре фильтра. Ресурсы темы обычно находятся в поддиректории **assets** директории темы.

```twig
<script type="text/javascript" src="{{ 'assets/js/menu.js'|theme }}"></script>
```

Если адрес сайта — __https://octobercms.com__, а активная тема называется `website`, приведённый выше пример выведет следующее:

```html
<script type="text/javascript" src="http://october.com/themes/website/assets/js/menu.js"></script>
```

## Объединение CSS и JavaScript

Фильтр также можно использовать для объединения ресурсов одного типа, передав массив файлов.

```twig
<link href="{{ [
    'assets/css/styles1.css',
    'assets/css/styles2.css'
]|theme }}" rel="stylesheet">
```

> **Примечание**: Вы можете включить минификацию ресурсов с помощью параметра `enableAssetMinify` в скрипте `config/cms.php`. По умолчанию минификация отключена.

### Псевдонимы комбинатора

Комбинатор ресурсов поддерживает общие псевдонимы, которые подставляют пути к файлам. Они начинаются с символа `@`. Например, [ресурсы AJAX-фреймворка](../../cms/ajax/introduction.md) можно включить в комбинатор.

```twig
<script src="{{ [
    '@framework.extras',
    'assets/javascript/app.js'
]|theme }}"></script>
```

Поддерживаются следующие псевдонимы:

Псевдоним | Описание
------------- | -------------
`@framework` | Дополнения AJAX-фреймворка, замена тега `{% framework %}` (JavaScript)
`@framework.extras` | Дополнения AJAX-фреймворка, замена тега `{% framework extras %}` (JavaScript, CSS)
`@framework.turbo` | Turbo AJAX-фреймворка, замена тега `{% framework turbo %}` (JavaScript)
`@framework.bundle` | Бандл AJAX-фреймворка, замена тега `{% framework extras turbo %}` (JavaScript, CSS)

:: tip
Один и тот же псевдоним можно использовать для JavaScript или CSS, например `@framework.extras`. Для определения используемого типа необходима хотя бы одна другая ссылка с расширением файла CSS или JS в массиве.
:::

### Внешние пути комбинатора

В некоторых случаях может потребоваться объединить файл за пределами темы. Это достигается путём добавления символа перед путём для создания динамического пути. Например, путь, начинающийся с `~/`, создаёт путь относительно приложения:

```twig
<script src="{{ ['~/modules/system/assets/js/framework.js']|theme }}"></script>
```

Для создания динамических путей поддерживаются следующие символы:

Символ | Описание
------------- | -------------
`~` | Относительно директории приложения
`$` | Относительно директории плагинов
`#` | Относительно директории тем

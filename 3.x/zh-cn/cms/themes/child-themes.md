# 子主题

子主题提供了主题继承的可能性。一个很好的用途是当您有一个第三方主题或处于只读模式的主题时。子主题将引用一个父主题，并将其用作备用来源。

如果一个名为 `home.htm` 的页面存在于父主题中但不存在于子主题中，系统会将其视为存在一样处理；URL 是活动的，您可以像正常一样打开该页面。在后端区域保存页面时，会在子主题中创建一个新文件来覆盖内容。

要为主题启用此功能，请导航到**设置 → 前端主题**，选择**编辑属性**，然后从**父主题**下拉列表中选择一个父主题。

## 主题锁定文件

使用 Composer 从第三方安装主题时，需要注意的是，当主题更新时，所有文件都可能被覆盖。这可能导致对主题所做的任何自定义更改丢失。作为安全机制，包含了一个名为 `.themelock` 的文件来保护主题免受系统更新期间可能丢失的任何更改。

当主题目录中存在 `.themelock` 文件时：

- 该主题只能被选择为父主题
- 该主题不会出现在后端 UI 中
- 该主题无法被选择为活动主题

## 创建新的子主题

`theme:copy` 命令可用于创建新主题，包括子主题。以下命令通过复制目录及其内容，从源主题 `demo` 创建一个名为 `demo-copy` 的新主题。在此过程中将删除 `.themelock` 文件。

```bash
php artisan theme:copy demo demo-copy
```

要创建继承父主题的子主题，请指定 `--child` 选项。

```bash
php artisan theme:copy demo demo-child --child
```

# Password 字段

`password` 字段渲染一个单行密码输入框，用于捕获敏感值，如密码。

```yaml
user_password:
    label: Password
    type: password
```

以下[字段属性](../form-fields.md)常用。

属性 | 描述
------------- | -------------
**title** | 表单字段的标题。
**comment** | 在字段下方放置描述性注释。

::: tip
查看 [Sensitive 表单小部件](./widget-sensitive.md)，了解一个可以捕获和显示敏感值的字段。
:::

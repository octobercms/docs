# 可用图标

October CMS 自带图标库，并包含第三方库，使查找合适的图标变得快速便捷。

## Phosphor 图标

[Phosphor 图标包](https://phosphoricons.com/)可在管理面板中使用。该库提供了一组灵活的日常使用图标。

```html
<i class="ph ph-laptop"></i>
```

当用作图标定义时，图标名称包含 `ph` 和 `ph-` 前缀。

```yaml
icon: ph ph-laptop
```

## October 图标

**October 图标包**是一个包含各种描述图标的自定义图标库。该图标包主要由核心功能使用，可能会不时更新。

```html
<i class="icon-october"></i>
```

当用作图标定义时，图标名称仅包含 `icon-` 前缀。

```yaml
icon: icon-october
```
